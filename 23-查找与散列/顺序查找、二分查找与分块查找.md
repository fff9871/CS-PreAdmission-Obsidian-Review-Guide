# 顺序查找、二分查找与分块查找（★★★）

#data-structures #searching

## Overview Table

| 方法 | 前提 | 时间 | 适用存储 |
|---|---|---:|---|
| 顺序查找 | 无 | $O(n)$ | 顺序表或链表 |
| 二分查找 | 关键字有序+可随机存取 | $O(\log n)$ | 数组/顺序表 |
| 分块查找 | 块间有序，块内可无序 | 取决于索引和块大小 | 分块顺序表 |

## 二分查找不变量

```text
闭区间 [left, right]：
while left <= right
  mid = left + (right-left)//2
  a[mid] < target → left = mid+1
  a[mid] > target → right = mid-1
```

寻找第一个 `>= target` 的下界、第一个 `> target` 的上界时，应把问题改写成“找最小的使谓词成立的下标”，而不是见到目标立即返回。

> [!warning]
> 有序链表不适合普通二分查找，因为定位中点需要线性时间；总成本不会因比较次数为对数就变成 $O(\log n)$。

## Exam/Test Patterns

| 场景 | 回答 |
|---|---|
| 有重复元素找首个 | 命中后继续向左收缩 |
| 计算 `mid` | `left + (right-left)//2` 可避免相加溢出 |
| 分块查找 | 先查索引定位块，再在块内顺序查找 |

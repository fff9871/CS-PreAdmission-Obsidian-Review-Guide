# IPv4编址、子网与CIDR（★★★）

#computer-networks #network-layer #ipv4 #subnetting #cidr

## Overview Table

| 概念 | 表示 | 作用 |
|---|---|---|
| IPv4 地址 | 32 bit，点分十进制 | 标识接口的网络位置 |
| 子网掩码 | 连续 1 表示网络/前缀部分 | 与 IP 按位与得到网络地址 |
| CIDR | `a.b.c.d/n` | 用可变长前缀聚合和分配地址 |
| 主机地址范围 | 去除网络地址和传统广播地址 | 分配给子网内接口 |

## 子网计算

给定 `192.168.10.77/26`：

- `/26` 掩码为 `255.255.255.192`，块大小 `256-192=64`。
- 77 落在区间 64–127。
- 网络地址 `192.168.10.64`，广播地址 `192.168.10.127`。
- 传统可用主机地址为 `.65`–`.126`。

    IP地址
      AND 子网掩码
      = 网络前缀 ──用于路由匹配

## 地址聚合与最长前缀

CIDR 允许把连续、前缀相同的网络聚合成较短路由，减小路由表。转发时若多个前缀都匹配目的地址，选择前缀长度最长、范围最具体的表项。

> [!warning]
> 一个主机能否直接通信取决于双方前缀配置和链路，而不只看传统 A/B/C 类。`/31` 可用于点到点链路，`/32` 表示单个主机路由，不能机械套用“总减 2”。

## Exam/Test Patterns

| 问法 | 回答步骤 |
|---|---|
| 求网络地址 | IP 与掩码逐位 AND |
| 求子网容量 | 一般为 `2^(32-n)` 个地址，再按场景处理保留地址 |
| 路由聚合 | 找公共高位前缀，并验证范围连续、边界对齐 |

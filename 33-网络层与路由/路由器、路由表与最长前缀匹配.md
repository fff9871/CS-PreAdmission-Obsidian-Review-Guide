# 路由器、路由表与最长前缀匹配（★★★）

#computer-networks #network-layer #routing #longest-prefix-match

## Overview Table

| 概念 | 时间尺度 | 任务 |
|---|---|---|
| 路由选择 | 较慢、控制平面 | 计算路径并生成路由信息 |
| 分组转发 | 每个分组、数据平面 | 按转发表把分组送到输出接口 |
| 路由表 | 协议产生的逻辑路由 | 可能含多个候选、度量和策略 |
| 转发表 | 实际高速查找结构 | 保存用于转发的最佳下一跳 |

## 最长前缀匹配

目的地址可能同时匹配默认路由 `/0`、汇总路由 `/16` 和更具体路由 `/24`，路由器选择前缀最长的 `/24`。前缀长度相同时，再依据管理距离、度量值或等价多路径等规则选路。

    目的IP → 匹配所有前缀 → 选最长前缀 → 下一跳/输出接口

## 路由器与交换机

| 维度 | 二层交换机 | 路由器 |
|---|---|---|
| 依据 | MAC 表 | IP 前缀表 |
| 范围 | 同一链路/VLAN | 不同 IP 网络之间 |
| 广播域 | 默认不隔离同 VLAN 广播 | 接口形成三层边界 |
| 表项来源 | 数据平面自学习 | 静态配置或路由协议 |

> [!warning]
> “路由器选择路径”与“路由器逐包转发”不是同一操作。面试中应分别说明控制平面和数据平面，且路由表与转发表的字段及数量可能不同。

## Exam/Test Patterns

| 问法 | 回答路径 |
|---|---|
| 路由器两大功能 | 路由选择与分组转发 |
| 多条前缀同时匹配 | 选择最长、最具体前缀 |
| 路由器 vs 交换机 | IP/跨网/广播边界 vs MAC/同网/帧转发 |

# 调度层次、评价指标与抢占（★★★）

#operating-systems #process-management #scheduling #preemption

## Overview Table

| 层次 | 选择对象 | 典型作用 |
|---|---|---|
| 高级/作业调度 | 外存后备作业 | 决定接纳量与系统负载 |
| 中级调度 | 挂起与换入进程 | 调节内存驻留和多道程度 |
| 低级/进程调度 | 就绪实体 | 决定下一个占用 CPU 者 |

## 评价指标

| 指标 | 定义/目标 |
|---|---|
| 周转时间 | `完成时间 - 到达时间`，越小越好 |
| 带权周转 | `周转时间 / 服务时间` |
| 等待时间 | 在就绪队列等待的总时间 |
| 响应时间 | 首次获得响应时间减到达时间 |
| 吞吐量 | 单位时间完成的作业数 |
| CPU 利用率 | CPU 忙碌时间比例 |
| 公平性/截止期 | 避免饥饿或满足实时约束 |

抢占式调度可在时钟中断或更高优先级任务到达时收回 CPU；非抢占式通常等待运行者阻塞或完成。

    到达/唤醒 → 就绪队列 → 调度决策 → 分派 → 运行
                       ↑                  │
                       └──── 抢占 ────────┘

> [!warning]
> 平均周转时间、响应时间、公平性和截止期可能互相冲突。调度算法的“最优”必须绑定工作负载与指标；等待时间不包含实际运行和阻塞 I/O 的时间。

## Exam/Test Patterns

| 场景 | 首要指标 |
|---|---|
| 批处理 | 吞吐量、周转时间 |
| 交互系统 | 响应时间、公平性 |
| 硬实时 | 截止期可满足性 |

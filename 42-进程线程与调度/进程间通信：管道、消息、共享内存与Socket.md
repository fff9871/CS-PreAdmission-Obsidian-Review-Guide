# 进程间通信：管道、消息、共享内存与Socket（★★★）

#operating-systems #process-management #ipc #shared-memory

## Overview Table

| IPC | 数据路径/模型 | 特点 |
|---|---|---|
| 匿名管道 | 内核字节流，常用于亲缘进程 | 单机、通常单向、无消息边界 |
| 命名管道 | 具名内核对象 | 无亲缘关系进程也可使用 |
| 消息队列 | 内核保存离散消息 | 保留边界，可按类型接收 |
| 共享内存 | 多进程映射同一物理页 | 数据面快，但需另行同步 |
| 信号 | 异步事件通知 | 信息量小，处理受限 |
| Socket | 双向端点 | 可跨主机，支持流或数据报 |

## 两种核心模型

    消息传递：P1 → 内核缓冲/通道 → P2
    共享内存：P1 ↘ 同一共享区 ↗ P2
                    ↑ 锁/信号量同步

选择 IPC 时考虑数据量、消息边界、复制次数、同步、生命周期、安全权限和是否跨主机。

> [!warning]
> 共享内存只解决“看见同一数据”，不自动提供原子性和顺序；管道的原子写边界受系统限制；TCP Socket 是字节流，也不保留应用消息边界。

## Exam/Test Patterns

| 需求 | 常见选择 |
|---|---|
| 父子进程流式连接 | 匿名管道 |
| 大块本机低复制数据 | 共享内存 + 同步原语 |
| 跨主机通信 | Socket/RPC |
| 轻量异步通知 | 信号或事件对象 |

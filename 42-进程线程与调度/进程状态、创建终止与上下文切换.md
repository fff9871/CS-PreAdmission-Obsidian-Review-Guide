# 进程状态、创建终止与上下文切换（★★★）

#operating-systems #process-management #process-state #context-switch

## Overview Table

| 状态 | 含义 | 典型去向 |
|---|---|---|
| 新建 | 正在创建、尚未进入就绪队列 | 就绪 |
| 就绪 | 已具备运行条件，只缺 CPU | 运行 |
| 运行 | 正占用 CPU | 就绪、阻塞、终止 |
| 阻塞/等待 | 等待 I/O、同步事件或资源 | 就绪 |
| 终止 | 执行结束，等待资源回收 | 被删除 |

## 状态转换

    新建 ─接纳→ 就绪 ─调度→ 运行 ─退出→ 终止
                    ↑          │  │
          事件完成 ─┘          │  └─等待事件→ 阻塞
                    抢占/时间片┘              │
                    └─────────────────────────┘

挂起表示进程映像的一部分可能被换出，它可与就绪/阻塞组合成“就绪挂起”“阻塞挂起”。

## 上下文切换

1. 中断、异常、阻塞或抢占进入内核。
2. 保存当前执行实体的寄存器、PC 和调度状态。
3. 更新状态与队列，选择下一个实体。
4. 切换地址空间等资源上下文，恢复现场并返回。

上下文切换是纯开销，还可能破坏 Cache、TLB 和分支预测器的局部性。

> [!warning]
> 运行到就绪通常由抢占产生；运行到阻塞由主动等待产生。阻塞进程在事件完成后先进入就绪态，而不是直接运行。模式切换、线程切换和进程切换的成本不同。

## Exam/Test Patterns

| 场景 | 转换 |
|---|---|
| 时间片耗尽 | 运行→就绪 |
| 等待磁盘 | 运行→阻塞 |
| I/O 完成 | 阻塞→就绪 |
| 调度器分派 | 就绪→运行 |

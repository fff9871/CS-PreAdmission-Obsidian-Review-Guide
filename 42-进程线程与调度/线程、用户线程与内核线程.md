# 线程、用户线程与内核线程（★★★）

#operating-systems #process-management #threads #thread-models

## Overview Table

| 对象 | 独有 | 同进程内共享 |
|---|---|---|
| 进程 | 地址空间、资源容器、保护边界 | — |
| 线程 | PC、寄存器、栈、调度状态 | 代码、数据、堆、打开文件等 |

## 实现模型

| 模型 | 优点 | 局限 |
|---|---|---|
| 用户级线程 | 创建切换快，可定制调度 | 内核不可见时，阻塞调用可能阻塞整个进程 |
| 内核级线程 | 可按线程阻塞和多核并行 | 创建、切换需内核参与 |
| 多对一 | 用户多线程映射一个内核线程 | 无法真正多核并行 |
| 一对一 | 每个用户线程对应内核线程 | 内核对象和切换开销较大 |
| 多对多 | 多个用户线程复用多个内核线程 | 运行时与内核协同复杂 |

    进程：资源与保护容器
      ├─线程 A：PC + registers + stack
      ├─线程 B：PC + registers + stack
      └─共享：code/data/heap/files

线程适合把可并行或需重叠等待的活动拆开，但共享地址空间也使竞态、死锁和故障传播更容易发生。

> [!warning]
> “线程切换一定不进入内核”只适用于特定用户线程实现；“线程比进程快”也取决于地址空间切换、内核调度和缓存行为。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| 进程 vs 线程 | 资源/保护单位 vs 执行/调度单位 |
| 线程独有数据 | PC、寄存器、栈和调度状态 |
| 多核并行条件 | 至少有多个内核可调度实体 |

# I-O接口与统一独立编址（★★★）

#computer-organization #io-system #io-interface #io-addressing

## Overview Table

| I/O 接口寄存器 | 作用 |
|---|---|
| 数据寄存器 | 暂存 CPU 与设备交换的数据 |
| 状态寄存器 | 反映就绪、忙、错误、中断等状态 |
| 控制寄存器 | 保存启动、模式、中断使能等命令 |

## 两种编址

| 方式 | 地址空间 | 指令 | 特点 |
|---|---|---|---|
| 统一编址/存储器映射 I/O | I/O 寄存器占用内存地址空间 | 普通 load/store | 指令统一、寻址灵活，占用地址范围 |
| 独立编址/端口映射 I/O | 单独 I/O 地址空间 | 专用 I/O 指令 | 地址空间分离，指令和控制专门化 |

## 接口作用

    CPU/总线 ↔ I/O接口 ↔ 外设
                 ├─ 数据缓冲
                 ├─ 状态与控制
                 ├─ 电平/时序转换
                 └─ 中断或DMA请求

接口缓冲 CPU 与设备的速度、数据格式和时序差异，并提供错误状态与设备选择逻辑。

> [!warning]
> “统一编址”不表示设备寄存器与普通内存具有完全相同的副作用和缓存属性。内存映射 I/O 常要求禁止普通 Cache、保持访问顺序并使用易失语义。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| 普通访存指令访问设备 | 统一编址 |
| 专用 IN/OUT 指令 | 独立编址 |
| I/O接口功能 | 缓冲、格式/时序转换、状态控制和请求 |

# 总线分类、宽度、带宽与复用（★★★）

#computer-organization #bus #bus-bandwidth

## Overview Table

| 分类/指标 | 含义 |
|---|---|
| 数据总线 | 传送数据，通常双向 |
| 地址总线 | 指定存储单元或 I/O 端口，通常由主设备输出 |
| 控制总线 | 传送读写、请求、响应、中断等控制信号 |
| 总线宽度 | 一次可并行传送的数据位数 |
| 总线带宽 | 单位时间最大传输数据量 |
| 总线复用 | 同一组线在不同时刻承载地址、数据等不同信号 |

## 带宽计算

若总线宽度为 W bit，每个总线周期传输一次，频率为 f：

`理论带宽 = (W/8) × f × 每周期传输次数`

例如 64 bit、100 MHz、每周期一次传输：理论带宽为 `8 B × 100M = 800 MB/s`。

## 总线结构

| 结构 | 特点 |
|---|---|
| 单总线 | 成本低、连接简单，但争用严重 |
| 多总线/分层总线 | 按速度和功能分层，提高并发和可扩展性 |
| 点到点互连 | 专用链路、并发高，控制和拓扑更复杂 |

    CPU/Cache ─高速总线─ 主存控制器
                      └─ I/O桥 ─外设总线─ 设备

> [!warning]
> 理论带宽不等于有效带宽；地址阶段、握手、等待状态、仲裁、协议开销和访问模式都会降低利用率。地址总线位数决定的是可表达地址数量，还需结合编址单位求容量。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| 总线三类信号 | 数据、地址、控制 |
| 带宽计算 | 每次字节数 × 每秒传输次数 |
| 复用优缺点 | 减少引脚和线路，但需分时、锁存和额外控制 |

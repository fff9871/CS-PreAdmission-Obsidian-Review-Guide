# 超参数、学习率调度与训练诊断（★★★）

#machine-learning #deep-learning #hyperparameter-tuning #training-diagnostics

## Overview Table

| 超参数 | 主要影响 |
|---|---|
| 学习率 | 稳定性和收敛速度 |
| Batch size | 梯度噪声、吞吐、显存、BN统计 |
| Weight decay | 容量与参数尺度 |
| 深度/宽度 | 表达能力、计算与过拟合 |
| Warmup/Schedule | 初期稳定和后期收敛 |

## 诊断顺序

    verify data/labels
      → overfit a tiny batch
      → monitor train loss/metric
      → compare validation
      → inspect gradients/activations
      → tune one controlled factor

- loss 不降：检查数据、损失、梯度、冻结参数、学习率和容量。
- train 降、val 升：高方差、泄漏/分布问题或增强不一致。
- 两者震荡：学习率、batch、归一化或随机性。

## 调参原则

先粗搜数量级，再局部细化；使用验证集和固定预算，记录随机种子与配置。大规模搜索要防止对验证集反复过拟合。

> [!warning]
> “train loss不变而test loss下降说明数据100%有问题”等绝对诊断不可靠；曲线只是症状，需要结合指标定义、噪声和训练状态定位。

## Exam/Test Patterns

| 症状 | 首要排查 |
|---|---|
| 第一轮即NaN | 输入、损失、学习率、精度和梯度 |
| 小批量也拟合不了 | 实现/标签/容量错误 |
| 验证指标抖动 | 样本量、BN、随机增强和评估模式 |

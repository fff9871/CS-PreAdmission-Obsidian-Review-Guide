# 反向传播、链式法则与计算图（★★★）

#machine-learning #deep-learning #backpropagation #computational-graph

## Overview Table

| 阶段 | 作用 |
|---|---|
| Forward | 按拓扑顺序计算中间值和损失 |
| Backward | 从损失反向传播伴随梯度 |
| Chain Rule | 局部导数相乘，分支梯度相加 |
| Optimizer Step | 用参数梯度更新权重 |

## 链式法则

若 `L→z→x`，则 `∂L/∂x=(∂L/∂z)(∂z/∂x)`。计算图有多条从 x 到 L 的路径时，各路径贡献相加。

    x --f--> h --g--> L
    forward: compute x,h,L
    backward: dL/dL → dL/dh → dL/dx

反向传播是高效计算梯度的算法，不等于参数更新；优化器在梯度算出之后更新参数。

## 矩阵维度检查

对 `z=Wx+b`，`∂L/∂W=(∂L/∂z)xᵀ`，`∂L/∂x=Wᵀ(∂L/∂z)`。面试推导先标注张量形状，可避免转置错误。

> [!warning]
> 反向传播依赖前向保存的中间值；原地修改可能破坏梯度。梯度累积是求和，框架不会自动在每一步清零。

# 残差连接、退化问题与深层网络（★★★）

#machine-learning #deep-learning #residual-connections #resnet

## Overview Table

| 概念 | 含义 |
|---|---|
| 残差块 | `y=F(x)+x` |
| Shortcut | 跳过若干变换的恒等/投影路径 |
| 退化问题 | 更深网络训练误差反而更高，不只是统计过拟合 |
| Bottleneck | `1×1 → 3×3 → 1×1` 控制通道与计算 |

## 梯度路径

`∂y/∂x = ∂F/∂x + I`

恒等项为信息和梯度提供短路径，使网络可学习对输入的增量修正。维度不一致时用投影 shortcut 匹配空间或通道。

    x ───────────────┐
     → conv/norm/act → F(x) ─ + → y
                     └───────┘

残差连接支持训练更深网络，但仍需正确初始化、归一化、优化与容量控制。

> [!warning]
> 残差连接缓解优化退化和梯度传播问题，不意味着网络不会过拟合或梯度永远稳定；相加前张量形状必须兼容。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| ResNet学什么 | 残差映射F(x)，输出F(x)+x |
| 维度不同 | 1×1投影/步幅匹配shortcut |
| 退化 vs 过拟合 | 前者可连训练误差都变高，后者训练低验证高 |

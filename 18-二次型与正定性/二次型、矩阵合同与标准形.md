# 二次型、矩阵合同与标准形（★★★）

#linear-algebra #quadratic-forms

## Overview Table

| 概念 | 形式 | 保持内容 |
|---|---|---|
| 矩阵等价 | $B=PAQ$ | 秩 |
| 矩阵相似 | $B=P^{-1}AP$ | 线性算子的特征结构 |
| 矩阵合同 | $B=C^TAC$ | 二次型惯性 |

## 二次型

$n$ 元二次齐次多项式可写成

$$f(x)=x^TAx,$$

其中可唯一选取实对称矩阵 $A$：交叉项 $x_ix_j$ 的系数平均分配到 $a_{ij},a_{ji}$。

## 合同变换

作可逆线性替换 $x=Cy$：

$$f(x)=y^T(C^TAC)y.$$

因此二次型换坐标对应矩阵合同 $B=C^TAC$。

```text
原坐标 x
  x=Cy
新坐标 y
  ↓
A 变为 CᵀAC
```

## 标准形与规范形

- 标准形：只有平方项 $d_1y_1^2+\cdots+d_ny_n^2$。
- 实规范形：非零系数进一步化为 $+1$ 或 $-1$，其余为 0。

求法包括配方法与正交变换。实对称矩阵可用正交矩阵 $Q$ 化为 $Q^TAQ=\Lambda$。

> [!warning]
> 相似变换用于线性算子换基；合同变换用于二次型变量替换。两者形式与不变量不同。

## Exam/Test Patterns

| 关键词 | 回答 |
|---|---|
| “二次型是什么” | $n$ 元二次齐次多项式，可写成 $x^TAx$ |
| “合同定义” | 存在可逆 $C$ 使 $B=C^TAC$ |
| “标准形” | 消去交叉项，只保留平方项 |
| “相似与合同” | 前者描述算子换基，后者描述二次型换变量 |

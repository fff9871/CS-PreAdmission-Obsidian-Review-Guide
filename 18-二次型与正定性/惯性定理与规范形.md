# 惯性定理与规范形（★★）

#linear-algebra #quadratic-forms

## Overview Table

| 数量 | 含义 |
|---|---|
| 正惯性指数 $p$ | 规范形中 $+1$ 的个数 |
| 负惯性指数 $q$ | 规范形中 $-1$ 的个数 |
| 零指数 | 规范形中 0 的个数 |
| 秩 | $p+q$ |
| 符号差 | $p-q$ |

## Sylvester 惯性定理

实对称矩阵经任意可逆合同变换后，正、负、零平方项个数不变。因此二次型的规范形

$$y_1^2+\cdots+y_p^2-y_{p+1}^2-\cdots-y_{p+q}^2$$

中的 $p,q$ 唯一确定。

```text
不同可逆变量替换
      ↓
可能得到不同系数的标准形
      ↓ 归一化
正、负、零项数量保持不变
```

## 与特征值的关系

实对称矩阵可正交对角化，所以正、负、零惯性指数分别等于正、负、零特征值的个数。

## 合同分类

两个同阶实对称矩阵合同，当且仅当它们具有相同的正、负、零惯性指数。等价地，秩和正惯性指数相同即可确定负惯性指数。

> [!warning]
> 惯性定理讨论合同而非相似。合同不要求保持具体特征值，只保持其正负零数量。

## Exam/Test Patterns

| 关键词 | 回答 |
|---|---|
| “惯性是什么” | 二次型规范形中正、负、零平方项的个数 |
| “合同保持什么” | 正、负、零惯性指数 |
| “如何由特征值求惯性” | 数正、负、零特征值个数 |
| “两个对称矩阵何时合同” | 惯性三元组相同 |

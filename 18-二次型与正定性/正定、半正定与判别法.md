# 正定、半正定与判别法（★★★）

#linear-algebra #quadratic-forms #positive-definite

## Overview Table

设 $A$ 为实对称矩阵：

| 类型 | 二次型条件 | 特征值条件 |
|---|---|---|
| 正定 | $x^TAx>0$ 对所有 $x\ne0$ | 全部 $>0$ |
| 半正定 | $x^TAx\ge0$ | 全部 $\ge0$ |
| 负定 | $x^TAx<0$ 对所有 $x\ne0$ | 全部 $<0$ |
| 不定 | 可取正值也可取负值 | 同时有正、负特征值 |

## 正定判定

对实对称矩阵，以下等价：

- $x^TAx>0$ 对所有非零 $x$；
- 所有特征值为正；
- 所有顺序主子式 $\Delta_1,\ldots,\Delta_n$ 均为正；
- 存在可逆 $R$ 使 $A=R^TR$；
- 存在正对角 Cholesky 分解 $A=LL^T$。

## 半正定判定

对实对称矩阵：

- 半正定当且仅当所有特征值非负；
- 当且仅当所有主子式非负；
- 当且仅当存在 $B$ 使 $A=B^TB$。

```text
定义判定：xᵀAx
谱判定：看全部特征值
子式判定：正定看顺序主子式；半正定看所有主子式
分解判定：Cholesky / BᵀB
```

## 与优化的联系

二次函数 $f(x)=\frac12x^TAx-b^Tx$ 的 Hessian 为 $A$。$A$ 正定时函数严格凸并有唯一全局极小点；半正定时函数凸但极小点可能不唯一。

> [!warning]
> 定义中的 $x$ 必须非零。正定要求矩阵的对称部分正定；通常课程直接把正定矩阵限定为实对称矩阵。

## Exam/Test Patterns

| 关键词 | 回答 |
|---|---|
| “正定定义” | 对所有非零 $x$，$x^TAx>0$ |
| “怎么判断正定” | 特征值全正；或顺序主子式全正 |
| “半正定子式判据” | 所有主子式非负 |
| “几何/优化意义” | 二次型处处向上，二次函数严格凸 |

# 集合运算、幂集与笛卡尔积（★★★）

#discrete-mathematics #set-theory

## Overview Table

| 概念 | 记号 | 核心含义 |
|---|---|---|
| 子集 | $A\subseteq B$ | $A$ 的每个元素都属于 $B$ |
| 幂集 | $\mathcal P(A)$ | $A$ 的全部子集构成的集合 |
| 对称差 | $A\triangle B$ | 只属于其中一个集合的元素 |
| 笛卡尔积 | $A\times B$ | 第一分量来自 $A$、第二分量来自 $B$ 的有序对 |

## 集合与基本运算

集合中的元素具有**确定性、互异性、无序性**。常用运算包括并、交、差与补：

| 运算 | 定义 |
|---|---|
| $A\cup B$ | 属于 $A$ 或 $B$ |
| $A\cap B$ | 同时属于 $A$ 和 $B$ |
| $A-B$ | 属于 $A$ 但不属于 $B$ |
| $\bar A$ | 在全集中但不属于 $A$ |

德摩根律：

$$\overline{A\cup B}=\bar A\cap\bar B,\qquad \overline{A\cap B}=\bar A\cup\bar B.$$

## 幂集

若 $A=\{a,b\}$，则

$$\mathcal P(A)=\{\varnothing,\{a\},\{b\},\{a,b\}\}.$$

若有限集 $A$ 有 $n$ 个元素，每个元素都有“选/不选”两种状态，所以 $|\mathcal P(A)|=2^n$。

> [!important]
> $\varnothing\subseteq A$ 对任何集合成立；$\varnothing\in A$ 是否成立取决于空集是不是 $A$ 的元素。

## 对称差

$$A\triangle B=(A-B)\cup(B-A)=(A\cup B)-(A\cap B).$$

它满足交换律、结合律，且 $A\triangle A=\varnothing$、$A\triangle\varnothing=A$。

## 笛卡尔积

$$A\times B=\{(a,b)\mid a\in A,b\in B\}.$$

若 $|A|=m,|B|=n$，则 $|A\times B|=mn$。有序对强调位置，因此一般 $A\times B\ne B\times A$。

```text
A 的元素 ─┐
           ├─ 按顺序配对 ─> (a,b) ─> A×B
B 的元素 ─┘
```

## Exam/Test Patterns

| 题型关键词 | 回答 |
|---|---|
| “幂集有多少元素” | 原集合有 $n$ 个元素，幂集有 $2^n$ 个元素 |
| “对称差” | 只在一个集合中，写成 $(A-B)\cup(B-A)$ |
| “笛卡尔积是否交换” | 一般不交换，因为有序对的分量位置不同 |
| “空集属于还是包含” | 空集是任何集合的子集，但未必是其元素 |

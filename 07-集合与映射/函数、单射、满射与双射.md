# 函数、单射、满射与双射（★★★）

#discrete-mathematics #set-theory #functions

## Overview Table

| 类型 | 输入约束 | 输出覆盖 | 反函数 |
|---|---|---|---|
| 一般函数 | 每个输入恰有一个输出 | 不要求 | 通常没有 |
| 单射 | 不同输入对应不同输出 | 不要求覆盖陪域 | 在像集上可逆 |
| 满射 | 允许不同输入同输出 | 覆盖整个陪域 | 不一定 |
| 双射 | 不同输入不同输出 | 覆盖整个陪域 | 存在 |

## 函数是特殊关系

函数 $f:A\to B$ 是 $A\times B$ 的一个子集，并满足：

1. 对每个 $x\in A$，至少有一个 $y\in B$ 使 $(x,y)\in f$；
2. 对每个 $x\in A$，至多有一个这样的 $y$。

因此每个定义域元素都**恰好**对应一个输出。$B$ 是陪域，实际输出构成像集 $f(A)$，二者不要混淆。

## 单射、满射与双射

$$
\begin{aligned}
\text{单射：}&\quad f(x_1)=f(x_2)\Rightarrow x_1=x_2;\\
\text{满射：}&\quad \forall y\in B,\exists x\in A, f(x)=y;\\
\text{双射：}&\quad \text{单射且满射}.
\end{aligned}
$$

```text
单射：A 中的箭头不碰撞
满射：B 中没有元素落空
双射：既不碰撞，也不落空
```

## 复合与逆函数

若 $f:A\to B,g:B\to C$，则 $(g\circ f)(x)=g(f(x))$。

| 已知 | 可推出 |
|---|---|
| $f,g$ 都单射 | $g\circ f$ 单射 |
| $f,g$ 都满射 | $g\circ f$ 满射 |
| $g\circ f$ 单射 | $f$ 必单射，$g$ 未必 |
| $g\circ f$ 满射 | $g$ 必满射，$f$ 未必 |

函数存在双侧反函数，当且仅当它是双射。

> [!warning]
> 判断满射必须先明确陪域。同一个表达式在不同陪域下，满射性可能不同。

## Exam/Test Patterns

| 题型关键词 | 回答 |
|---|---|
| “一一对应” | 双射 |
| “证明单射” | 从 $f(x_1)=f(x_2)$ 推出 $x_1=x_2$ |
| “证明满射” | 任取陪域元素 $y$，构造原像 $x$ |
| “为什么能比较集合大小” | 构造双射；双射说明两集合等势 |

# 卷积输出尺寸、参数量与计算量（★★★）

#machine-learning #computer-vision #convolution #model-complexity

## Overview Table

| 量 | 公式 |
|---|---|
| 输出高 | `⌊(H+2P-D(K-1)-1)/S⌋+1` |
| 输出宽 | 同理替换 W |
| 参数量 | `Cout×(Cin/G)×Kh×Kw + (bias?Cout:0)` |
| MACs | `Hout×Wout×Cout×(Cin/G)×Kh×Kw` |

## SAME 与 VALID

- VALID：不填充，尺寸通常缩小。
- SAME：按实现选择 padding，使 `S=1` 时输出尺寸接近输入；偶数核或步幅>1时左右填充可能不对称。

## 形状推导顺序

    N unchanged
    C → out_channels
    H/W → apply kernel, dilation, padding, stride formula

计算网络形状时逐层记录 `[N,C,H,W]`，池化和卷积分别更新空间尺寸；flatten 前必须用实际输出形状。

> [!warning]
> FLOPs 与 MACs 的计数约定可能差一倍；参数量不随输入 H/W 增长，但计算量会随输出空间面积增长。

## Exam/Test Patterns

| 题型 | 检查 |
|---|---|
| dilation | 有效核 `D(K-1)+1` |
| groups | 参数和计算除以 G |
| bias | 每个输出通道一个偏置 |

# 感受野与空洞卷积（★★★）

#machine-learning #computer-vision #receptive-field #dilated-convolution

## Overview Table

| 量 | 递推 |
|---|---|
| jump `j_l` | `j_l=j_{l-1}s_l` |
| receptive field `r_l` | `r_l=r_{l-1}+(k_eff-1)j_{l-1}` |
| effective kernel | `k_eff=d_l(k_l-1)+1` |

初始 `r_0=1, j_0=1`。步幅/池化会扩大后续一格在输入中的跳距，空洞率增大有效核但不增加核参数数目。

## 空洞卷积

    dilation=1: x x x
    dilation=2: x . x . x

优点是保持特征图分辨率的同时扩大感受野，适合分割和多尺度上下文；重复相同 dilation 可能产生网格效应。

## 理论与有效感受野

理论感受野按结构计算；实际梯度影响往往集中在中心区域，称有效感受野，受权重和训练影响。

> [!warning]
> 空洞卷积“不增加参数”不等于“不增加任何成本”，访存和实现效率仍可能变化；更大感受野也不保证更适合小目标。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| 3×3 dilation2有效核 | 5×5 |
| 扩大感受野不降采样 | 空洞卷积 |
| 网格效应 | 混合/递增dilation、多尺度设计 |

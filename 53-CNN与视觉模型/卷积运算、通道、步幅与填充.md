# 卷积运算、通道、步幅与填充（★★★）

#machine-learning #computer-vision #convolution #cnn

## Overview Table

| 参数 | 作用 |
|---|---|
| `in_channels` | 输入特征图通道数 |
| `out_channels` | 卷积核组数/输出通道数 |
| kernel size K | 局部感受区域 |
| stride S | 滑动步长，控制下采样 |
| padding P | 边界填充，控制尺寸与边缘信息 |
| dilation D | 核元素间隔，扩大感受野 |
| groups G | 通道分组连接方式 |

## 多通道卷积

每个输出通道对应一个形状 `[C_in,K_h,K_w]` 的卷积核，对所有输入通道分别相关运算后求和并加偏置。

    input [N,Cin,H,W]
      → weight [Cout,Cin/G,Kh,Kw]
      → output [N,Cout,Hout,Wout]

深度学习库中的“卷积”通常实现互相关，不翻转卷积核；参数通过训练学习，因此命名差异不影响模型表达。

> [!warning]
> 卷积核的空间尺寸 K×K 与通道数是不同维度；输出通道数等于卷积核组数，不由输入通道数自动决定。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| 单个卷积核深度 | `Cin/groups` |
| 输出通道 | `Cout`/卷积核个数 |
| stride增大 | 空间尺寸下降、采样更稀疏 |

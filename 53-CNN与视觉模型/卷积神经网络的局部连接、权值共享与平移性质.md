# 卷积神经网络的局部连接、权值共享与平移性质（★★★）

#machine-learning #computer-vision #cnn #translation-equivariance

## Overview Table

| 归纳偏置 | 作用 |
|---|---|
| 局部连接 | 聚焦邻域模式，减少参数 |
| 权值共享 | 同一检测器扫描不同位置 |
| 层次表示 | 边缘→纹理→部件→语义 |
| 平移等变 | 输入平移时特征图相应平移（理想条件） |

## 等变与不变

卷积近似满足 `f(Tx)=Tf(x)` 的平移等变；池化/GAP、数据增强和任务头可增强一定平移不变性。

    image → local filters → feature maps
          → deeper combinations → semantic features

边界填充、步幅、下采样和有限图像会破坏严格等变；旋转、尺度变化也不由普通卷积天然解决。

## 参数优势

全连接层参数与输入空间位置数量相乘；卷积核在位置间共享，使参数量只依通道和核大小，但计算仍随空间分辨率增长。

> [!warning]
> CNN 不是对所有平移“完全不变”，更准确是卷积的平移等变和聚合带来的近似不变；权值共享也可能限制位置特异模式。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| 参数少原因 | 局部连接 + 权值共享 |
| 特征层次 | 低层局部到高层语义组合 |
| 平移性质 | 卷积等变，池化/聚合近似不变 |

# 定点运算、溢出与ALU（★★★）

#computer-organization #data-representation #fixed-point #overflow #alu

## Overview Table

| 运算/标志 | 判断 |
|---|---|
| 补码加减 | 减法转成加上减数的补码负值 |
| 有符号溢出 | 同号相加结果异号，或异号相减结果符号异常 |
| 无符号溢出 | 看最高位进位/借位语义 |
| CF | 常反映无符号进位/借位 |
| OF | 反映有符号结果超出范围 |
| ZF/SF | 结果为零/结果符号 |

## 加法器与 ALU

ALU 执行加减、逻辑、移位和比较。减法 `A-B` 可转化为 `A + (~B + 1)`，从而复用加法器。串行进位加法器结构简单但延迟随位数增长；超前进位利用生成/传递信号并行计算进位。

    A ─────────┐
               ├─ 加法器/逻辑阵列 → Result + Flags
    B → 可选取反┘
        Cin=1 完成减法

## 溢出判断

补码加法中：

- 两个正数相加得到负数：正溢出。
- 两个负数相加得到非负数：负溢出。
- 异号相加不会发生有符号溢出。

也可用“符号位的进位与最高数值位的进位异或”判断 OF。

> [!warning]
> CF 与 OF 面向不同解释：同一比特结果可能对无符号数溢出、对有符号数不溢出，反之亦然。必须先明确数据类型。

## Exam/Test Patterns

| 场景 | 回答 |
|---|---|
| 补码减法 | 对减数按位取反加一，再做加法 |
| 同号相加结果异号 | 有符号溢出 |
| 比较大小 | 有符号比较与无符号比较使用的标志组合不同 |

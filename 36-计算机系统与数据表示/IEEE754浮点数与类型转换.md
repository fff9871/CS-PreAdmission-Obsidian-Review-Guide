# IEEE754浮点数与类型转换（★★★）

#computer-organization #data-representation #ieee-754 #floating-point

## Overview Table

| 格式 | 符号位 | 阶码位 | 尾数位 | 偏置 |
|---|---:|---:|---:|---:|
| 单精度 binary32 | 1 | 8 | 23 | 127 |
| 双精度 binary64 | 1 | 11 | 52 | 1023 |

## 规格化数

`value = (-1)^S × (1.F) × 2^(E-bias)`

转换步骤：

1. 将绝对值写成二进制科学计数法 `1.F × 2^e`。
2. 阶码存 `E=e+bias`。
3. 尾数字段保存小数点后的 F，隐含最高位 1。
4. 按舍入模式处理超出尾数精度的部分。

## 特殊值

| E | F | 含义 |
|---|---|---|
| 全 0 | 全 0 | `+0/-0` |
| 全 0 | 非 0 | 非规格化数 |
| 非全 0/1 | 任意 | 规格化数 |
| 全 1 | 全 0 | `+∞/-∞` |
| 全 1 | 非 0 | NaN |

## 类型转换

- `int → float` 可能因有效位不足而舍入，即使范围足够。
- `float → double` 通常精确保存已有二进制值。
- `double → float` 可能舍入或溢出。
- 浮点转整数会丢弃小数部分，并可能超出目标范围。

> [!warning]
> 十进制小数如 0.1 通常不能用有限二进制精确表示，因此浮点比较不宜机械使用 `==`；应结合误差容限和数值尺度。

## Exam/Test Patterns

| 问法 | 回答步骤 |
|---|---|
| 求 IEEE754 编码 | 符号→二进制规格化→加偏置→截取并舍入尾数 |
| E 全 0/1 | 先判断零、非规格化、无穷或 NaN |
| int 转 float | 关注 float 有效精度约 24 bit，可能舍入 |

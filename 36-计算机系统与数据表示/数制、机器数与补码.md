# 数制、机器数与补码（★★★）

#computer-organization #data-representation #complement

## Overview Table

| 编码 | 正数 | 负数 | 零 | 特点 |
|---|---|---|---|---|
| 原码 | 符号位 0，数值位为绝对值 | 符号位 1，数值位为绝对值 | `+0/-0` 两种 | 直观，运算复杂 |
| 反码 | 与原码相同 | 数值位逐位取反 | 两种零 | 加法需循环进位 |
| 补码 | 与原码相同 | 反码加 1 | 唯一零 | 加减统一，硬件简单 |
| 无符号 | 全部位表示大小 | 不表示负数 | 唯一零 | n 位范围 `0..2ⁿ-1` |

## 为什么数字计算机普遍使用二进制

- 两种稳定电平易由开关器件实现，噪声容限较大。
- 二值逻辑可直接对应布尔代数，逻辑门和存储单元规则。
- 编码、传输与检错电路容易标准化。

二进制不是数学上唯一选择，而是在器件可靠性、成本和逻辑设计之间形成的工程方案。

## n 位范围

- 原码/反码：`-(2^(n-1)-1) .. +(2^(n-1)-1)`。
- 补码：`-2^(n-1) .. 2^(n-1)-1`。
- 补码最低负数没有对应的正数，取绝对值时需特别处理。

## 补码求值与扩展

n 位补码最高位权值为 `-2^(n-1)`，其余位按正权相加。符号扩展时复制最高位，可保持数值；无符号扩展时在高位补 0。

    8位补码 1111 1011
    = -128 + 64+32+16+8+2+1 = -5

> [!warning]
> “负数补码按位取反加一”只是在固定字长下从绝对值求编码的操作方法。做位宽转换或解释十六进制时，必须先明确有符号性和字长。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| n 位补码范围 | `[-2^(n-1), 2^(n-1)-1]` |
| 补码转真值 | 最高位按负权，其余按正权相加 |
| 符号扩展 | 高位复制符号位 |

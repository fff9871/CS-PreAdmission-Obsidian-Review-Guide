# 顺序表与链表（★★★）

#data-structures #linear-lists

## Overview Table

| 操作 | 顺序表 | 单链表 |
|---|---:|---:|
| 按下标访问 | $O(1)$ | $O(n)$ |
| 按值查找（无序） | $O(n)$ | $O(n)$ |
| 已知位置后插删 | 平均 $O(n)$ | $O(1)$ |
| 空间 | 连续，无指针域 | 分散，有指针域 |
| 缓存局部性 | 好 | 通常较差 |

## 链表变体

| 类型 | 结构 | 优势 |
|---|---|---|
| 单链表 | `data + next` | 实现简单、空间开销小 |
| 双向链表 | `prev + data + next` | 已知结点可向两侧移动和删除 |
| 循环链表 | 尾指针回到表头 | 适合循环调度和从任意点遍历 |
| 静态链表 | 数组中以游标代替指针 | 无指针环境中模拟链接 |

## 头指针与头结点

- **头指针**：指向首结点或头结点的指针变量，是访问链表的入口。
- **头结点**：不存普通元素的哨兵结点，用来统一空表和首元结点的插删。

```text
head → [sentinel] → [a] → [b] → null
        头结点       数据结点
```

> [!warning]
> 数组中间位置的插入需要移动元素；动态数组尾插的单次最坏可为 $O(n)$，但按几何倍增长时摊还为 $O(1)$。

## Exam/Test Patterns

| 场景 | 结论 |
|---|---|
| 频繁按下标读取 | 优先顺序表 |
| 频繁在已知结点附近插删 | 优先链表 |
| 删除双链表结点 | 同时改前驱的 `next` 和后继的 `prev` |
| 循环链表终止 | 回到起点，而不是遇到 `null` |

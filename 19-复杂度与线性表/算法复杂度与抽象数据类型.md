# 算法复杂度与抽象数据类型（★★★）

#data-structures #complexity

## Overview Table

| 概念 | 核心问题 | 常用表达 |
|---|---|---|
| ADT | 数据是什么、支持什么操作 | 数据对象+关系+操作 |
| 时间复杂度 | 基本操作随规模如何增长 | $T(n)=O(f(n))$ |
| 空间复杂度 | 额外存储如何增长 | $S(n)=O(g(n))$ |
| 摊还复杂度 | 一串操作的平均代价 | 动态数组扩容为例 |

## 渐进记号

- $O(g(n))$：渐进上界，常用于描述最坏情况数量级，但 **$O$ 本身不等于“最坏情况”**。
- $\Omega(g(n))$：渐进下界；$\Theta(g(n))$：同时有上下界。
- 只保留增长最快的项，并忽略常数系数。

```text
确定问题规模 n
        ↓
选择基本操作
        ↓
统计执行次数 T(n)
        ↓
取渐近紧界并说明最好/平均/最坏情形
```

## 常见数量级

| 从快到慢 | 典型场景 |
|---|---|
| $O(1)$ | 数组按下标访问 |
| $O(\log n)$ | 二分查找、平衡树查找 |
| $O(n)$ | 线性扫描 |
| $O(n\log n)$ | 归并、堆排序、平均快排 |
| $O(n^2)$ | 朴素两层枚举、简单排序 |

> [!warning]
> 递归程序的额外空间通常要计算调用栈；“原地算法”通常指辅助空间为 $O(1)$。

## Exam/Test Patterns

| 提问 | 回答骨架 |
|---|---|
| “大 O 是什么” | 给出存在 $c,n_0$ 的渐进上界定义 |
| “时间换空间” | 说明哈希、缓存或预处理的代价 |
| “ADT 与存储结构” | ADT 规定逻辑和操作，存储结构是实现 |

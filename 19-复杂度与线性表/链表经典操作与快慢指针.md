# 链表经典操作与快慢指针（★★★）

#data-structures #linear-lists #two-pointers

## Overview Table

| 问题 | 关键不变量 | 复杂度 |
|---|---|---|
| 原地逆置 | `prev` 是已逆置部分，`cur` 是待处理部分 | $O(n)$ / $O(1)$ |
| 倒数第 $k$ 个 | 快指针始终领先 $k$ 步 | $O(n)$ / $O(1)$ |
| 中点 | 快指针每次两步，慢指针一步 | $O(n)$ / $O(1)$ |
| 判环 | 有环时快慢指针必相遇 | $O(n)$ / $O(1)$ |

## 原地逆置

```text
prev ← cur    next
null    a   →   b → c

每轮：next=cur.next → cur.next=prev → prev=cur → cur=next
```

## Floyd 判环与环入口

1. `slow` 走一步，`fast` 走两步；若相遇则有环。
2. 相遇后，一个指针回到头结点，两者每次各走一步。
3. 再次相遇的位置就是环入口。

> [!important]
> 处理指针前先保存后继；否则一旦改写 `next`，未处理链可能丢失。

> [!warning]
> “倒数第 $k$ 个”中 $k$ 是从 1 还是从 0 计数必须先约定；同时要处理 $k$ 超过链长的情况。

## Exam/Test Patterns

| 提问 | 答题关键 |
|---|---|
| “$O(1)$ 空间逆置” | 三指针并保存 `next` |
| “链表有环吗” | Floyd 快慢指针，不需哈希集合 |
| “删除结点” | 先考虑头结点、尾结点和空表 |

# 指令周期、机器周期与时钟周期（★★★）

#computer-organization #cpu #instruction-cycle

## Overview Table

| 周期 | 含义 | 包含关系 |
|---|---|---|
| 时钟周期 | CPU 最基本节拍 | 一个机器周期含一个或多个时钟周期 |
| 机器周期 | 完成一个相对完整子操作，如一次访存 | 一个指令周期含一个或多个机器周期 |
| 指令周期 | 取出并执行一条指令的总时间 | 随指令类型变化 |
| 中断周期 | 检查/响应中断并保存断点 | 常在指令结束边界进入 |

## 典型指令流程

    取指: PC→MAR, Mem→MDR→IR, PC更新
      ↓
    译码: 操作码译码、读取寄存器
      ↓
    执行: ALU运算/形成有效地址/分支判断
      ↓
    访存: Load/Store需要
      ↓
    写回: 结果写寄存器
      ↓
    检查中断

不同指令可跳过某些阶段；流水线 CPU 让多条指令的不同阶段重叠，而不是让单条指令不再经过这些逻辑功能。

> [!warning]
> “机器周期”在不同教材和处理器中定义并不完全一致。回答时应先说明它是完成一个基本操作所需的若干时钟周期，并结合所用模型解释。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| 三种周期大小 | 指令周期通常最大，机器周期居中，时钟周期最小 |
| 取指数据流 | `PC→MAR→主存→MDR→IR`，同时形成下一 PC |
| 中断何时响应 | 一般在现行指令执行结束后检查并响应可屏蔽中断 |

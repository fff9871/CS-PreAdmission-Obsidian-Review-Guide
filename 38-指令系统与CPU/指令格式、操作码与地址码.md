# 指令格式、操作码与地址码（★★★）

#computer-organization #instruction-set #instruction-format

## Overview Table

| 字段 | 作用 |
|---|---|
| 操作码 Opcode | 指定执行何种操作 |
| 地址码/寄存器字段 | 指定操作数位置或目的位置 |
| 立即数字段 | 指令内直接携带常数 |
| 寻址方式字段 | 指示如何形成有效地址 |
| 功能码 | 在主操作码下进一步区分操作 |

## 定长与变长指令

| 形式 | 优点 | 代价 |
|---|---|---|
| 定长 | 取指、对齐和译码简单，利于流水线 | 编码密度可能较低 |
| 变长 | 可按操作复杂度编码，密度高 | 边界识别和译码更复杂 |

操作码位数与可表示操作种类、地址字段数量和指令长度相互制约。扩展操作码可把某些地址字段组合用作更多操作码，提高编码利用率。

## 地址数目

| 类型 | 示例语义 |
|---|---|
| 三地址 | `R3 ← R1 op R2` |
| 二地址 | `R1 ← R1 op R2` |
| 一地址 | 累加器隐含为一个操作数 |
| 零地址 | 栈顶元素隐含作为操作数 |

> [!warning]
> 指令中的“地址”不一定是主存物理地址，也可能是寄存器编号、立即数或位移。ISA 指令格式与机器内部微操作格式也不是同一层次。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| 操作码位数增加 | 可编码操作更多，但挤占操作数字段或增加指令长度 |
| 定长为何利于流水 | PC 更新、取指对齐和并行译码更规则 |
| 零地址指令 | 操作数隐含在栈顶 |

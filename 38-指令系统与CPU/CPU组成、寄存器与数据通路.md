# CPU组成、寄存器与数据通路（★★★）

#computer-organization #cpu #registers #datapath

## Overview Table

| 部件/寄存器 | 作用 |
|---|---|
| ALU | 算术、逻辑、移位和比较 |
| 控制单元 | 译码并产生时序控制信号 |
| 通用寄存器 | 保存操作数和中间结果 |
| PC | 保存下一条指令地址 |
| IR | 保存当前指令 |
| MAR | 保存待访问主存地址 |
| MDR | 暂存主存读出/写入数据 |
| 状态寄存器 | 保存条件码、特权级、中断使能等状态 |

## 数据通路

    PC → 指令存储器 → IR/译码 → 寄存器堆
                              ↓          ↓
                           控制信号 → ALU → 数据存储器 → 写回

数据通路由寄存器、ALU、多路选择器和互连组成；控制器根据指令和状态选择数据来源、运算功能、写使能与下一 PC。

## CPU 的功能

- 指令控制：保证程序规定的执行顺序。
- 操作控制：产生微操作控制信号。
- 时间控制：按节拍组织动作。
- 数据加工：完成算术逻辑处理。
- 中断处理：保存断点并转入服务程序。

> [!warning]
> MAR/MDR 是教学模型中的典型寄存器，现代实现可能没有一一对应、程序员可见的实体。ISA 可见寄存器与微体系结构内部寄存器也应区分。

## Exam/Test Patterns

| 问法 | 回答路径 |
|---|---|
| CPU 由什么组成 | 运算器、控制器、寄存器/数据通路，并说明功能 |
| PC 与 IR | PC 指向下一条，IR 保存当前指令 |
| 控制器作用 | 译码、时序和控制信号，不直接完成主要数据运算 |

# 寻址方式与有效地址计算（★★★）

#computer-organization #instruction-set #addressing-modes

## Overview Table

| 寻址方式 | 操作数/有效地址 EA | 特点 |
|---|---|---|
| 立即 | 操作数在指令中 | 快，范围受字段长度限制 |
| 寄存器 | 操作数在寄存器 | 快，寄存器数量有限 |
| 直接 | `EA=A` | 一次主存访数，地址范围受字段限制 |
| 间接 | `EA=(A)` | 地址范围大，多一次或多次访存 |
| 寄存器间接 | `EA=(R)` | 地址在寄存器，常用于指针 |
| 基址/变址 | `EA=(Base/Index)+Disp` | 数组、结构体、重定位 |
| 相对 | `EA=(PC)+Disp` | 分支和位置无关代码 |
| 隐含 | 操作数由操作码约定 | 指令短，如累加器/栈操作 |

## 有效地址形成

    指令地址字段 A
      + 基址寄存器 / 变址寄存器 / PC
      = 有效地址 EA
      ↓
    访问寄存器或主存取得操作数

基址寄存器通常保存程序/段/对象起点，位移选择其中成员；变址寄存器常保存数组下标。实际 ISA 命名可能不同，答题应以公式和用途说明。

## MIPS 的典型方式

MIPS load/store 指令使用 `base + sign-extended offset`；分支常使用 PC 相对位移；跳转指令编码目标的一部分；算术操作数主要来自寄存器或立即数。

> [!warning]
> 有效地址是执行寻址计算得到的逻辑/虚拟地址，之后可能还要经过 MMU 页表转换。不要把“寻址方式”与“虚拟地址到物理地址翻译”混为一谈。

## Exam/Test Patterns

| 场景 | 回答 |
|---|---|
| 数组遍历 | 基址/变址加位移 |
| 分支目标 | 常用 PC 相对寻址 |
| 指针间接访问 | 寄存器间接或带位移的基址寻址 |

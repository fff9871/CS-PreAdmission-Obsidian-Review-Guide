# 线性回归与最小二乘法（★★★）

#machine-learning #linear-models #linear-regression #least-squares

## Overview Table

| 项目 | 形式 |
|---|---|
| 模型 | `ŷ = wᵀx + b` |
| 平方损失 | `J(w)=Σ(y_i-ŷ_i)²` |
| 矩阵解 | `w=(XᵀX)⁻¹Xᵀy`（可逆时） |
| 稳健求解 | QR、SVD、带正则的线性系统 |

## 几何与概率解释

最小二乘把 `y` 投影到设计矩阵列空间；残差与该空间正交。若噪声独立同分布且为零均值高斯，最小化平方误差等价于最大化似然。

    Xw ≈ y
    residual r = y-Xw
    normal equation: Xᵀr = 0

## 条件与问题

多重共线性使 `XᵀX` 病态、参数方差大；异常值会被平方损失放大。可用标准化、特征选择、岭回归、稳健损失或 SVD 求解。

> [!warning]
> 经典最小二乘最小化的是目标方向残差平方，不是样本到直线的欧氏垂直距离。直接求逆通常不如解线性方程、QR 或 SVD 稳定。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| 闭式解条件 | `XᵀX` 可逆；一般用伪逆/正则处理 |
| 高斯噪声 | MSE 与最大似然对应 |
| 共线性 | 参数不稳定，可用 L2/降维 |

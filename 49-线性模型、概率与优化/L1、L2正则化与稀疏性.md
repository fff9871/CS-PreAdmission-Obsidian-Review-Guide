# L1、L2正则化与稀疏性（★★★）

#machine-learning #linear-models #regularization #sparsity

## Overview Table

| 正则 | 惩罚 | 几何/效果 |
|---|---|---|
| L1/Lasso | `λΣ|w_j|` | 非光滑，常产生精确零权重 |
| L2/Ridge | `λΣw_j²` | 平滑收缩权重，缓解共线性 |
| Elastic Net | `λ1||w||1+λ2||w||2²` | 兼顾稀疏和稳定 |

## 为什么 L1 稀疏

L1 约束区域有尖角，损失等高线较容易在坐标轴处相切；优化上零点存在非光滑阈值效应。L2 的圆滑约束通常把权重缩小但不精确置零。

    objective = data loss + λ × complexity penalty

`λ` 越大通常模型越简单、偏差增大、方差下降。正则强度必须在验证集选择，且尺度敏感模型需先标准化特征。

> [!warning]
> L1 稀疏是常见结果而非任何优化器/数据下的绝对保证；神经网络中的 weight decay 与数学 L2 在自适应优化器中可能不完全等价。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| 特征选择倾向 | L1 |
| 缓解共线性 | L2 |
| λ 过大 | 高偏差/欠拟合 |

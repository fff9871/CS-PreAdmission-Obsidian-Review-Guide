# 工作集、驻留集与抖动（★★★）

#operating-systems #memory-management #virtual-memory #working-set #thrashing

## Overview Table

| 概念 | 含义 |
|---|---|
| 驻留集 | 某进程当前在物理内存中的页面集合 |
| 工作集 `W(t,Δ)` | 最近 Δ 个引用/时间窗口访问过的页面集合 |
| 抖动 | 系统大量时间用于换页而非有效执行 |
| PFF | 依据缺页频率动态调节分配页框 |

## 抖动形成

    多道程度上升
       → 每进程页框不足
       → 缺页频繁、I/O 增加
       → CPU 利用率下降
       → 系统误判并继续接纳任务
       → 更严重抖动

工作集模型尝试让每个进程的活跃局部性驻留；若所有工作集总和超过物理页框，应降低多道程度或挂起进程。

## 全局与局部置换

全局置换可从其他进程夺取页框，吞吐弹性大但进程互相干扰；局部置换只在自身驻留集中替换，隔离较强但分配不合适时难自适应。

> [!warning]
> CPU 利用率低不一定意味着应增加并发：若原因是抖动，增加进程会恶化。工作集窗口过小遗漏局部性，过大又包含多个阶段。

## Exam/Test Patterns

| 现象 | 诊断/措施 |
|---|---|
| 缺页率过高 | 增加页框或减少并发 |
| 活跃页总量超过内存 | 挂起部分进程 |
| 进程相互抢页 | 评估局部置换或工作集控制 |

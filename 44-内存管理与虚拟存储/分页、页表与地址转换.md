# 分页、页表与地址转换（★★★）

#operating-systems #memory-management #paging #page-table

## Overview Table

| 单位 | 所属 | 大小 |
|---|---|---|
| 页 page | 虚拟地址空间 | 固定大小 |
| 页框 frame | 物理内存 | 与页相同大小 |
| 页表项 PTE | 地址转换元数据 | 页框号、有效/权限/脏/访问位等 |

## 地址转换

设页大小为 `2^p` 字节：

    VA = [ virtual page number | page offset(p bits) ]
                 ↓ page table
    PA = [ physical frame number | same offset ]

`页号 = VA // 页大小`，`页内偏移 = VA mod 页大小`，物理地址 `= 页框号×页大小+偏移`。

## 页表项状态

有效/存在位表示映射是否可用；R/W/X 和用户/内核位执行保护；访问位帮助置换；脏位表示换出前是否需写回。写时复制常把共享页设为只读，在写保护异常时复制。

> [!warning]
> 页表位布局由架构定义；“有效位为 0”可能代表未映射、已换出或其他软件状态。分页消除外部碎片，但最后一页可能有内部碎片，页表本身也占空间。

## Exam/Test Patterns

| 题型 | 方法 |
|---|---|
| 求页号/偏移 | 整除与取模，页大小为 2 的幂时切位 |
| 求物理地址 | 页表取页框号，拼接原偏移 |
| 权限错误 | 映射存在也可能触发保护异常 |

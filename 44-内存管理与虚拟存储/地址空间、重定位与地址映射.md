# 地址空间、重定位与地址映射（★★★）

#operating-systems #memory-management #address-space #relocation

## Overview Table

| 地址 | 含义 |
|---|---|
| 符号地址 | 源程序中的名字或标签 |
| 逻辑/虚拟地址 | CPU 执行程序时产生的进程地址 |
| 线性地址 | 分段之后、分页之前的地址（部分架构术语） |
| 物理地址 | 主存硬件最终访问的地址 |

## 绑定与重定位

| 时机 | 特点 |
|---|---|
| 编译时 | 装入位置已知，生成绝对地址 |
| 装入时 | 装载器按实际起址修正可重定位地址 |
| 运行时 | MMU 动态转换，可在执行期间移动/换入 |

    source symbol → compiler/linker → virtual address
                                      ↓ MMU/page table
                                  physical address

地址空间让每个进程看到近似独立、连续的布局；保护位、基址界限或页表权限决定可访问范围。

> [!warning]
> 逻辑地址、线性地址和虚拟地址在不同教材/架构中可能同义或分层使用。答题先说明语境；地址转换不等于把所有数据立即复制到物理内存。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| 动态重定位 | 运行时由硬件映射逻辑地址到物理地址 |
| 地址空间价值 | 隔离、保护、共享和灵活装入 |
| MMU | 执行地址转换并检查权限的硬件 |

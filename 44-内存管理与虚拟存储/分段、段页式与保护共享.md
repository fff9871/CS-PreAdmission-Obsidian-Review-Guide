# 分段、段页式与保护共享（★★★）

#operating-systems #memory-management #segmentation #segmented-paging

## Overview Table

| 机制 | 地址形式 | 优点 | 代价 |
|---|---|---|---|
| 分页 | 页号 + 页内偏移 | 定长、便于物理分配 | 逻辑结构不直接可见 |
| 分段 | 段号 + 段内偏移 | 贴合代码/数据模块，便于保护共享 | 外部碎片、段长不一 |
| 段页式 | 段号 + 页号 + 偏移 | 兼顾逻辑分段与页式分配 | 转换层次和表空间增加 |

## 分段转换

段表项含基址、界限和权限。若 `offset < limit`，物理地址 `= base + offset`；否则越界异常。

    selector/segment → 段表：base + limit + permission
                               ↓
                         linear address
                               ↓ paging
                         physical address

共享库可让多个进程的不同虚拟段/页映射到同一只读物理页；私有写通过写时复制延迟创建副本。

> [!warning]
> 分段与“程序源代码分段”不是一回事。现代 64 位通用系统可能弱化传统硬件分段，但逻辑区域与页级保护仍存在。

## Exam/Test Patterns

| 比较 | 分页 | 分段 |
|---|---|---|
| 大小 | 固定 | 可变 |
| 可见性 | 通常对程序员透明 | 反映逻辑模块 |
| 碎片 | 内部 | 外部 |

# 条件概率、全概率与贝叶斯（★★★）

#probability #probability-basics

## Overview Table

| 概念 | 已知 | 所求 | 核心动作 |
|---|---|---|---|
| 条件概率 | $B$ 已发生 | $A$ 的概率 | 缩小样本空间 |
| 联合概率 | 两个事件 | 同时发生 | 使用乘法公式 |
| 全概率 | 多种原因 | 结果概率 | 分路径求和 |
| 贝叶斯 | 已观察结果 | 原因概率 | 反向更新 |
| 先验/后验 | 数据前/数据后 | 信念变化 | 似然修正先验 |

## 条件概率与乘法公式

当 $P(B)>0$ 时：

$$P(A\mid B)=\frac{P(A\cap B)}{P(B)}$$

等价地：

$$P(A\cap B)=P(A\mid B)P(B)=P(B\mid A)P(A)$$

> [!tip]
> $P(A\mid B)$ 中竖线右边是已经知道的条件，不能与 $P(B\mid A)$ 交换。

## 联合、边缘与条件概率

| 类型 | 离散形式 | 连续形式 |
|---|---|---|
| 联合 | $p_{X,Y}(x,y)$ | $f_{X,Y}(x,y)$ |
| 边缘 | $p_X(x)=\sum_yp_{X,Y}(x,y)$ | $f_X(x)=\int f_{X,Y}(x,y)dy$ |
| 条件 | $p_{X\mid Y}(x\mid y)=p_{X,Y}(x,y)/p_Y(y)$ | $f_{X\mid Y}(x\mid y)=f_{X,Y}(x,y)/f_Y(y)$ |

边缘化的本质是把不关心的变量“求和或积分消去”。边缘概率并不自动意味着变量独立。

## 全概率公式

若 $B_1,\ldots,B_n$ 构成样本空间的一个划分：

- $B_i\cap B_j=\varnothing$，$i\ne j$；
- $\bigcup_iB_i=\Omega$；
- $P(B_i)>0$；

则：

$$P(A)=\sum_{i=1}^nP(A\mid B_i)P(B_i)$$

```text
原因 B1 --P(A|B1)--\
原因 B2 --P(A|B2)----> 结果 A：各路径概率相加
原因 Bn --P(A|Bn)--/
```

## 贝叶斯公式

$$P(B_i\mid A)=
\frac{P(A\mid B_i)P(B_i)}
{\sum_jP(A\mid B_j)P(B_j)}$$

记忆方式：

$$\text{后验}=\frac{\text{似然}\times\text{先验}}{\text{证据}}$$

```text
先验 P(Bi)
     × 似然 P(A|Bi)
     ↓
未归一化后验
     ÷ 证据 P(A)
     ↓
后验 P(Bi|A)
```

## 数值例子：检测阳性

患病率为 $1\%$，灵敏度为 $99\%$，假阳性率为 $5\%$：

$$P(D\mid +)=\frac{0.99\times0.01}{0.99\times0.01+0.05\times0.99}\approx16.7\%$$

关键原因是基础患病率很低，这称为**基础率效应**。

## 先验、似然与后验

| 名称 | 含义 | 是否随当前数据变化 |
|---|---|---|
| 先验 $P(\theta)$ | 观察数据前对参数的认识 | 否 |
| 似然 $P(D\mid\theta)$ | 给定参数时观察到数据的可能性 | 是 |
| 后验 $P(\theta\mid D)$ | 结合数据后的参数认识 | 是 |
| 证据 $P(D)$ | 保证后验归一化 | 是 |

> [!warning]
> 先验不只来自历史频率，也可来自领域知识或建模假设；似然是参数的函数，但不是参数上的概率密度。

## Exam/Test Patterns

| 关键词 | 回答策略 |
|---|---|
| “由多种原因导致某结果” | 对原因划分后使用全概率公式 |
| “结果已知，反推原因” | 使用贝叶斯公式 |
| “联合转边缘” | 对其他变量求和或积分 |
| “先验如何更新” | 后验正比于似然乘先验 |
| “检测准确率很高但阳性可信度不高” | 说明基础率效应 |

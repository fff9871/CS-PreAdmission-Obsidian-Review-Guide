# 概率模型、随机变量与密度函数（★★★）

#probability #probability-basics #random-variables

## Overview Table

| 概念 | 适用对象 | 表示方式 |
|---|---|---|
| 普通变量 | 确定性关系 | 给定输入后取值确定 |
| 随机变量 | 随机试验结果 | $X:\Omega\to\mathbb R$ |
| 古典概型 | 有限、等可能结果 | 有利结果数/全部结果数 |
| 几何概型 | 连续区域中的等可能位置 | 长度、面积或体积之比 |
| PMF/PDF/CDF | 离散/连续/通用分布描述 | 点概率、密度、累计概率 |

## 随机变量

随机变量不是“会自己随机变化的普通变量”，而是把随机试验结果映射为实数的函数：

$$X:\Omega\rightarrow\mathbb R$$

例如抛两次硬币，令 $X$ 为正面数：

```text
HH -> 2
HT -> 1
TH -> 1
TT -> 0
```

| 类型 | 取值 | 例子 |
|---|---|---|
| 离散型 | 有限或可数 | 次数、人数、缺陷数 |
| 连续型 | 区间内连续取值 | 时间、温度、身高 |

## 古典概型

要求基本结果数量有限且等可能：

$$P(A)=\frac{|A|}{|\Omega|}$$

例如公平骰子出现偶数：$P=3/6=1/2$。

> [!warning]
> 如果各结果不等可能，不能直接使用“有利结果数/总结果数”。

## 几何概型

用几何测度计算连续区域中的概率：

$$P(A)=\frac{m(A)}{m(\Omega)}$$

其中 $m$ 可以是长度、面积或体积。该公式要求“均匀随机”相对于所采用的测度定义清楚。

## PMF、PDF 与 CDF

### 离散概率质量函数 PMF

$$p_X(x)=P(X=x),\qquad \sum_xp_X(x)=1$$

### 连续概率密度函数 PDF

$$f_X(x)\ge0,\qquad \int_{-\infty}^{\infty}f_X(x)dx=1$$

区间概率：

$$P(a\le X\le b)=\int_a^bf_X(x)dx$$

### 累积分布函数 CDF

$$F_X(x)=P(X\le x)$$

对连续且可导的分布：

$$f_X(x)=F_X'(x)$$

```text
PMF：点的质量（离散）
PDF：单位长度上的概率密度（连续）
CDF：从负无穷累计到 x 的概率（通用）
```

## 密度的三个关键性质

1. 密度值本身不是概率。
2. 密度可以大于 1，例如 $U(0,0.5)$ 的密度为 2。
3. 连续变量单点概率为 0：$P(X=x)=0$。

> [!important]
> 连续型随机变量中，概率对应面积；因此 $P(a<X<b)$ 与 $P(a\le X\le b)$ 相同。

## Exam/Test Patterns

| 关键词 | 回答策略 |
|---|---|
| “随机变量是什么” | 样本空间到实数的函数，而非随机取值的符号 |
| “有限等可能” | 古典概型，计数求比值 |
| “随机落点/随机时刻” | 几何概型，测度求比值 |
| “密度是否就是概率” | 密度不是概率，区间积分才是概率 |
| “点概率为何为零” | 单点区间长度为零，但变量仍可取到该值 |

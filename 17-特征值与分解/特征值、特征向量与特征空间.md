# 特征值、特征向量与特征空间（★★★）

#linear-algebra #eigenvalues

## Overview Table

| 概念 | 定义 |
|---|---|
| 特征值/向量 | $Av=\lambda v, v\ne0$ |
| 特征空间 | $E_\lambda=\ker(A-\lambda I)$ |
| 代数重数 | $\lambda$ 作为特征多项式根的重数 |
| 几何重数 | $\dim E_\lambda$ |
| 谱 | 全部特征值的集合 |

## 求解步骤

```text
det(A-λI)=0
      ↓
求全部特征值 λ
      ↓
解 (A-λI)v=0
      ↓
得到特征空间的一组基
```

## 几何意义

特征向量所在的一维子空间在变换下保持不变，特征值给出缩放倍数。$\lambda<0$ 时方向反转；$\lambda=0$ 时该方向被压到零。

## 高频性质

- 不同特征值对应的特征向量线性无关。
- 几何重数不超过代数重数。
- 特征值之和为迹，乘积为行列式（按代数重数）。
- 三角矩阵的特征值是对角元素。
- $A$ 可逆当且仅当 0 不是特征值。

> [!warning]
> 零向量属于特征空间，但不称为特征向量。一个特征向量不可能对应两个不同特征值。

| 关键词 | 回答 |

| “特征值意义” | 不变方向上的伸缩因子 |

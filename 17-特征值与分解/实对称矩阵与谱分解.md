# 实对称矩阵与谱分解（★★★）

#linear-algebra #eigenvalues #diagonalization

## Overview Table

| 性质 | 实对称矩阵的结论 |
|---|---|
| 特征值 | 全为实数 |
| 不同特征值的特征向量 | 互相正交 |
| 对角化 | 总能正交对角化 |
| 分解 | $A=Q\Lambda Q^T$ |

## 谱定理

若 $A=A^T\in\mathbb R^{n\times n}$，则存在正交矩阵 $Q$ 和实对角矩阵 $\Lambda$，使

$$A=Q\Lambda Q^T.$$

$Q$ 的列是标准正交特征向量，$\Lambda$ 的对角元是对应特征值。

```text
x ──Qᵀ──> 特征坐标
   ──Λ──> 各特征方向独立缩放
   ──Q──> 回到原坐标
```

## 谱分解形式

若 $q_i$ 是标准正交特征向量，则

$$A=\sum_{i=1}^n\lambda_iq_iq_i^T.$$

这把矩阵拆成沿各正交方向的秩一作用。

## 与正定性的联系

$$x^TAx=\sum_i\lambda_i(q_i^Tx)^2.$$

所以实对称矩阵正定，当且仅当全部特征值为正；半正定对应全部特征值非负。

> [!warning]
> 一般可对角化矩阵的特征向量不一定能选成正交组；正交谱分解是实对称/Hermitian 结构带来的加强结论。

## Exam/Test Patterns

| 关键词 | 回答 |
|---|---|
| “实对称矩阵优势” | 实特征值、正交特征向量、必可正交对角化 |
| “谱分解” | $A=Q\Lambda Q^T$ 或 $\sum\lambda_iq_iq_i^T$ |
| “为何能判正定” | 二次型在特征坐标下是 $\sum\lambda_i y_i^2$ |
| “EVD 限制” | 方阵；正交形式通常需对称/Hermitian |

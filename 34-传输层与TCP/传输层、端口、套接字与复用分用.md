# 传输层、端口、套接字与复用分用（★★★）

#computer-networks #transport-layer #ports #socket

## Overview Table

| 概念 | 作用 |
|---|---|
| 传输层 | 在端系统上提供进程到进程的逻辑通信 |
| 端口号 | 标识主机内的应用进程/通信端点 |
| 复用 | 多个应用把数据交给同一传输层协议发送 |
| 分用 | 接收端依据首部把报文交给正确套接字 |
| 套接字 | 应用访问传输服务的接口；常用 IP 与端口描述端点 |

## 网络层与传输层

| 维度 | 网络层 | 传输层 |
|---|---|---|
| 通信对象 | 主机/接口之间 | 应用进程之间 |
| 实现位置 | 主机与路由器 | 主要在端系统 |
| 典型协议 | IP、ICMP | TCP、UDP |
| 地址依据 | IP 前缀 | 端口与连接标识 |

    应用进程A ─端口→ TCP/UDP ─IP→ 网络 ─IP→ TCP/UDP ─端口→ 应用进程B

TCP 连接通常由四元组 `(源IP, 源端口, 目的IP, 目的端口)` 标识；UDP 分用通常主要依据本地目的 IP 与目的端口，具体实现依操作系统套接字绑定规则而定。

> [!warning]
> “套接字=IP+端口”是便于答题的端点抽象；编程接口中的 socket 还包含协议、状态、缓冲区和选项，已连接 TCP 套接字通常需要四元组才能唯一确定连接。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| 传输层服务对象 | 不同主机上的应用进程 |
| 复用与分用 | 发送端合并多进程数据；接收端按首部分发 |
| TCP连接标识 | 源/目的 IP 与源/目的端口四元组 |

# 磁盘结构、寻道与格式化（★★★）

#operating-systems #storage-management #disk-structure #disk-latency

## Overview Table

| 术语 | 含义 |
|---|---|
| 盘面/磁道/扇区 | 传统磁盘物理几何单位 |
| 柱面 | 各盘面相同半径磁道集合 |
| LBA | 对外呈现的线性逻辑块编号 |
| 分区 | 连续逻辑块范围及其元数据 |

## 访问时间

`磁盘访问时间 ≈ 寻道时间 + 旋转延迟 + 传输时间 + 控制器/排队时间`

- 平均旋转延迟约为半圈时间。
- 连续大块访问可摊薄寻道和旋转成本。
- SSD 无机械寻道，但有闪存页/块、擦除、FTL、垃圾回收和磨损均衡。

## 格式化层次

低级格式化建立扇区/块结构；分区划分逻辑区域；逻辑格式化创建文件系统元数据。现代磁盘多由厂商完成物理格式化。

> [!warning]
> CHS 是经典抽象，现代设备通常通过 LBA 并在内部重映射；机械磁盘调度结论不能原样套用 SSD。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| 机械盘主要延迟 | 寻道 + 旋转 + 传输 |
| 平均旋转延迟 | 一般按半圈估算 |
| LBA | 对外线性编号，隐藏物理几何 |

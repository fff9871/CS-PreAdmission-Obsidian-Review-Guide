# 连续、链接、索引分配与空闲空间管理（★★★）

#operating-systems #file-system #file-allocation #free-space

## Overview Table

| 分配方式 | 随机访问 | 扩展 | 主要问题 |
|---|---|---|---|
| 连续分配 | 快 | 困难 | 外部碎片、需预估大小 |
| 链接分配 | 顺序好，随机差 | 容易 | 指针开销、可靠性；FAT 可改进定位 |
| 索引分配 | 支持随机访问 | 逐级扩展 | 索引块开销 |
| extent | 连续区间列表 | 较灵活 | 碎片后 extent 数增加 |

## 多级索引寻址

    inode
      ├─ direct pointers → data blocks
      ├─ single indirect → pointer block → data
      ├─ double indirect → pointer blocks → data
      └─ triple indirect → ...

若块大小为 B、指针大小为 P，则一个间接块可存 `B/P` 个指针，据此计算最大文件大小。

## 空闲空间

位图每个块一位，便于查连续空闲区；空闲链表简单但随机找大区间慢；分组/计数法可压缩连续空闲范围。

> [!warning]
> “索引分配”与数据库索引无关。计算最大文件大小时要区分索引块和数据块，且文件大小上限还受 inode 字段和实现限制。

## Exam/Test Patterns

| 题型 | 关键 |
|---|---|
| 最大文件大小 | direct + 各级 indirect 可寻址数据块数 |
| 快速找连续空闲块 | 位图/extent 结构 |
| 随机访问差 | 纯链接分配 |

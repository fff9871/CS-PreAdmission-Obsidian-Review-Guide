# 缓冲、缓存、假脱机与设备分配（★★★）

#operating-systems #io-management #buffering #spooling

## Overview Table

| 机制 | 主要目的 | 示例 |
|---|---|---|
| Buffer 缓冲 | 匹配速度/粒度，平滑突发 | 单缓冲、双缓冲、环形缓冲 |
| Cache 缓存 | 保存副本以减少重复访问 | 页缓存、块缓存 |
| Spooling 假脱机 | 用磁盘队列把独占设备虚拟成共享服务 | 打印队列 |
| 设备分配 | 协调独占、共享和虚拟设备 | 分配表、预约、释放 |

## 双缓冲流水

    设备填充 A ─┐
                 ├─交替→ 处理者消费
    处理者消费 B ┘

当一个缓冲区被处理时，设备可并行填充另一个，从而重叠 I/O 与计算。环形缓冲适合连续生产—消费流。

## 数据一致性

写缓存提高性能但引入持久化延迟；需要写回策略、刷新、错误传播和崩溃一致性。直接 I/O、mmap 和 DMA 还可能涉及对齐、页固定和 Cache 一致性。

> [!warning]
> 缓冲与缓存目的不同但实现可重叠；“write 返回”也不总等于数据已落到稳定介质，需看同步标志和 fsync/设备语义。

## Exam/Test Patterns

| 需求 | 机制 |
|---|---|
| 速度不匹配 | 缓冲 |
| 重复读取 | 缓存 |
| 共享打印机 | Spooling |

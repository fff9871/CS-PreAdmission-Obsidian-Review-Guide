# 欧拉图与哈密顿图（★★★）

#discrete-mathematics #graph-theory #eulerian-graph #hamiltonian-graph

## Overview Table

| 对比 | 欧拉问题 | 哈密顿问题 |
|---|---|---|
| 遍历对象 | 每条边恰一次 | 每个顶点恰一次 |
| 顶点能否重复 | 可以 | 除起终点重合外不可以 |
| 简洁判定 | 无向图有度数充要条件 | 一般没有简单充要条件 |
| 典型复杂度 | 可线性构造 | 一般判定 NP-complete |

## 欧拉通路与欧拉回路

- 欧拉通路：每条边恰经过一次的迹。
- 欧拉回路：起终点相同的欧拉通路。
- 欧拉图：含欧拉回路的图。

对非零度顶点连通的无向图：

| 奇度顶点数 | 结论 |
|---:|---|
| 0 | 存在欧拉回路 |
| 2 | 存在开欧拉通路，端点就是两个奇度顶点 |
| 其他 | 不存在欧拉通路 |

## Hierholzer 算法

```text
从合法起点出发沿未使用边走成一个回路
                 ↓
若回路上某点仍有未使用边，从该点再走一个回路
                 ↓
把新回路拼入旧回路，直到所有边用完
```

用栈实现可达到 $O(|E|)$。Fleury 算法强调“除非不得已，不走桥”，直观但高效实现较复杂。

## 哈密顿路与哈密顿回路

- 哈密顿路：每个顶点恰经过一次。
- 哈密顿回路：回到起点的哈密顿路。

常见充分条件：对 $n\ge3$ 的简单图，若每个顶点度数至少 $n/2$，则存在哈密顿回路（Dirac 定理）。它是充分条件，不是必要条件。

> [!warning]
> “哈密顿图没有高效精确算法”应理解为一般判定问题目前没有已知多项式时间算法；小规模仍可用回溯、状态压缩动态规划求精确解。

## Exam/Test Patterns

| 题型关键词 | 回答 |
|---|---|
| “欧拉与哈密顿区别” | 前者遍历边，后者遍历顶点 |
| “一笔画” | 判断奇度顶点数并检查非零度部分连通 |
| “构造欧拉回路” | Hierholzer：找回路并不断拼接 |
| “哈密顿如何求” | 一般困难；小规模回溯/状态压缩，大规模可启发式 |

# 树、生成树与 Huffman 树（★★）

#discrete-mathematics #graph-theory #trees

## Overview Table

| 概念 | 目标 | 关键性质 |
|---|---|---|
| 树 | 连通且无环 | $n$ 个顶点、$n-1$ 条边 |
| 生成树 | 覆盖连通图全部顶点 | 是原图的生成子图 |
| 最小生成树 | 最小化生成树边权总和 | Prim/Kruskal |
| Huffman 树 | 最小化带权外部路径长度 | 反复合并最小权值 |

## 树的等价刻画

对有 $n$ 个顶点的无向图，以下条件等价：

- 连通且无环；
- 连通且有 $n-1$ 条边；
- 无环且有 $n-1$ 条边；
- 任意两顶点之间有唯一简单路径；
- 删除任一边都会不连通。

## 生成树与最小生成树

连通图的生成树保留全部顶点并选取足够边使其连通无环。带权图的最小生成树最小化边权总和。

> [!important]
> 最小生成树最小化的是总边权；最短路径树最小化的是某个源点到各顶点的路径距离，目标不同。

## Huffman 树

给定叶子权值 $w_i$，目标是最小化

$$WPL=\sum_i w_i\,l_i,$$

其中 $l_i$ 是叶子深度。

```text
把每个权值视作一棵树
       ↓
取权值最小的两棵合并
       ↓
新根权值 = 两者之和
       ↓
重复直到只剩一棵树
```

左右分支标 0/1 可得到前缀编码。权值相同可能产生不同树形，但最优 WPL 相同。

## Exam/Test Patterns

| 题型关键词 | 回答 |
|---|---|
| “树有多少边” | $n$ 个顶点的树有 $n-1$ 条边 |
| “生成树” | 覆盖全部顶点的树形子图 |
| “MST 与最短路树” | 一个最小化总权，一个最小化源点路径 |
| “Huffman 步骤” | 每次合并权值最小的两棵树 |

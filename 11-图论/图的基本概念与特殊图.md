# 图的基本概念与特殊图（★★★）

#discrete-mathematics #graph-theory

## Overview Table

| 类型 | 边的形式 | 允许自环/重边 |
|---|---|---|
| 无向图 | 无序对 $\{u,v\}$ | 依模型而定 |
| 有向图 | 有序对 $(u,v)$ | 依模型而定 |
| 混合图 | 同时有有向边、无向边 | 依模型而定 |
| 简单图 | 无向、无自环、无重边 | 不允许 |
| 多重图 | 可有平行边 | 通常允许重边 |

## 图的定义

图记为 $G=(V,E)$，其中 $V$ 是非空顶点集，$E$ 是边集。有限图要求 $V,E$ 有限。

```text
顶点集 V：对象
边集 E：对象之间的连接
G=(V,E)：结构整体
```

## 边与特殊结构

- 自环：边的两个端点相同。
- 平行边：同一对端点之间存在多条边。
- 简单图：无自环、无平行边。
- 完全图 $K_n$：任意两个不同顶点之间都有一条边。
- 二分图：顶点可分成两组，边只跨组连接。

简单无向完全图边数为

$$|E(K_n)|=\binom n2=\frac{n(n-1)}2.$$

## 路、回路与连通

| 概念 | 含义 |
|---|---|
| 途径/走法 | 顶点和边可重复 |
| 迹 | 边不重复 |
| 路径 | 顶点不重复 |
| 回路 | 起点和终点相同 |
| 连通图 | 任意两顶点间存在路径 |

不同教材对 walk/trail/path 的中文翻译可能不同，回答时应直接说明“顶点/边能否重复”。

> [!warning]
> 无向边应理解为无序端点对；写成有序二元组容易与有向边混淆。

## Exam/Test Patterns

| 题型关键词 | 回答 |
|---|---|
| “无向图定义” | 顶点集与无向边集组成；边表示无序端点对 |
| “简单图” | 无自环、无重边 |
| “完全图边数” | $n(n-1)/2$ |
| “路径与迹” | 路径不重复顶点，迹不重复边；先说明采用的术语 |

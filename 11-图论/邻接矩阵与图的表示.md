# 邻接矩阵与图的表示（★★）

#discrete-mathematics #graph-theory

## Overview Table

| 表示 | 空间 | 查边 | 遍历邻居 | 适合 |
|---|---:|---:|---:|---|
| 邻接矩阵 | $O(n^2)$ | $O(1)$ | $O(n)$ | 稠密图、矩阵运算 |
| 邻接表 | $O(n+m)$ | 视实现而定 | $O(\deg v)$ | 稀疏图、搜索 |
| 关联矩阵 | $O(nm)$ | — | — | 代数分析、网络结构 |

## 邻接矩阵

顶点按 $v_1,\ldots,v_n$ 排序，简单图邻接矩阵 $A=(a_{ij})$ 定义为

$$a_{ij}=\begin{cases}1,&v_i\text{ 与 }v_j\text{ 相邻}\0,&\text{否则。}\end{cases}$$

- 无向图的 $A$ 对称。
- 简单图对角线为 0。
- 有向图中，第 $i$ 行和为出度，第 $j$ 列和为入度。

## 矩阵幂与步数

对普通邻接矩阵，$(A^k)_{ij}$ 等于从 $v_i$ 到 $v_j$ 的长度为 $k$ 的走法数量。

```text
A      ：一步连接
A²     ：两步走法数量
A³     ：三步走法数量
布尔化求和：可达性
```

## 带权图

权重矩阵用边权替代 1；无边位置可记为 $\infty$。必须区分“无边”和“权重为 0 的边”。

## 与关系矩阵的联系

有限集合上的二元关系可视作有向图，关系矩阵就是其邻接矩阵。Warshall 算法既能求关系传递闭包，也能求图的可达性。

> [!warning]
> 自环在度数和矩阵中的计数约定不同：无向图自环对顶点度贡献 2，但邻接矩阵对角元素如何记录需看教材约定。

## Exam/Test Patterns

| 题型关键词 | 回答 |
|---|---|
| “无向图矩阵特点” | 对称；简单图对角线为 0 |
| “$A^k$ 的意义” | 长度为 $k$ 的走法数量 |
| “稀疏图表示” | 邻接表更省空间，遍历邻居更快 |
| “关系与图” | 关系矩阵就是对应有向图的邻接矩阵 |

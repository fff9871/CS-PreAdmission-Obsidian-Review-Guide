# 子图、补图、度数与同构（★★★）

#discrete-mathematics #graph-theory

## Overview Table

| 概念 | 核心条件 |
|---|---|
| 子图 | 顶点、边分别取原图的子集，并保持端点关系 |
| 生成子图 | 保留原图全部顶点 |
| 顶点导出子图 | 选顶点后保留其间全部原有边 |
| 补图 | 在同一顶点集上连接原图中未相邻的顶点 |
| 同构 | 存在保持邻接关系的顶点双射 |

## 子图分类

设 $G=(V,E)$，$G'=(V',E')$。

- 子图：$V'\subseteq V,E'\subseteq E$。
- 生成子图：$V'=V$。
- 顶点导出子图 $G[S]$：顶点为 $S$，边为原图中两端都在 $S$ 的全部边。
- 边导出子图：选取边集并带上这些边的端点。

## 补图

对简单图 $G$，补图 $\bar G$ 与 $G$ 顶点集相同，且不同顶点在 $\bar G$ 中相邻，当且仅当它们在 $G$ 中不相邻。

$$\deg_G(v)+\deg_{\bar G}(v)=n-1.$$

## 度数与握手定理

无向图：

$$\sum_{v\in V}\deg(v)=2|E|.$$

因此奇度顶点个数为偶数。有向图满足

$$\sum_v\deg^+(v)=\sum_v\deg^-(v)=|E|.$$

所有顶点度相同的图称为正则图。

## 图同构

图 $G,H$ 同构，若存在双射 $f:V(G)\to V(H)$，使

$$uv\in E(G)\Longleftrightarrow f(u)f(v)\in E(H).$$

```text
先比较不变量：顶点数、边数、度序列、连通性、环结构
                  ↓ 均一致仍不能确认
再尝试构造保持邻接的顶点双射
```

> [!warning]
> 顶点数、边数、度序列相同只是必要条件，不足以保证同构。

## Exam/Test Patterns

| 题型关键词 | 回答 |
|---|---|
| “握手定理” | 无向图度数总和等于边数两倍 |
| “奇度顶点个数” | 必为偶数 |
| “同构必要条件” | 顶点数、边数、度序列等不变量相同 |
| “如何最终证明同构” | 给出保持邻接关系的双射 |

# 栈与典型应用（★★★）

#data-structures #stacks-queues

## Overview Table

| 特性 | 含义 | 典型应用 |
|---|---|---|
| LIFO | 后进先出 | 函数调用、撤销、深度遍历 |
| 只操作栈顶 | `push/pop/top` 通常 $O(1)$ | 括号匹配、表达式求值 |
| 共享栈 | 两栈从数组两端向中间生长 | 提高固定空间利用率 |

## 括号匹配

```text
左括号 → 入栈
右括号 → 栈空？失败
           → 与栈顶配对？出栈 : 失败
扫描结束 → 栈空？成功 : 有多余左括号
```

## 表达式

- **中缀转后缀**：操作数直接输出；运算符根据优先级和结合性进出栈。
- **后缀求值**：操作数入栈；遇运算符弹出右操作数 $b$ 和左操作数 $a$，计算 $a\;op\;b$后压回。
- **递归**：系统调用栈保存返回地址、局部变量和现场。

> [!warning]
> 后缀求值中两次出栈的操作数顺序不能反；减法和除法会立即暴露该错误。

## Exam/Test Patterns

| 场景 | 回答 |
|---|---|
| 括号匹配 | 左入栈、右与栈顶匹配，最后栈必须空 |
| 递归改非递归 | 显式栈模拟调用帧与处理阶段 |
| 共享栈满 | 两个栈顶相邻 |

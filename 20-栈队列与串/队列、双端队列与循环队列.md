# 队列、双端队列与循环队列（★★★）

#data-structures #stacks-queues

## Overview Table

| 结构 | 受限方式 | 应用 |
|---|---|---|
| 队列 | 队尾入、队头出，FIFO | BFS、层序遍历、缓冲 |
| 双端队列 | 两端都可进出 | 滑动窗口、0-1 BFS |

## 循环队列

若 `front` 指向队头，`rear` 指向下一个入队位置，且牺牲一个单元：

- 队空：`front == rear`
- 队满：`(rear + 1) % capacity == front`
- 元素数：`(rear - front + capacity) % capacity`

```text
0   1   2   3   4
    F → [a][b][c] ← R(下一空位)
下标通过 % capacity 回绕
```

其他区分空/满的方法：增加元素个数 `size`，或保留最后一次操作标志。

> [!warning]
> `rear` 指向“队尾元素”还是“下一个空位”有不同约定，公式必须与约定配套。

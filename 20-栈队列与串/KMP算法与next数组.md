# KMP算法与next数组（★★★）

#data-structures #arrays-strings #kmp

## Overview Table

| 对象 | 含义 |
|---|---|
| 前缀 | 从串首开始的真子串 |
| 后缀 | 到串尾结束的真子串 |
| 失配函数 | 已匹配部分的最长相等真前后缀长度 |
| KMP 核心 | 主串指针不回退，模式指针按失配函数跳转 |

## 匹配流程

```text
text[i] == pattern[j] → i++, j++
text[i] != pattern[j] → j 跳到可复用的最长前缀位置
j == 0 仍失配       → i++
```

预处理模式串 $O(m)$，匹配 $O(n)$，总复杂度 $O(n+m)$。

## `next` 版本差异

| 版本 | 常见初值 | 失配后含义 |
|---|---:|---|
| `next` 教材版 | `next[0] = -1` | 跳到下一比较下标 |
| 前缀函数 `pi` | `pi[0] = 0` | 长度为 $i+1$ 前缀的最长 border 长度 |

> [!warning]
> 不同教材的 `next` 下标、初值和值的含义可不同。面试时先声明约定，再手算数组。

## Exam/Test Patterns

| 关键词 | 回答 |
|---|---|
| “主串不回溯” | 已匹配段内部的前后缀关系已经提供了下一对齐位置 |
| “为何线性” | 指针前进与回退的总次数受线性界限 |
| “手算 next” | 逐位求已扫描前缀的最长相等真前后缀 |

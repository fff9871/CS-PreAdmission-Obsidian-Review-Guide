# 数组与特殊矩阵压缩存储（★★）

#data-structures #arrays-strings

## Overview Table

| 对象 | 压缩思路 | 关键点 |
|---|---|---|
| 对称矩阵 | 只存上或下三角 | $n(n+1)/2$ 个元素 |
| 三角矩阵 | 存一个三角和一个常量 | 另一三角元素相同 |
| 对角/带状矩阵 | 只存非零带 | 建立 $(i,j)$ 到一维下标的映射 |
| 稀疏矩阵 | 只存非零元素 | 三元组或十字链表 |

## 数组地址映射

行优先存储中，二维数组 $A[m][n]$ 的元素地址可由基址、元素大小和前面的元素个数线性计算。数组能随机存取，根本原因就是这种可计算的连续布局。

```text
(row, col) → 线性下标 → base + offset × element_size
```

> [!warning]
> 压缩存储节省空间，但会增加下标换算或更新复杂度；不是所有矩阵运算都适合压缩格式。

## Exam/Test Patterns

| 关键词 | 回答 |
|---|---|
| “数组为何 $O(1)$ 定位” | 连续存储，地址可由下标公式直接算出 |
| “稀疏矩阵” | 存非零元素的行、列、值 |
| “对称矩阵” | 利用 $a_{ij}=a_{ji}$ 只存一个三角 |

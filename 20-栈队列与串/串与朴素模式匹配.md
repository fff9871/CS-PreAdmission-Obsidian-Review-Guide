# 串与朴素模式匹配（★★）

#data-structures #arrays-strings

## Overview Table

| 概念 | 定义 | 备注 |
|---|---|---|
| 串 | 零个或多个字符的有限序列 | 空串长度为 0 |
| 子串 | 主串中连续的字符序列 | 与子序列不同 |
| 模式匹配 | 定位模式串在主串中的出现 | 返回位置或匹配失败 |

## 朴素匹配

从主串每个可能起点开始，与模式串逐字符比较；失配时主串起点后移一位。

```text
text:    a b a b a c a
pattern: a b a c
         ✓ ✓ ✓ ×
           重新从下一起点比较
```

主串长 $n$、模式长 $m$ 时，最坏复杂度为 $O((n-m+1)m)$，简写为 $O(nm)$。

> [!warning]
> 子串必须连续；子序列只要保持相对次序，不要混淆。

## Exam/Test Patterns

| 提问 | 回答 |
|---|---|
| 朴素匹配的低效根源 | 失配后主串指针回溯，重复比较已知字符 |
| 模式串比主串长 | 必然匹配失败 |
| 与 KMP 对比 | KMP 利用模式自身的前后缀信息 |

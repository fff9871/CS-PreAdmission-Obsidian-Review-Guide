# 操作系统目标、功能与基本特征（★★★）

#operating-systems #os-fundamentals

## Overview Table

| 视角 | 操作系统的作用 |
|---|---|
| 资源管理者 | 管理处理机、内存、文件、设备和网络资源 |
| 用户接口 | 提供命令、GUI、库/API 与系统调用 |
| 扩充机器 | 隐藏硬件细节，提供进程、文件、虚拟内存等抽象 |
| 控制程序 | 处理异常、中断、保护和资源竞争 |

## 四个基本特征

| 特征 | 含义 |
|---|---|
| 并发 | 多个程序在时间上交错推进 |
| 共享 | 多个执行实体共同使用系统资源 |
| 虚拟 | 把一个物理资源抽象成多个逻辑资源 |
| 异步 | 程序推进速度受调度和事件影响，不可预知但应可控 |

并发与共享互为条件：并发活动会产生共享需求，共享资源又要求同步互斥机制。

    应用程序
       ↓ 系统调用/API
    操作系统：抽象 + 管理 + 保护
       ↓
    CPU / 内存 / 磁盘 / 设备

## 系统类型

批处理追求吞吐量，分时系统追求交互响应，实时系统关注截止期；现代通用系统通常融合多种目标。

> [!warning]
> 并发不等于并行：单核可通过交错执行形成并发，多核在同一时刻执行多个任务才是物理并行。实时也不等于“速度最快”，关键是可预测地满足时间约束。

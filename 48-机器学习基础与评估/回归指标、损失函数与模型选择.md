# 回归指标、损失函数与模型选择（★★★）

#machine-learning #ml-fundamentals #regression-metrics #loss-functions

## Overview Table

| 指标/损失 | 特点 |
|---|---|
| MSE | 大误差惩罚强，可导，对异常值敏感 |
| RMSE | 与目标同量纲，仍受大误差影响 |
| MAE | 对异常值更稳健，零点不可导可用次梯度 |
| Huber | 小误差平方、大误差线性，折中稳健性 |
| R² | 相对均值基线解释方差，可能为负 |
| MAPE | 相对误差直观，目标接近零时不稳定 |

## 损失与概率假设

- MSE 对应高斯噪声最大似然的经典形式。
- MAE 对应拉普拉斯噪声的经典形式。
- 选择损失要结合噪声、业务成本和优化稳定性。

## 模型选择

比较模型应固定数据划分与预处理，报告交叉验证均值和方差，并在最终测试集只评一次。复杂度相近时可优先选择更稳健、可解释或部署成本更低者。

> [!warning]
> R² 不是误差百分比，也不保证模型无偏；训练 loss 较低并不代表业务指标更好。若对数变换目标，评估时需明确是在变换空间还是原始空间。

## Exam/Test Patterns

| 场景 | 选择 |
|---|---|
| 异常值多 | MAE/Huber |
| 强惩罚大误差 | MSE/RMSE |
| 与均值基线比较 | R² |

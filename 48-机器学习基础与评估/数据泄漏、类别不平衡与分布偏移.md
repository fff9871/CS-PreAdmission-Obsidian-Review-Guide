# 数据泄漏、类别不平衡与分布偏移（★★★）

#machine-learning #ml-fundamentals #data-leakage #distribution-shift

## Overview Table

| 风险 | 表现 | 对策 |
|---|---|---|
| 目标泄漏 | 特征直接/间接包含未来标签 | 按生成时点审计特征 |
| 划分泄漏 | 相关实体跨训练测试 | 时间/组划分 |
| 预处理泄漏 | 全数据拟合标准化或选择特征 | 训练折内 pipeline |
| 类别不平衡 | 少数类被多数类淹没 | 重采样、代价敏感、阈值与合适指标 |
| 协变量偏移 | `P(X)` 变化 | 重加权、再训练、监控 |
| 概念漂移 | `P(Y|X)` 变化 | 新标签、在线更新、回滚策略 |

## 诊断路径

    unexpectedly high offline score
      → audit split/entity/time
      → audit feature availability
      → compare train/validation/deployment distributions
      → inspect per-group metrics and calibration

处理不平衡时，过采样/SMOTE 只能在训练折内部进行；阈值移动改变 Precision/Recall，但不改变模型排序本身。

> [!warning]
> 类别权重、重采样和阈值调整解决的是不同层次问题，不能混为一谈。测试分布变化后，历史离线指标可能失效。

## Exam/Test Patterns

| 现象 | 首查 |
|---|---|
| 离线极高、上线骤降 | 泄漏与分布偏移 |
| 正类1%而Accuracy 99% | 混淆矩阵、PR-AUC、Recall |
| 同用户多样本 | 按用户分组划分 |

# 数据预处理、标准化与特征工程（★★★）

#machine-learning #ml-fundamentals #data-preprocessing #feature-engineering

## Overview Table

| 操作 | 公式/目的 | 常见场景 |
|---|---|---|
| 标准化 | `(x-μ)/σ` | 距离模型、线性模型、神经网络 |
| Min-Max | `(x-min)/(max-min)` | 需要固定区间的输入 |
| 缺失处理 | 插补 + 缺失指示 | 表格数据 |
| 类别编码 | One-hot、目标编码、Embedding | 类别特征 |
| 特征变换 | log、分箱、交互项 | 偏态、非线性关系 |
| 数据增强 | 保标签的随机变换 | 图像、语音、文本 |

## 正确流水线

    raw training data
       → fit preprocessing statistics
       → transform train/val/test with same fitted state
       → model

标准化不改变特征的排序，但改变距离和正则惩罚尺度；树模型通常不依赖单调尺度变化，却仍受缺失、类别编码和异常值策略影响。

> [!warning]
> 均值、方差、词表、特征选择和目标编码都必须只从训练数据获得。先在全数据预处理再划分，会泄漏验证/测试信息。

## Exam/Test Patterns

| 模型/问题 | 处理 |
|---|---|
| KNN、K-means、SVM | 通常需尺度标准化 |
| 右偏正值 | 可评估 log 变换 |
| 目标编码 | 必须折内计算，防止泄漏 |

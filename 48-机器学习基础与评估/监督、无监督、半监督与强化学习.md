# 监督、无监督、半监督与强化学习（★★★）

#machine-learning #ml-fundamentals #learning-paradigms

## Overview Table

| 范式 | 训练信号 | 典型任务 |
|---|---|---|
| 监督学习 | 输入与标签 `(x,y)` | 分类、回归、排序 |
| 无监督学习 | 仅输入 `x` | 聚类、降维、密度估计 |
| 半监督学习 | 少量标签 + 大量无标签数据 | 伪标签、一致性训练 |
| 自监督学习 | 从数据自身构造预测目标 | 掩码建模、对比学习 |
| 强化学习 | 状态、动作、奖励与环境反馈 | 策略学习、序列决策 |

## 基本建模链路

    data → representation/features → model fθ
         → objective/loss → optimization
         → validation → generalization/deployment

监督学习关注从样本推广到未见数据；无监督学习发现结构，但结果是否“有意义”仍依赖距离、分布和任务定义。强化学习优化长期累计回报，还要处理探索与利用。

> [!warning]
> “有标签/无标签”不是唯一分类维度：生成式/判别式、参数/非参数、在线/批量学习都可交叉。自监督产生的标签来自数据本身，不等于人工监督。

## Exam/Test Patterns

| 关键词 | 判断 |
|---|---|
| 离散/连续标签 | 监督分类/回归 |
| 无标签找群组 | 无监督聚类 |
| 奖励与策略 | 强化学习 |

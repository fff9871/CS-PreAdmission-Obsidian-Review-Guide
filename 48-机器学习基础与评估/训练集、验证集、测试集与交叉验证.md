# 训练集、验证集、测试集与交叉验证（★★★）

#machine-learning #ml-fundamentals #data-splitting #cross-validation

## Overview Table

| 子集 | 用途 | 是否用于模型选择 |
|---|---|---|
| 训练集 | 拟合参数 | 是，通过优化直接使用 |
| 验证集 | 调超参数、早停、选模型 | 是 |
| 测试集 | 最终一次无偏近似评估 | 否 |
| 外部/时间外测试 | 检验跨域或未来泛化 | 否 |

## 划分原则

- 分类常用分层抽样保持类别比例。
- 时间序列按时间前后划分，不能随机把未来混入过去。
- 同一用户、病人、设备或实体的相关样本应按组划分。
- 所有预处理统计量必须只在训练折拟合。

## K折交叉验证

    split data into K folds
      → repeat K times: train on K-1, validate on 1
      → aggregate mean ± variance

交叉验证用于样本较少时估计模型选择性能；嵌套交叉验证可把超参数选择与外层性能估计分开。

> [!warning]
> 反复查看测试集并据此改模型，会让测试集事实上变成验证集。K 折也不能修复数据泄漏或分布不一致。

## Exam/Test Patterns

| 场景 | 正确做法 |
|---|---|
| 调学习率 | 看验证集，不看测试集 |
| 时间预测 | 时间顺序划分 |
| 同人多条记录 | group split |

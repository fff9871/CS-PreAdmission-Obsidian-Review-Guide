# 数据库中的B+树、Hash与全文索引（★★★）

#database #indexing #b-plus-tree

## Overview Table

| 项目 | 要点 |
|---|---|
| B+ 树索引 | 有序、多路、叶结点保存记录或记录定位信息 |
| Hash 索引 | 按哈希值定位，擅长等值查询 |
| 全文索引 | 倒排表从词项映射到文档或记录 |
| 空间索引 | 面向多维几何对象和空间谓词 |

## B+ 树能力

支持全键值、范围、排序、分组和符合最左前缀的复合键查询；叶链便于范围扫描。

## Hash 限制

失去键的全序，不适合一般范围查询、按键排序或最左前缀匹配；平均等值查找快，但需处理冲突。

## B 树对 B+ 树

B 树内部结点可保存记录；B+ 树内部结点更像导航目录，记录集中于叶子，通常扇出更大且范围访问更顺。

> [!warning]
> “B+ 树查找是 O(log n)”只描述数量级；数据库更关注树高对应的页 I/O 次数和叶页扫描量。

## Exam/Test Patterns

| 场景/关键词 | 回答 |
|---|---|
| 等值查询 | B+ 树或 Hash；还要看范围、排序和引擎支持 |
| 范围查询 | B+ 树 |
| 全文搜索 | 倒排索引，而不是普通 B+ 树逐字匹配 |

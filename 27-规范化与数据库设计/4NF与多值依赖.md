# 4NF与多值依赖（★★）

#database #normalization #fourth-normal-form

## Overview Table

| 概念 | 要点 |
|---|---|
| 多值依赖 X→→Y | 给定 X 后，Y 的取值集合独立于其余属性变化 |
| 平凡多值依赖 | Y 是 X 的子集，或 X 与 Y 合起来覆盖全部属性 |
| 4NF | 每个非平凡多值依赖的决定因素都是超码 |
| 目标 | 消除多个独立多值事实混存造成的组合冗余 |

## 典型场景

若课程独立拥有多位教师和多本参考书，把三者放在一个关系中会产生教师数乘参考书数的组合行。课程→→教师、课程→→参考书，二者相互独立，适合分解为课程教师和课程参考书两个关系。

    课程-教师-参考书
            ↓ 分解
    课程-教师   课程-参考书

## 与 BCNF 的关系

BCNF 处理函数依赖；4NF 进一步处理多值依赖。函数依赖是多值依赖的特殊情况，因此 4NF 比 BCNF 更强。

> [!warning]
> 一个关系满足 BCNF 仍可能因非平凡多值依赖而违反 4NF。只有确实存在独立多值事实时才需要这种分解。

## Exam/Test Patterns

| 场景/关键词 | 回答 |
|---|---|
| 两组独立的一对多事实混在一表 | 检查多值依赖和组合冗余 |
| 4NF 判定 | 非平凡多值依赖的决定因素必须是超码 |
| 4NF 与 BCNF | 分别重点处理多值依赖与函数依赖 |

# 函数依赖、属性闭包与候选码（★★★）

#database #normalization #functional-dependency

## Overview Table

| 项目 | 要点 |
|---|---|
| 函数依赖 X→Y | X 值相同的元组，其 Y 值也必须相同 |
| 完全依赖 | 去掉 X 中任一属性后不再能决定 Y |
| 部分依赖 | X 的真子集已经能决定 Y |
| 传递依赖 | X→Y、Y→Z 且不是平凡情形时，Z 经 Y 依赖于 X |
| 属性闭包 X+ | 由依赖集从 X 能推出的全部属性 |

## 闭包求法

从 X 开始，反复加入所有满足“依赖左部已包含”的右部属性，直到不再变化。若 X+ 覆盖关系全部属性，则 X 是超码。

## 候选码求法

先找不出现在任何依赖右部的必含属性，再补属性使闭包覆盖全体，最后检查最小性。

## 依赖推理

Armstrong 公理：自反、增广、传递；常用派生规则包括合并、分解和伪传递。

> [!warning]
> 能决定全部属性只能说明是超码；还必须删除任一属性都会失去该能力，才是候选码。

## Exam/Test Patterns

| 场景/关键词 | 回答 |
|---|---|
| 求候选码 | 闭包覆盖全属性加最小性 |
| 部分依赖 | 只在复合候选码语境中才可能出现 |
| 平凡依赖 | Y 是 X 的子集时，X→Y 自动成立 |

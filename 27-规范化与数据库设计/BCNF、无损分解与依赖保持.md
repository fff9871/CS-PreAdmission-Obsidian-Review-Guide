# BCNF、无损分解与依赖保持（★★★）

#database #normalization #bcnf #decomposition

## Overview Table

| 项目 | 要点 |
|---|---|
| BCNF | 每个非平凡函数依赖 X→Y 的决定因素 X 都是超码 |
| 无损连接 | 分解后自然连接可精确恢复原关系 |
| 依赖保持 | 约束可在各子关系内局部检查，无需先连接 |
| 3NF 与 BCNF | BCNF 更严格；3NF 可为保持依赖而保留部分主属性依赖 |

## 二元分解无损判据

把 R 分解为 R1、R2。若公共属性 R1∩R2 能函数决定 R1 或 R2，则该二元分解关于依赖集无损。

## 依赖保持检查

把依赖投影到各子关系并合并，若能推出原依赖集，则保持依赖。

## 取舍

BCNF 分解总能做到无损，但未必保持全部依赖；3NF 综合算法可同时做到无损和依赖保持。

> [!warning]
> “分解后能连接回来”还不够，必须不会产生伪元组；无损连接与依赖保持是两个独立目标。

## Exam/Test Patterns

| 场景/关键词 | 回答 |
|---|---|
| BCNF 判定 | 每个决定因素都是超码 |
| 无损与保持依赖 | 前者保证信息，后者保证约束可局部检查 |
| 3NF 与 BCNF 取舍 | 更强去冗余对更易保持依赖 |

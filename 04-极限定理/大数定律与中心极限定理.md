# 大数定律与中心极限定理（★★★）

#probability #limit-theorems

## Overview Table

| 定理      | 研究对象  | 核心结论             | 解决问题       |
| ------- | ----- | ---------------- | ---------- |
| 大数定律    | 样本均值  | $\bar X_n\to\mu$ | 均值最终靠近哪里   |
| 中心极限定理  | 标准化误差 | 趋近标准正态           | 均值如何波动     |
| 伯努利大数定律 | 事件频率  | 频率趋近概率           | 概率为何可由频率估计 |
| 二项正态近似  | 成功次数  | 近似正态             | 简化大样本概率计算  |

## 大数定律

若 $X_1,\ldots,X_n$ 独立同分布且 $E[X_i]=\mu$ 存在，则辛钦大数定律给出：

$$\bar X_n=\frac1n\sum_{i=1}^nX_i\xrightarrow{P}\mu$$

“依概率收敛”表示：任意 $\varepsilon>0$，都有

$$P(|\bar X_n-\mu|>\varepsilon)\to0$$

### 三种常见表述

| 名称       | 常用条件       | 结论              |
| -------- | ---------- | --------------- |
| 切比雪夫大数定律 | 独立、方差受控    | 样本均值与平均期望之差趋于 0 |
| 伯努利大数定律  | 独立重复事件     | 频率趋于概率 $p$      |
| 辛钦大数定律   | 独立同分布、期望存在 | 样本均值趋于总体期望      |

## 中心极限定理

若 $X_i$ 独立同分布：

$$E[X_i]=\mu,\qquad Var(X_i)=\sigma^2\in(0,\infty)$$

则：

$$\frac{\sum_{i=1}^nX_i-n\mu}{\sigma\sqrt n}\xrightarrow{d}N(0,1)$$

等价近似：

$$\bar X_n\approx N\left(\mu,\frac{\sigma^2}{n}\right)$$

```text
单个 Xi 可以不是正态
          ↓ 大量独立同分布求和
标准化后的和近似 N(0,1)
```

## 二项分布的正态近似

若 $X\sim B(n,p)$：

$$X\approx N(np,np(1-p))$$

常用经验条件是 $np$ 与 $n(1-p)$ 均至少为 5 或 10。计算离散概率时使用连续性校正：

$$P(X\le k)\approx P(Y\le k+0.5)$$

## 两个定理的核心区别

| 对比   | 大数定律       | 中心极限定理               |
| ---- | ---------- | -------------------- |
| 结论对象 | $\bar X_n$ | 标准化后的 $\bar X_n-\mu$ |
| 描述内容 | 收敛位置       | 误差分布                 |
| 给出速率 | 通常不直接给出    | 标准误差按 $1/\sqrt n$ 缩小 |
| 典型用途 | 一致估计、频率解释  | 置信区间、近似概率、假设检验       |

> [!warning]
> 中心极限定理需要条件。强依赖、无限方差或重尾数据不能机械套用经典形式。

## Exam/Test Patterns

| 问法 | 标准回答 |
|---|---|
| 为什么频率可估计概率 | 伯努利大数定律 |
| 为什么样本均值稳定 | 大数定律 |
| 为什么许多误差近似正态 | 中心极限定理 |
| 样本均值方差 | $\sigma^2/n$ |
| 二项正态近似 | 均值 $np$、方差 $np(1-p)$，加连续性校正 |

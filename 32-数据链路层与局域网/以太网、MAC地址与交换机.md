# 以太网、MAC地址与交换机（★★★）

#computer-networks #data-link-layer #ethernet #mac-address #switching

## Overview Table

| 对象 | 工作层次 | 依据 | 核心功能 |
|---|---|---|---|
| 集线器 | 物理层 | 无地址判断 | 向其他端口广播比特 |
| 二层交换机 | 数据链路层 | MAC 地址表 | 学习、过滤、转发帧 |
| 路由器 | 网络层 | IP 路由/转发表 | 跨网络转发分组 |

## 交换机自学习

交换机收到帧后，用**源 MAC 地址和入端口**更新 MAC 表；再查目的 MAC：

    收到帧
      ↓ 学习 源MAC→入端口
    查目的MAC
      ├─ 已知且不同端口 → 定向转发
      ├─ 已知且同端口   → 过滤
      └─ 未知/广播       → 除入端口外泛洪

MAC 表项会老化，以适应主机移动或拓扑变化。交换机每个端口形成独立冲突域，但默认仍处于同一广播域；VLAN 可逻辑划分广播域。

## 以太网帧与地址

| 字段/概念 | 要点 |
|---|---|
| 目的/源 MAC | 通常各 48 bit |
| 类型/长度 | 指示上层协议或负载长度 |
| 数据 | 经典以太网通常 46–1500 B |
| FCS | CRC 差错检测 |

> [!warning]
> 交换机不保证端到端可靠传输，也不会像路由器那样默认隔离广播域。MAC 地址用于本地链路交付，跨网通信仍靠 IP 路由。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| 交换机如何学习 | 从收到帧的源 MAC 学习端口映射 |
| 未知目的 MAC | 除入端口外泛洪 |
| 交换机 vs 路由器 | MAC/链路层/广播域 vs IP/网络层/跨网转发 |

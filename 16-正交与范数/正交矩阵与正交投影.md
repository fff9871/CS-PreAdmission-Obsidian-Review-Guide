# 正交矩阵与正交投影（★★★）

#linear-algebra #inner-product #orthogonality

## Overview Table

| 对象 | 公式 | 意义 |
|---|---|---|
| 正交矩阵 | $Q^TQ=QQ^T=I$ | 保持长度与夹角 |
| 正交投影矩阵 | $P^2=P,P^T=P$ | 投到某子空间 |
| 投影到列空间 | $P=A(A^TA)^{-1}A^T$ | $A$ 列满秩 |

## 正交矩阵

$Q$ 正交，当且仅当它的列向量构成标准正交基，也等价于 $Q^{-1}=Q^T$。

$$\|Qx\|_2=\|x\|_2,qquad \langle Qx,Qy\rangle=\langle x,y\rangle.$$

因此实正交矩阵表示旋转、反射及其复合，$\det Q=\pm1$。

## 正交投影

若 $Q$ 的列是子空间 $W$ 的标准正交基，则

$$P_W=QQ^T,qquad \operatorname{proj}_W b=QQ^Tb.$$

若基矩阵 $A$ 只保证列满秩，则

$$P_W=A(A^TA)^{-1}A^T.$$

```text
b = 投影分量 p + 正交残差 r
p ∈ W
r ⟂ W
```

## 投影矩阵性质

| 性质 | 含义 |
|---|---|
| $P^2=P$ | 投影两次等于一次 |
| $P^T=P$ | 正交投影是对称算子 |
| 特征值为 0 或 1 | 分别对应被消去和保留的方向 |

> [!warning]
> “两个矩阵相乘为单位矩阵”说明互逆；只有方阵自身满足 $Q^TQ=I$ 才称正交矩阵。

## Exam/Test Patterns

| 关键词 | 回答 |
|---|---|
| “正交矩阵定义” | $Q^TQ=I$，列/行向量均为标准正交组 |
| “正交矩阵作用” | 保持长度、内积和角度 |
| “投影矩阵” | 幂等；正交投影还对称 |
| “最小二乘” | 预测值是 $b$ 在列空间上的正交投影 |

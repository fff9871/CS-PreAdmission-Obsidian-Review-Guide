# 向量范数与矩阵范数（★★★）

#linear-algebra #norms

## Overview Table

| 范数 | 向量/矩阵公式 |
|---|---|
| 向量 1-范数 | $\|x\|_1=\sum_i|x_i|$ |
| 向量 2-范数 | $\|x\|_2=(\sum_i|x_i|^2)^{1/2}$ |
| 向量无穷范数 | $\|x\|_\infty=\max_i|x_i|$ |
| 矩阵 1-范数 | 最大绝对列和 |
| 矩阵无穷范数 | 最大绝对行和 |
| 矩阵 2-范数 | 最大奇异值 |
| Frobenius 范数 | 元素平方和开方 |

## 范数公理

范数满足：

1. 非负性与正定性：$\|x\|\ge0$，且等号仅在 $x=0$；
2. 齐次性：$\|\alpha x\|=|\alpha|\|x\|$；
3. 三角不等式：$\|x+y\|\le\|x\|+\|y\|$。

一般 $p$-范数：

$$\|x\|_p=\left(\sum_i|x_i|^p\right)^{1/p},\quad p\ge1.$$

“0-范数”常用来表示非零元素个数，但严格来说不是范数。

## 诱导矩阵范数

$$\|A\|=\max_{x\ne0}\frac{\|Ax\|}{\|x\|}.$$

它自然满足相容性 $\|Ax\|\le\|A\|\|x\|$。谱范数为

$$\|A\|_2=\sqrt{\lambda_{\max}(A^TA)}=\sigma_{\max}(A).$$

Frobenius 范数通常不是由同一个向量范数诱导，但满足次乘性并广泛使用。

## 范数等价

有限维空间中所有范数拓扑等价，但数值大小和几何形状不同；例如 1-范数单位球是菱形，2-范数单位球是圆。

> [!warning]
> 矩阵 2-范数必须对 $A^TA$ 最大特征值开平方；不要与 Frobenius 范数混淆。

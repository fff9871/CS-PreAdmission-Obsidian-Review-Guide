# 单表查询、聚合与分组（★★★）

#database #sql #query

## Overview Table

| 项目 | 要点 |
|---|---|
| WHERE | 分组前过滤行 |
| GROUP BY | 按键形成分组 |
| HAVING | 聚合后过滤分组 |
| ORDER BY | 对最终结果排序 |
| DISTINCT | 消除结果中的重复行 |

## 逻辑执行顺序

FROM / JOIN
         ↓
       WHERE
         ↓
      GROUP BY
         ↓
       HAVING
         ↓
       SELECT
         ↓
   DISTINCT / ORDER BY / LIMIT

## 聚合与 NULL

COUNT(*) 统计行数；COUNT(列) 忽略 NULL。SUM、AVG 等通常忽略 NULL，整个输入为空时结果可能为 NULL。

## 分组规则

SELECT 中未聚合的列通常必须出现在 GROUP BY 中。需要按聚合值过滤时用 HAVING，而不是 WHERE。

> [!warning]
> SQL 的逻辑执行顺序不等于数据库实际物理执行顺序；优化器可在保持语义的前提下重排操作。

## Exam/Test Patterns

| 场景/关键词 | 回答 |
|---|---|
| WHERE 与 HAVING | WHERE 过滤行，HAVING 过滤分组 |
| COUNT(*) 与 COUNT(col) | 前者计行，后者忽略该列 NULL |
| TOP-N | ORDER BY 后限制结果，否则返回哪几行没有稳定语义 |

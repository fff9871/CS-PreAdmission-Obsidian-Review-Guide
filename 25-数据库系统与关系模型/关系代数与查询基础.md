# 关系代数与查询基础（★★★）

#database #relational-model #relational-algebra

## Overview Table

| 项目 | 要点 |
|---|---|
| 选择 σ | 按谓词筛选元组，相当于行过滤 |
| 投影 π | 选择属性列，并按集合语义消除重复 |
| 连接 ⋈ | 按条件组合两个关系中的元组 |
| 并/差/交 | 要求关系并相容 |
| 笛卡尔积 × | 组合所有元组对 |

## 基本运算

选择、投影、并、差和笛卡尔积可构成常见关系代数基本运算；交、连接、除可由基本运算推导。

## 连接的含义

θ 连接先做笛卡尔积再按条件选择；等值连接的条件只含等号；自然连接还会合并同名属性并按同名属性相等匹配。

## 关系代数与 SQL

关系代数是过程化运算表达；SQL 更接近声明式语言。查询优化器可把 SQL 转换为关系代数表达式并做等价变换。

> [!warning]
> 投影在经典关系代数中自动去重；SQL 的 SELECT 默认保留重复，需要 DISTINCT 才去重。

## Exam/Test Patterns

| 场景/关键词 | 回答 |
|---|---|
| 选择下推 | 尽早过滤行，减少中间结果 |
| 投影下推 | 尽早去掉无用列，但要保留后续连接所需属性 |
| 自然连接 | 同名属性相等连接并合并重复列 |

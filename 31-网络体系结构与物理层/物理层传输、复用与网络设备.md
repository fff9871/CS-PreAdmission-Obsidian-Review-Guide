# 物理层传输、复用与网络设备（★★★）

#computer-networks #physical-layer #multiplexing

## Overview Table

| 主题 | 分类 | 关键点 |
|---|---|---|
| 传输方向 | 单工、半双工、全双工 | 是否允许双向及同时双向 |
| 传输时钟 | 同步、异步通信 | 是否以连续时钟/帧组织数据 |
| 复用 | FDM、TDM、WDM、CDM | 频率、时间、波长、码字维度共享介质 |
| 一层设备 | 中继器、集线器 | 再生/广播比特，不识别帧和 IP |

## 四种复用

| 技术 | 划分资源 | 典型理解 |
|---|---|---|
| FDM | 不同频带 | 多路信号同时占用不同频率 |
| TDM | 不同时隙 | 用户轮流占用全部频带 |
| WDM | 不同光波长 | 光纤中的“频分复用” |
| CDM/CDMA | 正交码片序列 | 用户可同时同频传输，以码区分 |

    共享信道
      ├─ 频率分片 → FDM
      ├─ 时间分片 → TDM
      ├─ 光波长分片 → WDM
      └─ 码字区分 → CDM

## 中继器与集线器

- **中继器**再生衰减信号，延长物理距离。
- **集线器**可看作多端口中继器，收到比特后向其他端口广播。
- 二者不学习 MAC 地址，不能隔离冲突域，链路带宽由端口共享。

> [!warning]
> “同步/异步”在数据通信、程序调用和分布式系统中含义不同。答题时先限定语境；物理层语境主要关注字符/帧边界和时钟同步方式。

## Exam/Test Patterns

| 场景/关键词 | 回答 |
|---|---|
| 光纤多路复用 | WDM，按波长区分 |
| 集线器工作层次 | 物理层；广播比特；不隔离冲突域 |
| 同步通信 | 按连续数据块传输并保持时钟同步，效率较高但同步复杂 |

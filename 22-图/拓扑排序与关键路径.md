# 拓扑排序与关键路径（★★★）

#data-structures #graphs #dag

## Overview Table

| 主题 | 对象 | 结果 |
|---|---|---|
| 拓扑排序 | 有向无环图 DAG | 满足每条边 $u\to v$ 中 $u$ 在 $v$ 之前的线性序 |
| AOV 网 | 顶点表示活动 | 用拓扑序表示先后约束 |
| AOE 网 | 边表示活动、顶点表示事件 | 关键路径决定工期 |

## Kahn 拓扑排序

```text
将所有入度 0 顶点入队
while 队非空:
  取出 u 并输出
  删除 u 的出边；新的入度 0 顶点入队
输出数 < V → 图中有环
```

拓扑序未必唯一。若某一步同时有多个入度 0 顶点，不同选择可产生不同合法序列。

## 关键路径

- 计算事件的最早发生时间 `ve`（按拓扑序正向）。
- 计算事件的最迟发生时间 `vl`（按逆拓扑序反向）。
- 活动的最早开始等于其起点 `ve`，最迟开始由终点 `vl` 减活动时长。
- 时间余量为 0 的活动是关键活动。

> [!warning]
> 关键路径可以不唯一；缩短一条关键活动也不一定缩短总工期，因为可能有多条并列关键路径。

## Exam/Test Patterns

| 提问 | 回答 |
|---|---|
| 用拓扑排序判环 | 最终处理顶点数小于 $V$ 则有环 |
| 拓扑序唯一 | 每步只有一个可选的入度 0 顶点是常用判据 |
| 关键活动 | 最早开始时间=最迟开始时间 |

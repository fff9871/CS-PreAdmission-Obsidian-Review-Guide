# 检查点、迁移学习与可复现训练（★★★）

#machine-learning #pytorch #checkpointing #reproducibility

## Overview Table

| 状态 | 是否建议保存 |
|---|---|
| model state_dict | 是 |
| optimizer state_dict | 继续训练需要 |
| scheduler/scaler state | 继续训练需要 |
| epoch/global step | 是 |
| best metric/config | 是 |
| RNG states | 严格恢复时需要 |

## 恢复训练

    build same model/optimizer
      → load states
      → restore step/scheduler/scaler/RNG
      → set train mode
      → continue

迁移学习加载预训练 backbone 后替换任务头；可用 `strict=False` 处理预期的键差异，但必须检查 missing/unexpected keys。

## 可复现性

固定 Python/NumPy/PyTorch/DataLoader 随机种子，记录依赖和硬件；启用确定性算法可能降低性能，且不同设备/版本仍可能有浮点差异。

> [!warning]
> 只保存模型权重无法精确恢复带动量优化器、学习率调度和混合精度状态；“固定随机种子”也不保证跨平台逐位一致。

## Exam/Test Patterns

| 场景 | 保存 |
|---|---|
| 仅部署推理 | 模型state_dict + 配置/预处理 |
| 断点续训 | 模型、优化器、调度器、scaler、step |
| 最佳模型 | 按验证指标保存，不只最后epoch |

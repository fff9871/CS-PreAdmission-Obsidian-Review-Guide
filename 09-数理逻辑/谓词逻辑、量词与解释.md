# 谓词逻辑、量词与解释（★★★）

#discrete-mathematics #logic #predicate-logic

## Overview Table

| 概念 | 含义 | 示例 |
|---|---|---|
| 谓词 | 含变量、代入后成为命题 | $P(x):x>0$ |
| 全称量词 | 对域中所有元素成立 | $\forall xP(x)$ |
| 存在量词 | 域中至少一个元素成立 | $\exists xP(x)$ |
| 辖域 | 量词实际控制的公式范围 | $\forall x(P(x)\to Q(x))$ |
| 解释 | 为常量、函数、谓词指定语义 | 指定个体域和符号含义 |

## 从命题到谓词

命题逻辑把简单命题视作整体；谓词逻辑进一步分析“对象具有什么性质、对象之间有什么关系”。

```text
个体域 + 常量/函数/谓词的解释
            ↓
         谓词公式
            ↓ 赋值
           真值
```

## 自由变元与约束变元

量词辖域内与量词变量同名的出现是**约束出现**；没有被量词约束的是**自由出现**。含自由变元的公式通常不是封闭命题，其真值还依赖变量赋值。

> [!warning]
> 变量名可以在不捕获自由变量的前提下改名；替换时必须避免变量捕获。

## 量词否定与顺序

$$\neg\forall xP(x)\equiv\exists x\neg P(x),$$
$$\neg\exists xP(x)\equiv\forall x\neg P(x).$$

$\forall x\exists yP(x,y)$ 表示每个 $x$ 可选择自己的 $y$；$\exists y\forall xP(x,y)$ 要求一个统一的 $y$，后者通常更强。

## 解释与逻辑分类

| 概念 | 条件 |
|---|---|
| 在解释 $I$ 下为真 | 按 $I$ 指定的域和符号语义求值为真 |
| 可满足 | 至少存在一个解释使公式为真 |
| 永真/有效 | 每个适当解释下都真 |
| 逻辑蕴含 | $P\models Q$：每个使 $P$ 真的解释也使 $Q$ 真 |

## 中文翻译模板

| 中文 | 逻辑式 |
|---|---|
| 所有学生都通过了 | $\forall x(Student(x)\to Pass(x))$ |
| 有学生通过了 | $\exists x(Student(x)\land Pass(x))$ |
| 没有学生通过 | $\forall x(Student(x)\to\neg Pass(x))$ |
| 并非所有学生都通过 | $\exists x(Student(x)\land\neg Pass(x))$ |

## Exam/Test Patterns

| 题型关键词 | 回答 |
|---|---|
| “否定全称命题” | 换成存在量词，并否定谓词 |
| “量词顺序能否交换” | 同类量词可交换；全称与存在一般不可交换 |
| “自由变元” | 不在对应量词辖域内的变量出现 |
| “解释是什么” | 给个体域及非逻辑符号赋予具体语义 |

# 推理规则与证明方法（★★★）

#discrete-mathematics #logic #proof-methods

## Overview Table

| 规则 | 前提 | 结论 |
|---|---|---|
| 假言推理 MP | $p,p\to q$ | $q$ |
| 拒取式 MT | $p\to q,\neg q$ | $\neg p$ |
| 假言三段论 | $p\to q,q\to r$ | $p\to r$ |
| 析取三段论 | $p\lor q,\neg p$ | $q$ |
| 合取消去 | $p\land q$ | $p$ 或 $q$ |

## 推理的语义基础

从前提集合 $\Gamma$ 推出结论 $q$，要求不存在“所有前提都真而结论假”的解释，即

$$\Gamma\models q.$$

当且仅当 $\bigwedge\Gamma\land\neg q$ 不可满足。

## 证明方法

| 方法 | 操作 |
|---|---|
| 直接证明 | 从前提出发连续使用推理规则 |
| 条件证明 | 为证 $p\to q$，暂设 $p$ 并推出 $q$ |
| 逆否证明 | 为证 $p\to q$，证明 $\neg q\to\neg p$ |
| 反证法 | 暂设结论否定，推出矛盾 |
| 分情况 | 证明各互斥且穷尽情况都得到结论 |

```text
前提
 ↓ 合法推理规则
中间结论
 ↓
目标结论
```

## 常见谬误

| 错误形式 | 名称 | 为什么错 |
|---|---|---|
| $p\to q,q\vdash p$ | 肯定后件 | $q$ 可能由别的原因造成 |
| $p\to q,\neg p\vdash\neg q$ | 否定前件 | 前件不发生不代表后件不发生 |

## 量词推理边界

- 全称实例化：由 $\forall xP(x)$ 可得任意特定对象 $a$ 的 $P(a)$。
- 存在实例化：可引入一个新常元代表某个见证，但不能把它当作任意对象。
- 全称推广：待推广对象不能依赖未解除的特殊假设。

> [!warning]
> 推理规则的形式相似不代表可以反向使用；尤其要区分 MP、MT 与两种谬误。

## Exam/Test Patterns

| 题型关键词 | 回答 |
|---|---|
| “三段论” | 报出假言三段论或经典大前提—小前提—结论结构 |
| “反证法依据” | 前提与结论否定合取不可满足 |
| “肯定后件” | 无效推理，给出“下雨则地湿，地湿未必下雨” |
| “证明蕴含” | 可用条件证明或逆否证明 |

# 主存编址、扩展与多模块交叉（★★★）

#computer-organization #memory-hierarchy #main-memory #memory-interleaving

## Overview Table

| 主题 | 核心关系 |
|---|---|
| 按字节编址 | 每个地址对应 1 B |
| 按字编址 | 每个地址对应一个机器字 |
| 地址线数 | n 根地址线最多选择 `2^n` 个地址单元 |
| 位扩展 | 多芯片并联数据位，增加字长 |
| 字扩展 | 片选不同芯片，增加地址单元数 |
| 双端口存储器 | 两套独立地址/数据/控制端口，可并行访问不同单元 |
| 多体低位交叉 | 连续地址分布到不同模块，流水访问提高带宽 |

## 存储器扩展

    地址高位 ─→ 译码/片选 ─→ 选择某组芯片（字扩展）
    地址低位 ───────────→ 芯片内部单元
    多片数据端并联 ─────→ 扩大一次读写位数（位扩展）

例如用 `1K×8` 芯片组成 `4K×16` 存储器：字数扩大 4 倍、字长扩大 2 倍，共需 `4×2=8` 片。

## 双端口与多模块并行

双端口 RAM 通过两套端口支持两个主设备并行访问；若同时访问同一单元且包含写操作，需要冲突检测和优先规则。多模块存储器则把地址空间分散到多个存储体，通过并行启动不同体提高带宽。

## 交叉存储

低位交叉以低地址位选择存储体，使连续地址落入不同体，可在一个体完成恢复前启动另一个体访问；高位交叉更像按地址段分体，适合容量扩展但连续带宽优势较弱。

> [!warning]
> 多体交叉提高的是连续访问吞吐量，不必然降低单次访问延迟。若访问步长与体数产生冲突，多个请求仍可能集中到同一存储体。

## Exam/Test Patterns

| 问法 | 回答步骤 |
|---|---|
| 芯片数量 | 分别计算字扩展倍数和位扩展倍数后相乘 |
| 地址线分配 | 低位进芯片，高位参与片选；交叉方式另行判断 |
| 多体低位交叉 | 连续地址轮流落到不同存储体 |

# 虚拟存储、页表与TLB（★★★）

#computer-organization #memory-hierarchy #virtual-memory #page-table #tlb

## Overview Table

| 概念 | 作用 |
|---|---|
| 虚拟地址 | 程序使用的地址，由虚页号与页内偏移组成 |
| 页表 | 记录虚页到物理页框的映射及权限/状态 |
| TLB | 缓存近期页表项，加速地址翻译 |
| 缺页异常 | 所需页不在主存，转入操作系统调页 |
| 页面置换 | 主存页框不足时选择换出页 |

## 地址翻译

    虚拟地址 [VPN | Offset]
             ↓ 查TLB
       命中 ─────────────→ [PPN | Offset]
       未命中 → 查页表
                   ├─ 在内存 → 回填TLB
                   └─ 不在内存 → 缺页异常→磁盘调页

TLB 命中/缺失描述地址翻译缓存；Cache 命中/缺失描述数据块是否在高速缓存。二者可能组合出现，不能混为一谈。

## 段式与段页式

- **分页**按固定大小页面管理，便于离散分配并减少外部碎片。
- **分段**按代码、数据、栈等逻辑单元管理，便于保护和共享，但可能产生外部碎片。
- **段页式**先用段号找到段的页表，再以页号完成映射，结合逻辑分段与分页分配。

## 有效访问时间

简化模型中，TLB 命中只需一次主存访问数据，TLB 未命中还需访问页表；多级页表、Cache 和硬件页表遍历会改变具体次数。缺页代价远大于普通 TLB/Cache 缺失，因为涉及辅存 I/O。

> [!warning]
> 虚拟存储的主要目标不仅是“扩大内存”，还包括地址空间隔离、保护、共享和简化装载。页大小增大可减小页表，但会增加内部碎片和缺页传输量。

## Exam/Test Patterns

| 关键词 | 回答 |
|---|---|
| TLB 是什么 | 页表项的高速缓存 |
| TLB miss | 查页表，不一定缺页 |
| Page fault | 页表表明页面不在主存，需要操作系统处理 |

# 树、二叉树与基本性质（★★★）

#data-structures #trees

## Overview Table

| 概念 | 关键定义 |
|---|---|
| 树 | $n$ 个结点的有限集，非空时有唯一根，其余结点分属于互不相交的子树 |
| 二叉树 | 每个结点至多有左、右两棵有序子树 |
| 满二叉树 | 每层结点数都达到最大 |
| 完全二叉树 | 除最后一层外均满，最后一层从左向右连续 |

## 常用性质

- 非空树有 $n-1$ 条边。
- 二叉树中，若 $n_0$ 为叶结点数、$n_2$ 为度 2 结点数，则 $n_0=n_2+1$。
- 第 $i$ 层最多 $2^{i-1}$ 个结点（根为第 1 层）。
- 高度为 $h$ 的二叉树最多 $2^h-1$ 个结点。
- 含 $n$ 个结点的完全二叉树高度为 $\lfloor\log_2 n\rfloor+1$。

```text
一般树 ─孩子兄弟表示→ 二叉链表
结点: [firstChild | data | nextSibling]
```

> [!warning]
> 二叉树不是“度不超过 2 的树”这么简单：它的左右子树有顺序，即使只有一棵子树也要区分左右。

## Exam/Test Patterns

| 题型 | 方法 |
|---|---|
| 由度数求叶子 | 用结点数与边数的两种计数建立等式 |
| 完全二叉树下标 | 对 1 起始下标，左孩子 $2i$，右孩子 $2i+1$ |
| 满与完全的区别 | 满二叉树一定完全，反之不一定 |

# B树、B+树与外存索引（★★★）

#data-structures #trees #multiway-search-tree

## Overview Table

| 维度 | B 树 | B+ 树 |
|---|---|---|
| 数据位置 | 内部结点和叶结点都可存记录 | 记录集中在叶结点，内部结点主要存索引 |
| 搜索结束 | 可在非叶结点结束 | 通常到叶结点结束，路径长度更稳定 |
| 范围查询 | 需在树中多次导航 | 叶子按键有序串联，顺序扫描高效 |
| 扇出 | 内部结点带记录，通常较小 | 内部结点更紧凑，通常更大 |

## 为什么适合数据库

```text
一个结点 ≈ 一个磁盘/页块
更大扇出 → 更矮的树 → 更少的随机 I/O
叶子有序链 → 范围查询只需定位起点后顺序读
```

## m 阶约束

“m 阶”常表示结点最多有 $m$ 个孩子。B 树的非根内部结点通常至少有 $\lceil m/2\rceil$ 个孩子，关键字数是孩子数减 1。但教材对“阶”和根结点下界的记号可略有差异。

> [!warning]
> B 树不是“二叉树”，其 B 也不应解读为 Binary。B+ 树叶子之间的有序链接是范围查询的关键。

## Exam/Test Patterns

| 追问 | 回答链 |
|---|---|
| “为何不用 AVL” | 外存访问以块为单位，多路树扇出大、高度低、I/O 少 |
| “B+ 树范围查询” | 先定位最小键叶子，再沿叶链扫描 |
| “B 树与 B+ 树” | 比数据位置、搜索路径、叶链和扇出 |

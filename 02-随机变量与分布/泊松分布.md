# 泊松分布（★★★）

#probability #distributions

## Overview Table

| 项目 | 内容 |
|---|---|
| 场景 | 固定时间/面积内事件发生次数 |
| 参数 | 平均发生次数 $\lambda$ |
| 取值 | $0,1,2,\ldots$ |
| 期望 | $\lambda$ |
| 方差 | $\lambda$ |

## 概率质量函数

$$P(X=k)=e^{-\lambda}\frac{\lambda^k}{k!}$$

$\lambda$ 表示观察区间中的平均事件数。如果单位时间速率为 $r$，观察长度为 $t$，通常有 $\lambda=rt$。

## 典型假设

- 不重叠区间中的事件数近似独立。
- 平均发生速率稳定。
- 极短区间内发生两个及以上事件的概率可忽略。

## 与二项分布的关系

当 $n$ 很大、$p$ 很小、$np=\lambda$ 时：

$$B(n,p)\approx Poisson(\lambda)$$

这对应“大量机会中，每次发生概率很小”的稀有事件模型。

## 与指数分布的关系

在泊松过程中：

- 固定时间内的事件数服从泊松分布。
- 相邻事件的等待时间服从 [[指数分布]]。

> [!warning]
> 现实数据如果方差显著大于均值，简单泊松模型可能不合适，这称为过度离散。

## Exam/Test Patterns

| 关键词 | 标准回答 |
|---|---|
| 单位时间内请求数 | 泊松分布 |
| 参数 $\lambda$ | 区间内平均发生次数，同时也是方差 |
| 二项近似条件 | $n$ 大、$p$ 小、$np$ 有限 |
| 等待下一次事件 | 指数分布而不是泊松分布 |

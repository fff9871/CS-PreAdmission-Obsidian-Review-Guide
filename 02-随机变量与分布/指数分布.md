# 指数分布（★★★）

#probability #distributions

## Overview Table

| 项目  | 内容              |
| --- | --------------- |
| 场景  | 泊松过程中等待下一次事件的时间 |
| 参数  | 事件速率 $\lambda$  |
| 取值  | $x\ge0$         |
| 期望  | $1/\lambda$     |
| 方差  | $1/\lambda^2$   |

## 密度、分布函数与尾概率

$$f(x)=\lambda e^{-\lambda x},\qquad x\ge0$$

$$F(x)=1-e^{-\lambda x}$$

$$P(X>x)=e^{-\lambda x}$$

## 无记忆性

$$P(X>s+t\mid X>s)=P(X>t)$$

已经等待了多久，不改变继续等待的分布。连续分布中，指数分布是典型的无记忆分布。

## 与泊松分布的关系

```text
同一个泊松过程
├─ 长度 t 的区间内发生几次 -> Poisson(λt)
└─ 等待下一次发生多久     -> Exponential(λ)
```

> [!warning]
> 指数分布假定危险率恒定。具有老化、磨损效应的寿命数据通常不适合直接使用指数分布。

## Exam/Test Patterns

| 关键词 | 标准回答 |
|---|---|
| 等待下一次到达 | 指数分布 |
| 无记忆性 | $P(X>s+t\mid X>s)=P(X>t)$ |
| 平均等待时间 | $1/\lambda$ |
| 固定区间事件数 | 泊松分布 |

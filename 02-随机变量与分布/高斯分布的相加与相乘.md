# 高斯分布的相加与相乘（★★★）

#probability #distributions

## Overview Table

| 操作 | 条件 | 结论 |
|---|---|---|
| 高斯随机变量相加 | 独立或联合高斯 | 仍为高斯 |
| 高斯随机变量线性组合 | 联合高斯 | 仍为高斯 |
| 两个高斯随机变量直接相乘 | 一般情况 | 通常不是高斯 |
| 两个关于同一变量的高斯密度相乘 | 归一化 | 仍为高斯密度 |

## 独立高斯变量之和

若：

$$X_i\sim N(\mu_i,\sigma_i^2)$$

且相互独立，则：

$$\sum_iX_i\sim N\left(\sum_i\mu_i,\sum_i\sigma_i^2\right)$$

若 $X,Y$ 不独立：

$$Var(X+Y)=Var(X)+Var(Y)+2Cov(X,Y)$$

## 联合高斯的线性组合

若随机向量：

$$X\sim N(\mu,\Sigma)$$

则：

$$a^TX+b\sim N(a^T\mu+b,a^T\Sigma a)$$

## 高斯密度的乘积

对同一个未知量 $x$：

$$N(x;\mu_1,\sigma_1^2)N(x;\mu_2,\sigma_2^2)\propto N(x;\mu,\sigma^2)$$

其中：

$$\frac1{\sigma^2}=\frac1{\sigma_1^2}+\frac1{\sigma_2^2}$$

$$\mu=\sigma^2\left(\frac{\mu_1}{\sigma_1^2}+\frac{\mu_2}{\sigma_2^2}\right)$$

方差越小，精度 $1/\sigma^2$ 越大，对融合后均值的影响越大。

```text
先验高斯 × 似然高斯
        ↓ 精度相加
      后验高斯
```

> [!warning]
> “密度函数相乘”与“随机变量取值相乘”是两件事。$XY$ 通常不服从正态分布。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| 多个独立高斯的和 | 高斯；均值、方差分别相加 |
| 一般相关变量之和 | 方差需加入协方差项 |
| 高斯变量的乘积 | 通常不是高斯 |
| 高斯密度的乘积 | 归一化后是高斯，精度相加 |
| 为什么贝叶斯高斯模型方便 | 共轭更新后仍为高斯 |

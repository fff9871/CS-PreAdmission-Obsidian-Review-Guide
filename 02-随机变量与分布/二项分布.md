# 二项分布（★★★）

#probability #distributions

## Overview Table

| 项目 | 内容 |
|---|---|
| 场景 | $n$ 次独立重复试验中的成功次数 |
| 参数 | 试验次数 $n$、成功概率 $p$ |
| 取值 | $0,1,\ldots,n$ |
| 期望 | $np$ |
| 方差 | $np(1-p)$ |

## 概率质量函数

若 $X\sim B(n,p)$：

$$P(X=k)=\binom nkp^k(1-p)^{n-k}$$

组合数表示成功出现在哪 $k$ 次，后两项表示某一种排列发生的概率。

## 成立条件

1. 试验次数固定为 $n$。
2. 每次只有成功和失败。
3. 各次试验相互独立。
4. 每次成功概率都为 $p$。

```text
X1, X2, ..., Xn 独立且 Xi ~ Bernoulli(p)
                    ↓
          X = ΣXi ~ Binomial(n,p)
```

## 常用近似

- $n$ 大、$p$ 小且 $np=\lambda$：$B(n,p)\approx Poisson(\lambda)$。
- $np$、$n(1-p)$ 足够大：$B(n,p)\approx N(np,np(1-p))$。

> [!warning]
> 使用正态近似计算整数事件时，通常需要连续性校正，例如 $P(X\le k)\approx P(Y\le k+0.5)$。

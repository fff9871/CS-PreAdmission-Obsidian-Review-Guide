# 几何分布（★★）

#probability #distributions

## Overview Table

| 项目 | 内容 |
|---|---|
| 场景 | 第一次成功出现所需的试验次数 |
| 参数 | 每次成功概率 $p$ |
| 取值 | $1,2,3,\ldots$ |
| 期望 | $1/p$ |
| 方差 | $(1-p)/p^2$ |

## 概率质量函数

要使第一次成功发生在第 $k$ 次，前 $k-1$ 次必须失败，第 $k$ 次成功：

$$P(X=k)=(1-p)^{k-1}p$$

尾概率：

$$P(X>k)=(1-p)^k$$

## 无记忆性

$$P(X>s+t\mid X>s)=P(X>t)$$

已经失败了多少次，不改变未来还要等待多久的分布。这要求每次试验独立且成功概率不变。

## 参数约定

有些教材把“成功前的失败次数”定义为几何随机变量，此时取值从 0 开始。面试时应主动说明采用哪种定义。

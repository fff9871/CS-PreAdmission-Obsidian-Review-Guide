# 负二项分布（★★）

#probability #distributions

## Overview Table

| 项目 | 内容 |
|---|---|
| 场景 | 第 $r$ 次成功出现所需的总试验次数 |
| 参数 | 成功次数 $r$、成功概率 $p$ |
| 取值 | $r,r+1,\ldots$ |
| 期望 | $r/p$ |
| 方差 | $r(1-p)/p^2$ |

## 概率质量函数

若 $X$ 表示第 $r$ 次成功发生时的总试验次数，则：

$$P(X=k)=\binom{k-1}{r-1}p^r(1-p)^{k-r},\qquad k\ge r$$

解释：第 $k$ 次必须成功，前 $k-1$ 次中恰有 $r-1$ 次成功。

## 与几何分布的关系

- $r=1$ 时，负二项分布退化为 [[几何分布]]。
- 第 $r$ 次成功的等待时间，可看作 $r$ 个独立几何变量之和。

## 另一种参数化

部分教材令随机变量表示“第 $r$ 次成功前的失败次数”，此时取值从 0 开始，公式会相应平移。答题时必须声明定义。

> [!tip]
> 负二项分布也常用于方差大于均值的计数数据建模，但其参数解释可能与“等待第 $r$ 次成功”不同。

## Exam/Test Patterns

| 关键词 | 标准回答 |
|---|---|
| 第 $r$ 次成功需要多少次 | 负二项分布 |
| $r=1$ | 几何分布 |
| 公式中的 $\binom{k-1}{r-1}$ | 前 $k-1$ 次选出 $r-1$ 次成功 |
| 参数化争议 | 说明变量表示总试验次数还是失败次数 |

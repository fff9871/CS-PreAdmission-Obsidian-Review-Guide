# 均匀分布（★★★）

#probability #distributions

## Overview Table

| 项目 | 内容 |
|---|---|
| 场景 | 区间中各等长子区间概率相同 |
| 参数 | 下界 $a$、上界 $b$ |
| 密度 | $1/(b-a)$ |
| 期望 | $(a+b)/2$ |
| 方差 | $(b-a)^2/12$ |

## 密度与分布函数

若 $X\sim U(a,b)$：

$$f_X(x)=\begin{cases}\frac1{b-a},&a<x<b\\0,&\text{其他}\end{cases}$$

$$F_X(x)=\begin{cases}0,&x\le a\\\frac{x-a}{b-a},&a<x<b\\1,&x\ge b\end{cases}$$

区间概率就是长度比例：

$$P(c<X<d)=\frac{d-c}{b-a}$$

## 标准均匀分布的重要性

$U(0,1)$ 是随机数生成的基础。通过逆变换法：

$$X=F^{-1}(U),\qquad U\sim U(0,1)$$

可以从均匀随机数生成许多目标分布。

## 线性变换

若 $U\sim U(0,1)$，则：

$$X=a+(b-a)U\sim U(a,b)$$

> [!warning]
> “所有实数取值等可能”的均匀分布不存在；均匀分布必须定义在有限区间或离散有限集合上。

## Exam/Test Patterns

| 关键词 | 标准回答 |
|---|---|
| 区间内等密度 | 连续均匀分布 |
| 区间概率 | 子区间长度除以总长度 |
| $U(0,1)$ 的用途 | 逆变换、接受拒绝、Box-Muller 等随机生成 |
| 从 $U(0,1)$ 到 $U(a,b)$ | $a+(b-a)U$ |

# 伯努利分布（★★★）

#probability #distributions

## Overview Table

| 项目  | 内容            |
| --- | ------------- |
| 场景  | 一次试验只有成功/失败   |
| 取值  | $X\in\{0,1\}$ |
| 参数  | 成功概率 $p$      |
| 期望  | $p$           |
| 方差  | $p(1-p)$      |

## 定义与公式

$$P(X=x)=p^x(1-p)^{1-x},\qquad x\in\{0,1\}$$

令成功为 1、失败为 0，则：

$$E[X]=0(1-p)+1p=p$$

$$Var(X)=p(1-p)$$

## 建模含义

伯努利变量是“事件指示器”。若 $I_A=1$ 表示事件 $A$ 发生，则：

$$E[I_A]=P(A)$$

这使复杂计数问题可以写成多个指示变量之和。

> [!tip]
> 二分类标签、一次点击、一次检验是否通过，都可先考虑伯努利分布。

## 与其他分布的关系

- $n$ 个独立同参数伯努利变量之和服从 [[二项分布]]。
- Bernoulli$(p)$ 是 Binomial$(1,p)$。
- 伯努利试验重复到首次成功得到 [[几何分布]]。

> [!warning]
> “只有两个取值”不一定意味着取值必须写成 0 和 1；编码为 0/1 后才直接使用上述期望和方差。

## Exam/Test Patterns

| 关键词 | 标准回答 |
|---|---|
| 一次成功/失败 | 伯努利分布 |
| 0-1 分布、两点分布 | 通常指伯努利分布 |
| 指示变量期望 | 等于对应事件概率 |
| 方差最大时 | $p=1/2$，最大方差为 $1/4$ |

# 正态分布（★★★）

#probability #distributions

## Overview Table

| 项目 | 内容 |
|---|---|
| 记号 | $X\sim N(\mu,\sigma^2)$ |
| 形状 | 关于 $\mu$ 对称的钟形曲线 |
| 期望 | $\mu$ |
| 方差 | $\sigma^2$ |
| 典型来源 | 多个小而近似独立的扰动叠加 |

## 概率密度

$$f(x)=\frac1{\sqrt{2\pi}\sigma}\exp\left[-\frac{(x-\mu)^2}{2\sigma^2}\right]$$

$\mu$ 控制中心，$\sigma$ 控制尺度。约有：

- $68.3\%$ 落在 $\mu\pm\sigma$；
- $95.4\%$ 落在 $\mu\pm2\sigma$；
- $99.7\%$ 落在 $\mu\pm3\sigma$。

## 标准化

$$Z=\frac{X-\mu}{\sigma}\sim N(0,1)$$

标准化将任意正态变量转换为标准正态变量，便于查表或计算尾概率。

## 线性变换与线性组合

若 $X\sim N(\mu,\sigma^2)$：

$$aX+b\sim N(a\mu+b,a^2\sigma^2)$$

若随机向量 $X$ 联合高斯，则任意线性组合 $a^TX$ 仍为高斯。

## 为什么常见

- 中心极限定理使大量独立小扰动之和趋近正态。
- 数学上对线性运算封闭。
- 只需均值和协方差即可描述单峰对称高斯模型。

> [!warning]
> 数据呈钟形并不足以证明正态；厚尾、偏态和多峰数据可能需要其他模型。

## Exam/Test Patterns

| 关键词 | 标准回答 |
|---|---|
| 标准化 | 减均值再除以标准差 |
| 多个独立高斯之和 | 仍为高斯，均值相加、方差相加 |
| 误差叠加 | 中心极限定理常导致近似正态 |
| 联合高斯且不相关 | 可以推出独立 |

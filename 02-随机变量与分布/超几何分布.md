# 超几何分布（★★★）

#probability #distributions

## Overview Table

| 项目 | 内容 |
|---|---|
| 场景 | 有限总体中不放回抽样 |
| 总体 | $N$ 个对象，其中 $M$ 个目标对象 |
| 抽样 | 不放回抽取 $n$ 个 |
| 随机变量 | 抽到目标对象的数量 $X$ |
| 期望 | $nM/N$ |

## 概率质量函数

$$P(X=k)=\frac{\binom Mk\binom{N-M}{n-k}}{\binom Nn}$$

分子表示从目标对象中选出 $k$ 个，同时从非目标对象中选出 $n-k$ 个；分母表示所有抽法。

## 方差

令 $p=M/N$：

$$Var(X)=np(1-p)\frac{N-n}{N-1}$$

最后一项叫**有限总体修正因子**，反映不放回抽样带来的依赖性。

## 与二项分布比较

| 特征 | 超几何 | 二项 |
|---|---|---|
| 抽样方式 | 不放回 | 放回或独立重复 |
| 成功概率 | 随抽样变化 | 固定为 $p$ |
| 各次试验 | 不独立 | 独立 |
| 总体很大、样本很小 | 可近似二项 | 直接使用 |

> [!tip]
> 看见“从一批产品中随机抽取若干件，且不放回”，优先想到超几何分布。

## Exam/Test Patterns

| 关键词 | 标准回答 |
|---|---|
| 不放回抽样 | 超几何分布 |
| 总体 $N$、目标数 $M$、抽取 $n$ | 使用组合数公式 |
| 与二项的核心区别 | 是否独立、成功概率是否保持不变 |
| 有限总体修正 | $(N-n)/(N-1)$ |

# 分布总览与选择（★★★）

#probability #random-variables #distributions

## Overview Table

| 问题特征 | 首选分布 | 关键条件 |
|---|---|---|
| 一次成功/失败 | [[伯努利分布]] | 两种结果 |
| $n$ 次中成功几次 | [[二项分布]] | 独立、成功率不变 |
| 固定区间内发生几次 | [[泊松分布]] | 稀疏、近似独立、平均速率稳定 |
| 不放回抽样命中几次 | [[超几何分布]] | 有限总体、不放回 |
| 首次成功要几次 | [[几何分布]] | 独立伯努利试验 |
| 第 $r$ 次成功要几次 | [[负二项分布]] | 独立伯努利试验 |
| 有限区间等可能取值 | [[均匀分布]] | 连续且密度恒定 |
| 多个微小因素叠加 | [[正态分布]] | 对称连续、中心聚集 |
| 等待下一次事件多久 | [[指数分布]] | 泊松过程等待时间 |

## 选择流程

```text
变量是离散的吗？
├─ 是
│  ├─ 一次成败 -> 伯努利
│  ├─ 固定次数内成功数
│  │  ├─ 独立/放回 -> 二项
│  │  └─ 不放回 -> 超几何
│  ├─ 固定时间内事件数 -> 泊松
│  └─ 等到成功的试验次数
│     ├─ 第一次成功 -> 几何
│     └─ 第 r 次成功 -> 负二项
└─ 否
   ├─ 区间内等密度 -> 均匀
   ├─ 对称钟形/误差叠加 -> 正态
   └─ 等待下一次事件 -> 指数
```

## 分布之间的联系

| 联系 | 条件 | 结论 |
|---|---|---|
| 二项近似泊松 | $n$ 大、$p$ 小、$np=\lambda$ | $B(n,p)\approx Poisson(\lambda)$ |
| 二项近似正态 | $np,n(1-p)$ 足够大 | $B(n,p)\approx N(np,np(1-p))$ |
| 超几何近似二项 | 总体远大于样本 | 不放回依赖可忽略 |
| 泊松与指数 | 泊松过程 | 计数服从泊松，等待时间服从指数 |
| 几何与指数 | 离散/连续 | 都具有无记忆性 |

> [!warning]
> “题目长得像”不足以选分布，必须先判断独立性、是否放回、变量是次数还是等待时间。

## Exam/Test Patterns

| 题面词语 | 典型分布 |
|---|---|
| 每次成功概率相同、重复 $n$ 次 | 二项 |
| 总体中抽取且不放回 | 超几何 |
| 单位时间内电话/故障/请求数量 | 泊松 |
| 首次成功、第 $r$ 次成功 | 几何、负二项 |
| 寿命、到达间隔 | 指数 |
| 测量误差、多个小扰动之和 | 正态 |

# 生产者消费者、读者写者与哲学家（★★★）

#operating-systems #concurrency-control #semaphore #classic-synchronization

## Overview Table

| 问题 | 资源/约束 | 常见信号量 |
|---|---|---|
| 有界缓冲区 | 空槽、产品、缓冲区互斥 | `empty=N, full=0, mutex=1` |
| 读者写者 | 多读单写 | 读者计数锁、资源锁、闸门 |
| 哲学家就餐 | 相邻筷子互斥 | 筷子锁 + 破坏循环等待策略 |
| 睡眠理发师 | 有限等候椅和顾客/理发师配对 | 顾客数、理发师、计数互斥 |

## 生产者—消费者顺序

    producer: P(empty) → P(mutex) → put → V(mutex) → V(full)
    consumer: P(full)  → P(mutex) → get → V(mutex) → V(empty)

先等待资源计数、再取得互斥锁，可避免持有 mutex 时等待 empty/full 导致对方无法进入缓冲区。

## 公平性变体

- 读者优先可能使写者饥饿。
- 写者优先可能使持续到来的写者延迟读者。
- 公平版本按到达次序或通过闸门限制新读者插队。
- 哲学家可限制最多 N-1 人同时拿筷子、固定资源顺序或由服务者分配。

> [!warning]
> 经典题答案取决于题目要求的优先策略和信号量定义。只证明“互斥”不够，还要检查死锁、饥饿、计数越界和并发度。

## Exam/Test Patterns

| 关键词 | 方案核心 |
|---|---|
| 缓冲区 N 个槽 | empty=N、full=0、mutex=1 |
| 多读单写 | 首读者加写锁、末读者释放，另管读者计数 |
| 哲学家死锁 | 破坏循环等待或限制竞争者数量 |

# 软件互斥与硬件原子指令（★★★）

## Overview Table

| 方法 | 代表 | 特点 |
|---|---|---|
| 纯软件互斥 | Peterson、Dekker | 展示意愿与让步，依赖内存模型假设 |

## Peterson 两进程思想

    flag[i] = true          // 表示希望进入
    turn = j                // 让对方优先
    while flag[j] && turn==j: wait
    critical section
    flag[i] = false

在经典顺序一致模型和两个参与者假设下，它满足互斥、进步与有限等待。现代处理器/编译器可能重排访问，实现时需正确的原子类型和内存屏障。

## 原子指令与内存顺序

CAS 比较内存旧值，匹配时原子替换；成功只保证该读改写原子，跨多个位置的不变量仍需协议。Acquire/Release 等顺序用于建立跨线程的可见性关系。

> [!warning]
> 关闭中断只阻止本处理器处理中断，不能让其他核停止访问共享数据；原子指令也不自动保证公平。CAS 循环还可能遇到 ABA、活锁和缓存争用。

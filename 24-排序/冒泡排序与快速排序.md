# 冒泡排序与快速排序（★★★）

#data-structures #sorting

## Overview Table

| 算法 | 交换方式 | 平均时间 | 稳定 |
|---|---|---:|---|
| 冒泡排序 | 只交换相邻逆序元素 | $O(n^2)$ | 是 |
| 快速排序 | 围绕 pivot 做跨区间交换和分区 | $O(n\log n)$ | 否 |

## 冒泡排序

每趟通过相邻比较将当前最大元素“冒”到末端。若某趟没有交换，则数组已有序，可提前结束。最坏比较次数为 $n(n-1)/2$。

## 快速排序

```text
选 pivot
   ↓ partition
[ <= pivot ] pivot [ >= pivot ]
   ↓                 ↓
递归排左区       递归排右区
```

- 分区代价为线性；划分均匀时递归高度 $O(\log n)$。
- 每次 pivot 都成为极端元素时，退化为 $O(n^2)$ 和 $O(n)$ 递归深度。
- 随机 pivot、三数取中、三路分区可改善特定输入。

> [!warning]
> 经典快排不稳定，且并非严格 $O(1)$ 空间：除原地分区外，还需要计算递归栈。

## Exam/Test Patterns

| 提问 | 回答 |
|---|---|
| 快排为何实践中快 | 原地分区、常数小、缓存局部性好 |
| 已有序输入 | 固定选端点为 pivot 可退化；随机化可减小风险 |
| 重复元素很多 | 三路分区为 `<,=,>` 三段 |

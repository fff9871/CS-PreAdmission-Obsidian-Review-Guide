# 计数原理、排列与组合（★★★）

#discrete-mathematics #combinatorics #counting

## Overview Table

| 场景 | 方法 | 公式 |
|---|---|---|
| 互斥分类 | 加法原理 | $m+n$ |
| 连续步骤 | 乘法原理 | $mn$ |
| 选出并排序 $k$ 个 | 排列 | $P(n,k)=n!/(n-k)!$ |
| 只选不排序 $k$ 个 | 组合 | $\binom nk=n!/[k!(n-k)!]$ |

## 加法与乘法原理

- 加法原理：完成任务的方案被分成互斥类别，总数为各类方案数之和。
- 乘法原理：任务由连续步骤组成，总数为各步选择数之积。

```text
“或者”且类别互斥 ─> 加法
“先……再……”       ─> 乘法
```

若分类不互斥，应先用 [[容斥原理与鸽巢原理]] 修正重复。

## 排列与组合

$$P(n,k)=n(n-1)\cdots(n-k+1),$$
$$\binom nk=\frac{P(n,k)}{k!}.$$

关系 $P(n,k)=\binom nk k!$ 表示“先选集合，再给所选元素排序”。

## 可重复选择

| 场景 | 计数 |
|---|---|
| 长度 $k$、每位有 $n$ 种选择 | $n^k$ |
| 从 $n$ 类取 $k$ 个、允许重复且不计顺序 | $\binom{n+k-1}{k}$ |
| 多重集全排列，重复数为 $n_i$ | $n!/(n_1!\cdots n_r!)$ |

## 二项式定理

$$
(x+y)^n=\sum_{k=0}^n\binom nkx^{n-k}y^k.
$$

因此 $\sum_{k=0}^n\binom nk=2^n$，可解释为 $n$ 元集合的全部子集数。

> [!warning]
> 先确认顺序、重复、空位和对象是否可区分，再选公式；不要仅凭题目出现“选择”就套组合数。

## Exam/Test Patterns

| 题型关键词 | 回答 |
|---|---|
| “分类完成” | 类别互斥则加法 |
| “分步完成” | 各步骤选择数相乘 |
| “是否考虑顺序” | 考虑用排列，不考虑用组合 |
| “允许重复取球” | 不计顺序时考虑隔板法 $\binom{n+k-1}{k}$ |

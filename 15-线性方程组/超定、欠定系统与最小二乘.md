# 超定、欠定系统与最小二乘（★★★）

#linear-algebra #linear-systems #least-squares

## Overview Table

| 形状 | 常见名称 | 典型情况 |
|---|---|---|
| $m>n$ | 高/长矩阵，超定 | 方程多于未知数，可能无精确解 |
| $m<n$ | 宽矩阵，欠定 | 未知数多，若有解通常不唯一 |
| $m=n$ | 方阵 | 满秩时唯一解 |

## 超定系统与最小二乘

若 $Ax=b$ 无精确解，最小二乘选择

$$\hat x=\arg\min_x\|Ax-b\|_2^2.$$

最优残差 $r=b-A\hat x$ 与列空间正交，因此

$$A^T(A\hat x-b)=0
\Longrightarrow A^TA\hat x=A^Tb.$$

若 $A$ 列满秩，则 $\hat x=(A^TA)^{-1}A^Tb$。

## 欠定系统与最小范数解

欠定一致系统通常有无穷多解。常选择欧氏范数最小的解：

$$x_*=A^+b,$$

其中 $A^+$ 是 Moore–Penrose 伪逆。

```text
b
│\ 残差 r ⟂ col(A)
│ \
│  A x̂  ← b 在列空间上的正交投影
└──────── col(A)
```

## 数值计算

正规方程会平方条件数；数值上通常优先 QR，病态或秩亏时使用 SVD。

> [!warning]
> “最优解”必须说明优化标准。超定问题通常最小化残差；欠定问题常在精确解中最小化解范数。

## Exam/Test Patterns

| 关键词 | 回答 |
|---|---|
| “长矩阵” | 常指 $m>n$，超定系统 |
| “最小二乘几何意义” | 把 $b$ 正交投影到 $A$ 的列空间 |
| “正规方程” | $A^TAx=A^Tb$ |
| “秩亏怎么办” | 用伪逆/SVD 得最小范数最小二乘解 |

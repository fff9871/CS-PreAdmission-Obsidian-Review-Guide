# 非齐次线性方程组与解结构（★★★）

#linear-algebra #linear-systems

## Overview Table

设 $A$ 为 $m\times n$，$r=\operatorname{rank}(A)$：

| 秩条件 | 解的情况 |
|---|---|
| $r<\operatorname{rank}([A\mid b])$ | 无解 |
| $r=\operatorname{rank}([A\mid b])=n$ | 唯一解 |
| $r=\operatorname{rank}([A\mid b])<n$ | 无穷多解 |

## 有解条件

$Ax=b$ 有解，当且仅当 $b$ 属于 $A$ 的列空间：

$$b\in\operatorname{col}(A)
\Longleftrightarrow
\operatorname{rank}(A)=\operatorname{rank}([A\mid b]).$$

## 解的结构

若 $x_p$ 是一个特解，则所有解为

$$x=x_p+x_h,qquad x_h\in\ker A.$$

```text
一个特解 xp
   + 齐次解空间 ker A
   = 非齐次全部解（仿射空间）
```

所以一致非齐次解集通常不是向量空间，而是零空间的平移。

## 高斯消元

1. 对增广矩阵 $[A\mid b]$ 做初等行变换；
2. 若出现 $[0\cdots0\mid c],c\ne0$，则无解；
3. 识别主元变量和自由变量；
4. 写成“特解 + 齐次通解”。

> [!warning]
> 自由变量数是 $n-r$，其中 $n$ 是未知数个数，不是方程数 $m$。

## Exam/Test Patterns

| 关键词 | 回答 |
|---|---|
| “什么时候有解” | 系数矩阵与增广矩阵秩相等 |
| “唯一解” | 有解且秩等于未知数个数 |
| “通解结构” | 一个特解加相伴齐次方程通解 |
| “解集是不是空间” | 非齐次时通常是仿射空间，不一定含零向量 |

# 概率论学习地图

#dashboard #probability

## Overview

本学习库覆盖原资料概率论部分的全部 20 个知识点，并将“常见概率分布”拆分为独立分布笔记。推荐顺序：

```text
概率规则
  -> 随机变量与分布
  -> 数字特征与依赖关系
  -> 大数定律与中心极限定理
  -> 参数估计与假设检验
  -> 机器学习应用与随机数生成
```

# 操作系统速查

#dashboard #operating-systems #quick-reference

## OS定位 → [[操作系统目标、功能与基本特征]]

- 四特征：并发、共享、虚拟、异步。
- 角色：资源管理者、用户接口、扩充机器、控制程序。
- 用户态/内核态通过 syscall、异常或中断受控切换。

## 事件与系统调用 → [[中断、异常与陷入]]

`异步外部事件 → interrupt`；`当前指令触发 → exception`；`主动进入内核 → trap/syscall`。

`app → API wrapper → syscall/trap → dispatcher → kernel service → return`

## 进程状态 → [[进程状态、创建终止与上下文切换]]

`新建 → 就绪 → 运行 → 终止`；运行等待事件进入阻塞，事件完成回到就绪；抢占使运行回到就绪。

## 线程模型 → [[线程、用户线程与内核线程]]

- 线程独有：PC、寄存器、栈、调度状态。
- 同进程共享：代码、数据、堆、打开文件。
- 多对一用户线程无法在多个核上同时执行。

## 调度指标 → [[调度层次、评价指标与抢占]]

- `周转时间 = 完成时间 - 到达时间`
- `带权周转时间 = 周转时间 / 服务时间`
- `响应时间 = 首次运行/响应时间 - 到达时间`
- `等待时间 = 就绪队列中的累计时间`

## 调度算法 → [[FCFS、SJF、优先级与时间片轮转]]

| 算法 | 一句话 |
|---|---|
| FCFS | 简单但有护航效应 |
| SJF/SRTF | 最短作业/最短剩余时间，长作业可饥饿 |
| Priority | 高优先级先，老化防饥饿 |
| RR | 时间片过大近似 FCFS，过小切换开销高 |
| MLFQ | 用历史行为近似识别短任务和交互任务 |

## 临界区 → [[临界区、竞态条件与原子性]]

正确性检查：互斥、进步、有限等待；高级语言单条语句通常不天然原子。

## 锁与原子指令 → [[互斥锁、自旋锁与读写锁]]

- 短临界区且不可睡眠：评估自旋。
- 等待较长：阻塞型 mutex。
- CAS/LL-SC 提供原子读改写，公平性和多变量不变量仍靠协议。

## 信号量 → [[信号量与PV操作]]

`P(S)` 获取许可、无许可则等待；`V(S)` 归还许可并唤醒。

有界缓冲：`empty=N, full=0, mutex=1`。

## 条件变量 → [[管程与条件变量]]

`while (!predicate) cond.wait(lock)`；wait 原子释放锁并睡眠，醒来后重获锁再复查。

## 死锁 → [[死锁条件、资源分配图与处理策略]]

四条件：互斥、请求并保持、不可剥夺、循环等待。

`Need = Max - Allocation`；银行家算法只批准试分配后仍存在安全序列的请求。

## 地址转换 → [[分页、页表与地址转换]]

页大小 `2^p`：低 p 位为页内偏移；`PA = PFN × page_size + offset`。

分页有页内内部碎片；分段有外部碎片；段页式组合两者。

## TLB与缺页 → [[TLB、有效访问时间与缺页边界]]

`TLB miss → page walk`，页表显示不驻留时才 `page fault`。

简化单级模型：`EAT = α(ε+m) + (1-α)(ε+2m)`。

## 缺页处理 → [[请求分页与缺页处理]]

`检查合法性 → 找页框/置换 → 脏页写回 → 调入/零填充 → 更新页表/TLB → 重启指令`。

## 页面置换 → [[FIFO、LRU、CLOCK与Belady异常]]

- OPT：理论最少；FIFO：可能 Belady；LRU：栈算法；CLOCK：访问位近似 LRU。
- 抖动：工作集总需求超过可用页框，应增加页框或降低多道程度。

## I-O路径 → [[I-O软件层次、驱动与设备控制器]]

`用户库 → 系统调用/VFS → 设备无关层 → 驱动 → 控制器/设备 → 完成中断`。

程序查询 / 中断驱动 / DMA：CPU 参与度依次降低，但 DMA 仍需配置与完成处理。

## I-O语义 → [[阻塞非阻塞、同步异步与I-O多路复用]]

- 阻塞/非阻塞：未就绪时调用是否等待。
- 同步/异步：操作完成由调用者等待还是内核完成后通知。
- select/poll/epoll 是就绪多路复用，不自动等于异步 I/O。

## 磁盘调度 → [[FCFS、SSTF、SCAN与C-SCAN磁盘调度]]

`总寻道量 = Σ|相邻服务磁道差|`；SCAN 到端点反向，LOOK 到最远请求反向，C-SCAN 单向服务。

## RAID → [[RAID级别、容量与可靠性]]

| 级别 | 可用容量 | 容错 |
|---|---:|---|
| RAID 0 | `N×S` | 0 块 |
| RAID 1/10 | 典型 `N/2×S` | 依镜像组故障分布 |
| RAID 5 | `(N-1)×S` | 1 块 |
| RAID 6 | `(N-2)×S` | 2 块 |

## 文件对象 → [[文件、目录、inode与文件描述符]]

`pathname → directory entry → inode → open-file object → process fd`。

硬链接指向同一 inode；符号链接保存路径。所有写端关闭且缓冲读空时，管道读端得到 EOF。

## 文件分配 → [[连续、链接、索引分配与空闲空间管理]]

索引节点最大文件：`direct blocks + single indirect + double indirect + ...`；每个间接块指针数 `= block_size/pointer_size`。

## 安全 → [[身份认证、授权与访问控制]]

认证证明“是谁”，授权判断“能做什么”，审计记录“做了什么”。最小权限、默认拒绝、职责分离、完全仲裁。

## 虚拟机与容器 → [[虚拟机、Hypervisor与系统虚拟化]]

- VM：客体独立内核；Hypervisor 虚拟化 CPU、内存和设备。
- 容器：共享宿主内核；namespace 隔离视图，cgroup 限制资源。

## 分布式调用 → [[RPC、RMI与分布式通信]]

超时表示结果未知；至少一次可能重复，需幂等或去重；强一致通常需要协调并受网络分区影响。

## BUAA MOS构建 → [[BUAA-MOS实验环境、构建与GXemul]]

`.c/.S → .o → linker script + linker → MIPS ELF → GXemul`。

## BUAA MOS内存 → [[BUAA-MOS物理内存、页表与TLB重填]]

`page_alloc → pgdir_walk → PTE → TLB invalidate/refill`；页引用计数、PTE 和空闲链表必须一致。

## BUAA MOS异常与COW → [[BUAA-MOS系统调用、IPC与fork]]

`exception vector → Trapframe → handler/dispatcher → restore + eret`。

COW：父子共享只读页，首次写异常时分配、复制并重映射。

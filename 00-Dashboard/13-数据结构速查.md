# 数据结构速查

#dashboard #data-structures #quick-reference

## 复杂度与表示 → [[算法复杂度与抽象数据类型]]、[[数据逻辑结构与存储结构]]

| 模式 | 数量级/选择 |
|---|---|
| 数组按下标 | O(1) |
| 平衡树、二分 | O(log n) |
| 遍历表 | O(n) |
| 高效比较排序 | O(n log n) |

## 线性表 → [[顺序表与链表]]、[[链表经典操作与快慢指针]]

| 需求 | 选择 |
|---|---|
| 按下标、缓存局部性 | 顺序表 |
| 已知位置频繁插删 | 链表 |
| 倒数第 k 个、判环 | 双指针 |

## 栈与队列 → [[栈与典型应用]]、[[队列、双端队列与循环队列]]

| 结构 | 规则 | 应用 |
|---|---|---|
| 栈 | LIFO | 括号、表达式、递归/DFS |
| 队列 | FIFO | BFS、层序、缓冲 |
| 循环队列 | 下标循环 | 牺牲一格时满：rear 的下一位置等于 front |

## 数组与矩阵 → [[数组与特殊矩阵压缩存储]]

- 对称矩阵只存一个三角，共 n(n+1)/2 个元素。
- 稀疏矩阵可存非零元素的行、列和值。

## 字符串匹配 → [[串与朴素模式匹配]]、[[KMP算法与next数组]]

- 朴素匹配最坏 O(nm)；KMP 为 O(n+m)。
- next 或前缀函数记录可复用的最长相等真前后缀信息。

## 二叉树性质 → [[树、二叉树与基本性质]]

| 性质 | 公式 |
|---|---|
| 叶子与度 2 结点 | n0=n2+1 |
| 高 h 最多结点 | 2^h-1 |
| 完全二叉树高度 | floor(log2 n)+1 |
| n 结点空指针域 | n+1 |

## 遍历与重建 → [[二叉树遍历、重建与线索化]]

- 先序：根左右；中序：左根右；后序：左右根。
- 先序+中序、后序+中序可唯一重建（结点值互异）。
- 一般先序+后序不唯一。

## 搜索树与外存索引 → [[二叉搜索树、AVL树与红黑树]]、[[B树、B+树与外存索引]]

| 结构 | 关键点 |
|---|---|
| BST | 可退化为链 |
| AVL | 左右子树高度差至多 1 |
| 红黑树 | 宽松平衡，更新折中 |
| B+ 树 | 高扇出、低 I/O、叶链范围扫描 |

## 堆、Huffman 与并查集 → [[堆、Huffman树与并查集]]

- 堆顶取极值 O(1)，插入/删顶 O(log n)，自底建堆 O(n)。
- Huffman 反复合并两个最小权，得到最小 WPL 前缀码。
- 并查集用路径压缩与按秩合并，实际近似常数。

## 图的存储与遍历 → [[图的概念与存储]]、[[DFS、BFS与图遍历]]

| 表示 | 空间 | 全图遍历 |
|---|---:|---:|
| 邻接矩阵 | O(V²) | O(V²) |
| 邻接表 | O(V+E) | O(V+E) |

## 最小生成树 → [[最小生成树：Prim与Kruskal]]

- Prim：从顶点集向外选最轻边；矩阵版 O(V²)，堆版 O(E log V)。
- Kruskal：边排序加并查集，O(E log E)。

## 最短路径 → [[最短路：Dijkstra、Bellman-Ford与Floyd]]

| 条件 | 算法 |
|---|---|
| 无权 | BFS |
| 非负权单源 | Dijkstra |
| 可有负边单源 | Bellman-Ford |
| 全源 | Floyd-Warshall |

## 拓扑与关键路径 → [[拓扑排序与关键路径]]

- 拓扑排序只对 DAG 存在；处理数小于 V 说明有环。
- 关键活动的最早开始等于最迟开始，时间余量为 0。

## 查找与散列 → [[顺序查找、二分查找与分块查找]]、[[动态查找结构对比]]、[[哈希表与冲突处理]]

- 二分：有序且可随机存取，O(log n)。
- 哈希：平均 O(1)，最坏 O(n)；负载因子 α=n/m。

## 排序综合 → [[排序性能、稳定性与选择]]、[[插入排序与希尔排序]]、[[冒泡排序与快速排序]]、[[选择排序与堆排序]]、[[归并排序、基数排序与外部排序]]

| 需求 | 选择 |
|---|---|
| 近有序、小规模 | 插入 |
| 平均快、内存原地 | 快排 |
| 最坏 O(n log n) 且原地 | 堆排序 |
| 稳定、外部数据 | 归并 |
| 键可拆为有限位 | 基数 |

# 离散数学学习地图

#dashboard #discrete-mathematics

## Overview

这套笔记面向北航推免面试，按照“定义准确 → 条件辨析 → 反例 → 口述应用”的顺序组织。

```text
集合与映射
  -> 二元关系与序
  -> 命题/谓词逻辑
  -> 代数系统
  -> 图论
  -> 组合计数
```

推荐先掌握集合、映射和关系，再学习逻辑与代数系统；图论和组合数学可并行复习。

# 线性代数公式速查

#quick-reference #linear-algebra

## 行列式 → [[行列式、余子式与几何意义]]

| 公式 | 内容 |
|---|---|
| $A_{ij}=(-1)^{i+j}M_{ij}$ | 代数余子式 |
| $\det A=\sum_j a_{ij}A_{ij}$ | 按第 $i$ 行展开 |
| $\det(AB)=\det A\det B$ | 乘积行列式 |
| $\det(A^T)=\det A$ | 转置不改变行列式 |
| $A$ 可逆 $\Leftrightarrow\det A\ne0$ | 方阵可逆判定 |

## 逆矩阵与秩 → [[逆矩阵、伴随矩阵与初等变换]]、[[矩阵的秩、等价与满秩]]

| 公式/结论 | 内容 |
|---|---|
| $A^{-1}=\operatorname{adj}(A)/\det A$ | 伴随矩阵法，要求 $\det A\ne0$ |
| $\operatorname{rank}(A)$ | 非零子式最高阶数 = 行阶梯形非零行数 |
| $\operatorname{rank}(A)=\operatorname{rank}(A^T)$ | 行秩等于列秩 |
| $A$ 方阵满秩 | 等价于可逆、零空间仅含 0、0 不是特征值 |

## 线性相关与空间 → [[线性组合、线性相关与判定]]、[[向量空间、子空间、基与维数]]

| 结论 | 公式 |
|---|---|
| 线性无关 | $\sum c_i v_i=0\Rightarrow c_i=0$ |
| 张成空间 | $\operatorname{span}(v_1,\ldots,v_k)$ |
| 基 | 线性无关且张成整个空间 |
| 维数公式 | $\dim U+\dim W=\dim(U+W)+\dim(U\cap W)$ |

## 线性变换 → [[线性变换、核、像与矩阵表示]]

| 公式 | 内容 |
|---|---|
| $T(au+bv)=aT(u)+bT(v)$ | 线性性 |
| $\ker T=\{v:T(v)=0\}$ | 核 |
| $\operatorname{im}T=\{T(v)}$ | 像 |
| $\dim\ker T+\dim\operatorname{im}T=\dim V$ | 秩—零化度定理 |

## 线性方程组 → [[齐次线性方程组与基础解系]]、[[非齐次线性方程组与解结构]]

设 $A$ 为 $m\times n$，$r=\operatorname{rank}(A)$：

| 情况 | 结论 |
|---|---|
| $Ax=0$ | 解空间维数 $n-r$ |
| $Ax=b$ 有解 | $\operatorname{rank}(A)=\operatorname{rank}([A\mid b])$ |
| 有唯一解 | 两秩相等且 $r=n$ |
| 有无穷多解 | 两秩相等且 $r<n$ |
| 无解 | $\operatorname{rank}(A)<\operatorname{rank}([A\mid b])$ |

## 最小二乘 → [[超定、欠定系统与最小二乘]]

| 公式 | 条件 |
|---|---|
| $A^TA\hat x=A^Tb$ | 正规方程 |
| $\hat x=(A^TA)^{-1}A^Tb$ | $A$ 列满秩 |
| $\hat x=A^+b$ | Moore–Penrose 伪逆的一般表达 |

## 内积与正交 → [[内积、正交与Gram-Schmidt正交化]]、[[正交矩阵与正交投影]]

| 公式 | 内容 |
|---|---|
| $\langle x,y\rangle=x^Ty$ | 欧氏内积 |
| $\operatorname{proj}_u v=\frac{\langle v,u\rangle}{\langle u,u\rangle}u$ | 投影到向量 $u$ |
| $Q^TQ=I$ | 正交矩阵 |
| $Q^{-1}=Q^T$ | 正交矩阵求逆 |
| $P=Q(Q^TQ)^{-1}Q^T$ | 投影到 $\operatorname{col}(Q)$ |

## 范数 → [[向量范数与矩阵范数]]

| 范数 | 公式 |
|---|---|
| $\|x\|_1$ | $\sum_i|x_i|$ |
| $\|x\|_2$ | $\sqrt{\sum_i|x_i|^2}$ |
| $\|x\|_\infty$ | $\max_i|x_i|$ |
| $\|A\|_1$ | 最大绝对列和 |
| $\|A\|_\infty$ | 最大绝对行和 |
| $\|A\|_2$ | $\sqrt{\lambda_{\max}(A^TA)}=\sigma_{\max}(A)$ |
| $\|A\|_F$ | $\sqrt{\sum_{ij}|a_{ij}|^2}$ |

## 特征值 → [[特征值、特征向量与特征空间]]

| 公式 | 内容 |
|---|---|
| $Av=\lambda v, v\ne0$ | 特征对 |
| $\det(A-\lambda I)=0$ | 特征方程 |
| $\sum_i\lambda_i=\operatorname{tr}(A)$ | 按代数重数 |
| $\prod_i\lambda_i=\det A$ | 按代数重数 |
| 几何重数 $\le$ 代数重数 | 特征空间维数上界 |

## 相似与谱分解 → [[相似矩阵与相似对角化]]、[[实对称矩阵与谱分解]]

| 形式 | 条件/意义 |
|---|---|
| $B=P^{-1}AP$ | 相似，同一线性变换在不同基下的矩阵 |
| $A=PDP^{-1}$ | 有 $n$ 个线性无关特征向量 |
| $A=Q\Lambda Q^T$ | 实对称矩阵谱分解，$Q$ 正交 |

## 常用分解 → [[LU、QR与常用矩阵分解]]、[[奇异值分解与PCA]]

| 分解 | 形式 | 用途 |
|---|---|---|
| LU | $PA=LU$ | 解方程、行列式 |
| QR | $A=QR$ | 最小二乘、正交基 |
| EVD | $A=PDP^{-1}$ | 方阵且可对角化 |
| SVD | $A=U\Sigma V^T$ | 任意矩阵、压缩、伪逆 |

## 二次型与正定 → [[二次型、矩阵合同与标准形]]、[[惯性定理与规范形]]、[[正定、半正定与判别法]]

| 结论 | 公式/条件 |
|---|---|
| 二次型 | $f(x)=x^TAx$，可取 $A$ 对称 |
| 合同 | $B=C^TAC$，$C$ 可逆 |
| 正定 | $x^TAx>0$ 对所有 $x\ne0$ |
| Sylvester 判据 | 实对称矩阵所有顺序主子式 $>0$ |
| 特征值判据 | 实对称矩阵所有特征值 $>0$ |
| 半正定 | 所有特征值 $\ge0$；等价于所有主子式非负 |

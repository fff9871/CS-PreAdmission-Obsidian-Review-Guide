# 操作系统学习地图

#dashboard #operating-systems

## Overview

学习主线采用“抽象与内核边界 → 执行实体 → 并发控制 → 地址空间 → 持久化与 I/O → 安全与分布式 → BUAA MOS 实现”。面试回答建议固定为：**定义 → 核心机制/状态 → 数据结构或流程 → 性能与正确性边界 → 例外**。

    application
       ↓ API / system call
    process & thread ── scheduling / synchronization
       ↓
    virtual memory ── file & I/O
       ↓
    protection / virtualization / distributed services
       ↓
    BUAA MOS: MIPS exception + TLB + user-level services

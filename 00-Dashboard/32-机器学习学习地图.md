# 机器学习学习地图

#dashboard #machine-learning

## Overview

学习主线采用“任务与数据 → 概率/线性模型 → 经典监督与无监督算法 → 深度网络优化 → 视觉与序列架构 → PyTorch训练闭环”。面试回答建议按 **问题定义 → 假设 → 目标函数 → 优化/推断 → 指标 → 失效边界** 展开。

    data & labels
       → representation / preprocessing
       → model + objective + optimization
       → validation / diagnosis
       → deployment distribution

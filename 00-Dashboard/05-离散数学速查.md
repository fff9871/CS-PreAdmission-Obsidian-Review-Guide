# 离散数学速查

#quick-reference #discrete-mathematics

## 集合运算 → [[集合运算、幂集与笛卡尔积]]

| 项目 | 结论 |
|---|---|
| 幂集大小 | 若 $|A|=n$，则 $|\mathcal P(A)|=2^n$ |
| 对称差 | $A\triangle B=(A-B)\cup(B-A)$ |
| 德摩根律 | $\overline{A\cup B}=\bar A\cap\bar B$；$\overline{A\cap B}=\bar A\cup\bar B$ |
| 笛卡尔积 | $A\times B=\{(a,b)\mid a\in A,b\in B\}$，通常 $A\times B\ne B\times A$ |

## 映射与势 → [[函数、单射、满射与双射]]、[[集合的势与可数性]]

| 概念 | 判定 |
|---|---|
| 单射 | $f(x_1)=f(x_2)\Rightarrow x_1=x_2$ |
| 满射 | $\forall y\in B,\exists x\in A:f(x)=y$ |
| 双射 | 同时单射、满射；存在反函数 |
| 等势 | 两集合之间存在双射 |
| 可数无限 | 与 $\mathbb N$ 等势；$\mathbb Z,\mathbb Q$ 可数，$\mathbb R$ 不可数 |
| Cantor 定理 | $|A|<|\mathcal P(A)|$ |

## 关系性质 → [[二元关系与关系性质]]

| 性质 | 公式 |
|---|---|
| 自反 | $\forall x\in A,(x,x)\in R$ |
| 反自反 | $\forall x\in A,(x,x)\notin R$ |
| 对称 | $(x,y)\in R\Rightarrow(y,x)\in R$ |
| 反对称 | $(x,y),(y,x)\in R\Rightarrow x=y$ |
| 传递 | $(x,y),(y,z)\in R\Rightarrow(x,z)\in R$ |

## 闭包 → [[关系闭包]]

| 闭包 | 最小扩充 |
|---|---|
| 自反闭包 | $r(R)=R\cup I_A$ |
| 对称闭包 | $s(R)=R\cup R^{-1}$ |
| 传递闭包 | $t(R)=\bigcup_{k\ge1}R^k$；有限集上可用 Warshall |

## 等价与序 → [[等价关系、等价类与划分]]、[[偏序、全序与良序]]

| 结构 | 条件 |
|---|---|
| 等价关系 | 自反 + 对称 + 传递 |
| 偏序 | 自反 + 反对称 + 传递 |
| 全序 | 偏序 + 任意两元素可比 |
| 良序 | 全序 + 每个非空子集有最小元 |
| 严格偏序 | 反自反 + 传递；因此也不对称 |

## 命题逻辑 → [[命题逻辑与真值表]]、[[逻辑等价式与范式]]

| 式子 | 等价形式 |
|---|---|
| 蕴含 | $p\to q\equiv\neg p\lor q$ |
| 等价 | $p\leftrightarrow q\equiv(p\to q)\land(q\to p)$ |
| 逆否 | $p\to q\equiv\neg q\to\neg p$ |
| 德摩根 | $\neg(p\land q)\equiv\neg p\lor\neg q$ |
| 排中律 | $p\lor\neg p\equiv\top$ |
| 矛盾律 | $p\land\neg p\equiv\bot$ |

## 谓词逻辑 → [[谓词逻辑、量词与解释]]

| 规则 | 公式 |
|---|---|
| 否定全称 | $\neg\forall xP(x)\equiv\exists x\neg P(x)$ |
| 否定存在 | $\neg\exists xP(x)\equiv\forall x\neg P(x)$ |
| 量词顺序 | $\forall x\exists yP(x,y)$ 通常不等价于 $\exists y\forall xP(x,y)$ |
| 自由/约束 | 量词辖域内同名变量是约束出现；其余为自由出现 |

## 推理规则 → [[推理规则与证明方法]]

| 名称 | 形式 |
|---|---|
| 假言推理 MP | $p,p\to q\vdash q$ |
| 拒取式 MT | $p\to q,\neg q\vdash\neg p$ |
| 假言三段论 | $p\to q,q\to r\vdash p\to r$ |
| 析取三段论 | $p\lor q,\neg p\vdash q$ |
| 反证法 | 假设 $\neg q$ 推出矛盾，从而得到 $q$ |

## 代数系统 → [[代数系统、半群、幺半群与群]]、[[环、整环与域]]

```text
封闭二元运算
  + 结合律 = 半群
  + 单位元 = 幺半群
  + 每个元素有逆元 = 群
  + 交换律 = 交换群
```

| 结构 | 核心条件 |
|---|---|
| 环 | $(R,+)$ 为交换群，乘法结合，乘法对加法分配 |
| 整环 | 有幺交换环且无零因子 |
| 域 | $(F,+)$ 为交换群，$(F\setminus\{0\},\cdot)$ 为交换群，且分配律成立 |

## 欧拉函数 → [[欧拉函数]]

| 情况 | 公式 |
|---|---|
| 定义 | $\varphi(n)=|\{1\le k\le n:\gcd(k,n)=1\}|$ |
| 素数 $p$ | $\varphi(p)=p-1$ |
| 素数幂 | $\varphi(p^a)=p^a-p^{a-1}$ |
| 一般分解 | $\varphi(n)=n\prod_{p\mid n}(1-1/p)$ |

## 图的度数 → [[图的基本概念与特殊图]]、[[子图、补图、度数与同构]]

| 结论 | 公式/条件 |
|---|---|
| 无向图握手定理 | $\sum_{v\in V}\deg(v)=2|E|$ |
| 奇度顶点 | 个数必为偶数 |
| 有向图 | $\sum\deg^+(v)=\sum\deg^-(v)=|E|$ |
| 完全图 | $|E(K_n)|=n(n-1)/2$ |

## 欧拉与哈密顿 → [[欧拉图与哈密顿图]]

| 问题 | 欧拉 | 哈密顿 |
|---|---|---|
| 关注对象 | 每条边一次 | 每个顶点一次 |
| 无向欧拉回路 | 非零度顶点连通，所有顶点度为偶数 | — |
| 无向欧拉通路 | 非零度顶点连通，恰有 0 或 2 个奇度顶点 | — |
| 一般算法 | Hierholzer，线性于边数 | 一般判定为 NP-complete，无简单充要度数条件 |

## 树与 Huffman → [[树、生成树与Huffman树]]

| 结论 | 内容 |
|---|---|
| 树 | 连通无环图 |
| 等价刻画 | $n$ 个顶点的树有 $n-1$ 条边；任意两点间唯一路径 |
| 生成树 | 连通图中覆盖全部顶点的树 |
| Huffman | 每次合并权值最小的两棵树，得到最小带权外部路径长度 |

## 计数 → [[计数原理、排列与组合]]、[[容斥原理与鸽巢原理]]

| 公式 | 内容 |
|---|---|
| 排列 | $P(n,k)=n!/(n-k)!$ |
| 组合 | $\binom nk=n!/[k!(n-k)!]$ |
| 二项式 | $(x+y)^n=\sum_{k=0}^n\binom nkx^{n-k}y^k$ |
| 两集合容斥 | $|A\cup B|=|A|+|B|-|A\cap B|$ |
| 鸽巢 | $N$ 个对象放入 $k$ 个盒子，至少一盒有 $\lceil N/k\rceil$ 个 |

## 递推 → [[递推关系与生成函数]]

| 类型 | 解法 |
|---|---|
| $a_n=ca_{n-1}$ | $a_n=a_0c^n$ |
| 二阶齐次 | 解特征方程 $r^2-pr-q=0$ |
| 普通生成函数 | $A(x)=\sum_{n\ge0}a_nx^n$，将递推转成代数方程 |

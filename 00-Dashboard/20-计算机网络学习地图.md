# 计算机网络学习地图

#dashboard #computer-networks

## Overview

主线采用“分层与传输基础 → 链路交付 → 跨网路由 → 端到端传输 → 应用协议”，面试回答优先使用“层次—对象—协议—机制—边界”的结构。

    应用层：DNS / HTTP / TLS / FTP / Email
                       ↓
    传输层：UDP / TCP可靠传输与拥塞控制
                       ↓
    网络层：IP编址、ARP、ICMP、路由
                       ↓
    链路层：成帧、ARQ、以太网、交换机
                       ↓
    物理层：比特、信道、复用与容量

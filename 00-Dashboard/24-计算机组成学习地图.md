# 计算机组成学习地图

#dashboard #computer-organization

## Overview

主线采用“系统与数据表示 → 存储层次 → 指令与 CPU → 流水线 → 总线与 I/O”，回答时区分 ISA、微体系结构与操作系统三个层次。

    程序/数据表示
          ↓
    ISA：指令、寄存器、寻址
          ↓
    CPU 数据通路与控制器
          ↓
    流水线 + Cache + 虚拟存储
          ↓
    总线、主存与 I/O 设备

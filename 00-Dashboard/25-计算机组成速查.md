# 计算机组成速查

#dashboard #computer-organization #quick-reference

## 体系结构 → [[冯诺依曼结构、哈佛结构与存储程序]]

- 五大部件：运算器、控制器、存储器、输入设备、输出设备。
- 存储程序：指令和数据预先以二进制存入存储器，CPU 按 PC 取指执行。
- 冯诺依曼：指令/数据共享空间；哈佛：二者存储与通路分离。

## CPU性能 → [[CPU性能指标、CPI与阿姆达尔定律]]

- `T = 1/f`
- `CPU时间 = IC × CPI × T = IC × CPI / f`
- `性能 = 1/执行时间`
- `加速比 = 旧时间/新时间`
- `Amdahl: Speedup = 1 / ((1-p)+p/s)`

## 补码与溢出 → [[数制、机器数与补码]]

- n 位无符号：`0 .. 2^n-1`
- n 位补码：`-2^(n-1) .. 2^(n-1)-1`
- 补码减法：`A-B = A + (~B+1)`
- 同号相加结果异号：有符号溢出。
- CF 面向无符号进位，OF 面向有符号溢出。

## IEEE754 → [[IEEE754浮点数与类型转换]]

| 格式 | S | E | F | Bias |
|---|---:|---:|---:|---:|
| binary32 | 1 | 8 | 23 | 127 |
| binary64 | 1 | 11 | 52 | 1023 |

`规格化值 = (-1)^S × (1.F) × 2^(E-bias)`

## 存储层次 → [[存储层次与局部性]]

`寄存器 → Cache → 主存 → 辅存`：速度递减、容量递增、位成本递减。

- SRAM：快、不刷新，常用于 Cache。
- DRAM：密度高、需刷新，常用于主存。
- 时间局部性：近期对象再访问；空间局部性：邻近地址再访问。

## Cache地址与AMAT → [[Cache结构、命中率与平均访问时间]]

`Address = Tag | Set Index | Block Offset`

- Offset 位数：`log₂(块字节数)`
- Index 位数：`log₂(组数)`
- `AMAT = Hit Time + Miss Rate × Miss Penalty`

## Cache策略 → [[Cache替换算法与写策略]]

| 维度 | 选项 |
|---|---|
| 映射 | 直接、全相联、组相联 |
| 替换 | Random、FIFO、LRU/伪LRU |
| 写命中 | Write-through、Write-back |
| 写缺失 | Write-allocate、No-write-allocate |

## 虚拟存储 → [[虚拟存储、页表与TLB]]

`VA[VPN|Offset] → TLB → 页表 → PA[PPN|Offset]`

- TLB miss：需查页表，不一定缺页。
- Page fault：页面不在主存，需要操作系统调页。
- 页内偏移在地址翻译前后保持不变。

## 指令与寻址 → [[寻址方式与有效地址计算]]

- 立即：操作数在指令中。
- 寄存器：操作数在寄存器中。
- 基址/变址：`EA = Register + Displacement`。
- 相对：`EA = PC + Displacement`。
- MIPS：定长、Load/Store、R/I/J 格式。

## CPU数据通路 → [[CPU组成、寄存器与数据通路]]

- PC：下一指令地址；IR：当前指令。
- MAR：主存地址；MDR：主存读写数据。
- 典型流程：`取指 → 译码 → 执行 → 访存 → 写回 → 检查中断`。

## 流水线 → [[指令流水线原理与性能]]

- 理想 k 段执行 n 条：`(k+n-1)T`
- 理想加速比：`nk/(k+n-1)`，n 大时趋近 k。
- 结构冒险：争硬件；数据冒险：依赖；控制冒险：下一 PC 不确定。
- RAW 是真相关；WAR/WAW 常可由寄存器重命名消除。

## 多核与SMT → [[多核、SMT与并行性]]

- 多核复制物理执行核心；SMT 在一个核心中保存多个线程状态并共享部分资源。
- 四核八线程 = 4 个物理核心、8 个逻辑处理器，不代表 8 倍性能。
- 加速受串行比例、同步、Cache/内存带宽和功耗限制。

## 总线 → [[总线分类、宽度、带宽与复用]]

- 三类：数据、地址、控制总线。
- `理论带宽 = 总线字节宽度 × 每秒传输次数`
- 同步定时依时钟；异步定时依请求/应答握手。
- 仲裁保证同一时刻只有一个主设备驱动共享总线。

## I-O与中断 → [[DMA传送与I-O通道]]

| 方式 | CPU 参与 |
|---|---|
| 程序查询 | 持续忙等并搬运 |
| 中断驱动 | 设备就绪后中断，CPU 服务程序搬运 |
| DMA | CPU 配置，DMA 控制器块传输，结束中断 |
| 通道 | 专用 I/O 处理器执行通道程序 |

## 中断流程 → [[中断响应、优先级与向量]]

`指令结束 → 检查请求 → 保存断点/状态 → 取得向量 → ISR → 中断返回`

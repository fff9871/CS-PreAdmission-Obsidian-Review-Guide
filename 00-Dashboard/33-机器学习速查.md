# 机器学习速查

#dashboard #machine-learning #quick-reference

## 学习范式 → [[监督、无监督、半监督与强化学习]]

- 监督：标签；无监督：结构；自监督：从数据构造目标；强化：奖励与长期回报。
- 分类输出离散类别，回归输出连续值，排序输出相对次序。

## 泛化与划分 → [[训练集、验证集、测试集与交叉验证]]

训练集拟合，验证集调参，测试集最终一次评估；时间、用户、设备等相关实体按组/时间划分。

## 分类指标 → [[分类指标、ROC-AUC与阈值]]

- `Precision=TP/(TP+FP)`
- `Recall=TP/(TP+FN)`
- `F1=2PR/(P+R)`
- `FPR=FP/(FP+TN)`
- ROC-AUC看跨阈值排序；正类稀少时重点看PR曲线与阈值指标。

## 回归指标 → [[回归指标、损失函数与模型选择]]

- `MSE=mean((y-ŷ)²)`，`RMSE=sqrt(MSE)`
- `MAE=mean(|y-ŷ|)`
- `R²=1-SSE/SST`

## 线性回归 → [[线性回归与最小二乘法]]

`ŷ=Xw+b`；`min ||y-Xw||²`；满秩时 `w=(XᵀX)⁻¹Xᵀy`，工程上优先QR/SVD/线性求解器。

## 逻辑回归 → [[逻辑回归、Sigmoid与交叉熵]]

`p=σ(wᵀx+b)`，`σ(z)=1/(1+e^-z)`；BCE是Bernoulli负对数似然。

## MLE与MAP → [[最大似然、MAP与贝叶斯公式]]

`MLE=argmax p(D|θ)`；`MAP=argmax p(D|θ)p(θ)`；高斯先验↔L2，拉普拉斯先验↔L1。

## 梯度优化 → [[BGD、SGD、Mini-batch与Momentum]]

`θ←θ-ηg`；Momentum累积方向；Adagrad累积平方梯度；RMSprop用平方梯度EMA；Adam结合一二阶矩和偏差修正。

## 决策树 → [[决策树、信息熵与信息增益]]

`H=-Σp log₂p`；信息增益=`父熵-加权子熵`；ID3用增益、C4.5用增益率、CART分类用Gini。

## 朴素贝叶斯 → [[朴素贝叶斯与条件独立假设]]

`ŷ=argmax_y log p(y)+Σ_j log p(x_j|y)`；核心是假设给定类别后特征条件独立。

## SVM → [[线性SVM、间隔与支持向量]]

软间隔：`min 1/2||w||²+CΣξ`；支持向量决定边界；RBF核γ越大越局部，C越大越重视训练违例。

## 集成 → [[Bagging、随机森林与Boosting]]

Bagging并行重采样降方差；随机森林再做特征随机；Boosting串行纠错/拟合负梯度。

## K-means → [[K-means目标函数、算法与初始化]]

`min Σ||x_i-μ_{c_i}||²`；最近中心分配 ↔ 簇均值更新；K-means++ + 多次重启。

## GMM与EM → [[GMM、EM与软聚类]]

`p(x)=Σπ_kN(x|μ_k,Σ_k)`；E步算责任度，M步加权更新参数。

## PCA → [[PCA、方差最大化与协方差矩阵]]

中心化 → 协方差 → 特征分解 → 取最大特征值方向；等价于固定维数最小平方重构误差。

## 反向传播 → [[反向传播、链式法则与计算图]]

前向保存中间量，反向局部导数相乘、分支梯度相加；`backward`求梯度，optimizer `step`更新参数。

## 激活与梯度 → [[梯度消失、梯度爆炸与参数初始化]]

Sigmoid饱和；ReLU正区梯度1、负区0；Xavier常配Tanh，He常配ReLU；爆炸可用裁剪。

## 归一化 → [[归一化：BatchNorm、LayerNorm、GroupNorm与InstanceNorm]]

BN按通道跨N/H/W，LN按样本特征，GN按通道组，IN按样本每通道空间；BN训练用batch统计、推理用running统计。

## 卷积形状 → [[卷积输出尺寸、参数量与计算量]]

`Hout=floor((H+2P-D(K-1)-1)/S)+1`

参数=`Cout×(Cin/G)×Kh×Kw + bias`。

## 感受野 → [[感受野与空洞卷积]]

`j_l=j_{l-1}s_l`；`r_l=r_{l-1}+(k_eff-1)j_{l-1}`；`k_eff=d(k-1)+1`。

## 深度可分离卷积 → [[1x1卷积与深度可分离卷积]]

参数：标准=`K²CinCout`；Depthwise Separable=`K²Cin+CinCout`。

## Attention → [[Attention与Query-Key-Value]]

`softmax(QKᵀ/√d_k)V`；padding mask屏蔽填充，causal mask屏蔽未来。

## Transformer → [[Transformer编码器、解码器、Mask与位置编码]]

Self-Attention + FFN + Residual + Norm + Position；标准注意力复杂度随序列长度约 `O(n²d)`。

## PyTorch训练循环 → [[PyTorch训练循环、Loss与Optimizer]]

`train → zero_grad → forward → loss → backward → optional clip → step`。

验证：`model.eval()` + `torch.no_grad()`；两者职责不同。

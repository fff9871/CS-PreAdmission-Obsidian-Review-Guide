# 数据库速查

#dashboard #database #quick-reference

## 三级模式与独立性 → [[数据库系统、三级模式与二级映像]]

| 层次 | 内容 |
|---|---|
| 外模式 | 用户局部视图 |
| 模式 | 全局逻辑结构 |
| 内模式 | 物理存储结构 |
| 二级映像 | 分别支撑逻辑与物理独立性 |

## 键与完整性 → [[关系模型、键与完整性约束]]

- 候选码：能唯一标识且最小；主码：选定的候选码；外码：引用另一关系的键。
- 完整性：实体、参照、用户定义。
- NULL 不等于 0 或空字符串，普通比较产生 UNKNOWN。

## 关系代数 → [[关系代数与查询基础]]

| 运算 | 含义 |
|---|---|
| 选择 | 过滤行 |
| 投影 | 选择列并按集合语义去重 |
| 连接 | 按条件组合关系 |
| 并/差/交 | 要求并相容 |

## ER 转换 → [[ER模型与关系模式转换]]

- 1:N：1 端主码进入 N 端作外码。
- M:N：建立联系表，包含两端外码和联系属性。
- 1:1：结合全参与、NULL 与查询方向选择外码位置，并加 UNIQUE。

## SQL 逻辑顺序 → [[单表查询、聚合与分组]]

FROM/JOIN → WHERE → GROUP BY → HAVING → SELECT → DISTINCT/ORDER BY/LIMIT

- COUNT(*) 计行；COUNT(列) 忽略 NULL。
- WHERE 过滤行；HAVING 过滤聚合后的组。

## 连接与子查询 → [[多表连接、子查询与集合运算]]

- LEFT JOIN 要保留未匹配左行时，右表过滤条件通常放 ON。
- UNION 去重；UNION ALL 保留重复。
- 子查询可能含 NULL 时，NOT EXISTS 通常比 NOT IN 更稳妥。

## 数据库对象 → [[视图、存储过程与触发器]]

| 对象 | 关键点 |
|---|---|
| 普通视图 | 保存查询定义 |
| 物化视图 | 保存结果并需刷新 |
| 存储过程 | 显式调用的数据库程序 |
| 触发器 | 由事件自动执行 |

## 函数依赖与码 → [[函数依赖、属性闭包与候选码]]

- X+ 覆盖全部属性：X 是超码；再满足最小性：X 是候选码。
- 完全依赖：去掉决定因素任一属性后不再成立。

## 范式 → [[1NF、2NF与3NF]]、[[BCNF、无损分解与依赖保持]]、[[4NF与多值依赖]]

| 范式 | 核心 |
|---|---|
| 1NF | 属性值原子化 |
| 2NF | 消除非主属性对码的部分依赖 |
| 3NF | 消除非主属性对码的传递依赖 |
| BCNF | 每个非平凡函数依赖的决定因素都是超码 |
| 4NF | 每个非平凡多值依赖的决定因素都是超码 |

## ACID → [[事务、ACID与事务状态]]

| 性质 | 典型支撑 |
|---|---|
| 原子性 | UNDO/回滚 |
| 一致性 | 正确逻辑、约束及其他事务性质 |
| 隔离性 | 锁、MVCC、串行化协议 |
| 持久性 | REDO/WAL |

## 隔离级别 → [[并发异常与隔离级别]]

| 级别 | 脏读 | 不可重复读 | 幻读 |
|---|---|---|---|
| Read Uncommitted | 可能 | 可能 | 可能 |
| Read Committed | 防止 | 可能 | 可能 |
| Repeatable Read | 防止 | 防止 | 标准下可能 |
| Serializable | 防止 | 防止 | 防止 |

## 锁与串行化 → [[锁粒度、S锁、X锁与意向锁]]、[[两段锁、可串行化与死锁]]

- S-S 兼容；涉及 X 的 S-X、X-S、X-X 冲突。
- 2PL：增长阶段只加锁，收缩阶段只解锁。
- 优先图无环 ⇔ 调度冲突可串行化。
- 等待图有环表示死锁。

## MVCC → [[MVCC、时间戳与乐观并发控制]]

- 多版本加可见性规则减少快照读与写的互相阻塞。
- 写写冲突、当前读和元数据仍可能需要锁或冲突检测。

## 索引 → [[数据库中的B+树、Hash与全文索引]]、[[聚簇索引、二级索引与覆盖索引]]

| 类型 | 擅长 |
|---|---|
| B+ 树 | 等值、范围、排序、分组、前缀 |
| Hash | 等值 |
| 全文 | 词项到文档的倒排检索 |
| 覆盖索引 | 避免回表 |

## 查询优化 → [[查询执行计划与优化]]

- 看执行计划、估算与实际行数、扫描方式、连接算法、排序和回表。
- 常见方向：减少数据量、合适索引、批量查询、更新统计信息、按键分页。

## 存储引擎 → [[MySQL存储引擎与选型]]

- 通用 OLTP 通常优先 InnoDB：事务、MVCC、崩溃恢复、行级锁。
- 引擎能力随版本变化，选型需核对当前文档。

## 恢复 → [[日志、WAL与故障类型]]、[[UNDO、REDO、检查点与恢复流程]]

- WAL：日志先于对应脏页落盘。
- steal 需要 UNDO；no-force 需要 REDO。
- 检查点缩短恢复扫描，不等于备份。

## 安全与备份 → [[数据库安全、权限与备份]]

- 最小权限、角色授权、审计、参数化查询。
- RPO：可接受数据丢失量；RTO：可接受恢复时间。

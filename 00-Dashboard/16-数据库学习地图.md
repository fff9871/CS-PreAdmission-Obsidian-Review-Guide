# 数据库学习地图

#dashboard #database

## Overview

主线采用“数据模型与设计 → SQL → 事务并发 → 存储索引 → 恢复安全”，同时训练定义、机制、复杂度与工程选型。

    三级模式与关系模型
            ↓
      ER 设计与规范化
            ↓
       SQL 与数据库对象
            ↓
       事务与并发控制
            ↓
     存储、索引与查询优化
            ↓
        恢复与安全

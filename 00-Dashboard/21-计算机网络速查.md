# 计算机网络速查

#dashboard #computer-networks #quick-reference

## 分层模型 → [[网络体系结构、OSI与TCP-IP模型]]

| 五层 | 通信对象/单位 | 典型协议/设备 |
|---|---|---|
| 应用 | 应用报文 | HTTP、DNS、FTP、SMTP |
| 传输 | 进程；段/用户数据报 | TCP、UDP、端口 |
| 网络 | 主机；IP 数据报 | IP、ICMP、路由器 |
| 链路 | 相邻节点；帧 | Ethernet、PPP、交换机 |
| 物理 | 比特 | 中继器、集线器 |

## 时延与性能 → [[网络性能指标、时延与吞吐量]]

- `发送时延 = 分组长度 L / 链路速率 R`
- `传播时延 = 距离 d / 信号传播速度 v`
- `总时延 = 处理 + 排队 + 发送 + 传播`
- `时延带宽积 = 传播时延 × 带宽`
- 带宽是能力上限，吞吐量是实际交付速率。

## 信道容量 → [[奈奎斯特定理与香农公式]]

- 无噪声：`C = 2B log₂V`
- 有噪声：`C = B log₂(1+S/N)`
- `SNR(dB)=10log₁₀(S/N)`
- 同时受两种约束时取更严格上限。

## 链路可靠与介质访问 → [[停止等待、GBN与选择重传]]

| 机制 | 速记 |
|---|---|
| CRC | 模 2 除法，负责检错 |
| 停止-等待 | 发一帧等一个确认 |
| GBN | 接收窗口 1，累计确认，回退重传 |
| SR | 缓存乱序，只重传缺失帧 |
| CSMA/CD | 先听后发、边发边听、冲突退避 |
| CSMA/CA | 监听、退避、ACK，可选 RTS/CTS |

## 交换机与路由器 → [[以太网、MAC地址与交换机]]

- 交换机从**源 MAC**学习端口；未知目的 MAC 泛洪。
- 交换机隔离冲突域，默认不隔离同 VLAN 广播域。
- 路由器按 IP 前缀跨网转发，接口形成三层边界。

## IPv4 与子网 → [[IPv4编址、子网与CIDR]]

- `网络地址 = IP AND 子网掩码`
- `/n` 表示 n 位网络前缀。
- 普通子网地址数：`2^(32-n)`；可用主机数按具体场景判断。
- 多条路由匹配时选择**最长前缀**。

## ARP、DHCP与ICMP → [[DHCP、ICMP与网络诊断]]

| 协议 | 速记 |
|---|---|
| ARP | 本地 IPv4 下一跳 IP → MAC |
| DHCP | Discover → Offer → Request → ACK |
| ICMP | 差错报告与诊断；ping、traceroute |

## 路由协议 → [[RIP、OSPF与BGP]]

| 协议 | 范围 | 关键词 |
|---|---|---|
| RIP | IGP | 距离向量、跳数、15 跳 |
| OSPF | IGP | 链路状态、Dijkstra、区域 |
| BGP | EGP | 路径向量、AS_PATH、策略 |

## UDP与TCP → [[UDP协议与适用场景]]

| 特性 | UDP | TCP |
|---|---|---|
| 连接 | 无连接 | 面向连接 |
| 数据模型 | 报文 | 字节流 |
| 可靠顺序 | 不内建 | 提供 |
| 控制 | 无内建流量/拥塞控制 | 滑动窗口与拥塞控制 |
| 常见场景 | DNS、实时媒体、游戏 | Web、文件、事务数据 |

## TCP建连与释放 → [[TCP三次握手与连接建立]]

- 建立：`SYN → SYN+ACK → ACK`
- 释放：`FIN → ACK → FIN → ACK`
- 每个 FIN 关闭一个发送方向；主动关闭方通常进入 TIME-WAIT。
- `2MSL`：保证最终 ACK 可重传，并等待旧报文消失。

## TCP窗口与拥塞 → [[TCP拥塞控制算法]]

- 实际在途上限通常受 `min(rwnd,cwnd)` 限制。
- `rwnd` 保护接收方；`cwnd` 保护网络。
- 慢开始近似指数增长；拥塞避免加法增大。
- 超时：强降窗；多个重复 ACK：快重传，经典 Reno 快恢复。

## DNS与HTTP → [[DNS域名系统与解析]]

- DNS：客户端递归请求本地解析器；解析器迭代查询根、TLD、权威。
- HTTP 状态码：2xx 成功、3xx 重定向/缓存、4xx 客户端错误、5xx 服务端错误。
- HTTP 语义无状态，不等于每次都断开连接。
- HTTPS = HTTP over TLS，提供机密性、完整性和身份认证。

## 常见端口 → [[电子邮件SMTP、POP3与IMAP]]

| 服务 | 常见端口 |
|---|---|
| DNS | 53 UDP/TCP |
| HTTP / HTTPS | 80 / 443 |
| FTP 控制 | 21 TCP |
| SMTP | 25/587；加密提交常见 465 |
| POP3 / POP3S | 110 / 995 |
| IMAP / IMAPS | 143 / 993 |

> [!warning]
> 端口是约定而非不可改变的物理属性；实际服务可配置其他端口。

`URL解析 → DNS → 路由/ARP → TCP或QUIC → TLS → HTTP → 解析与渲染`

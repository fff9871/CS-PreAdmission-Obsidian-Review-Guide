# 概率在机器学习中的作用（★★★）

#probability #machine-learning

## Overview Table

| 作用 | 概率视角 | 常见例子 |
|---|---|---|
| 表示噪声 | $Y=f(X)+\varepsilon$ | 测量误差、标签噪声 |
| 定义训练目标 | 最大化似然 | 交叉熵、均方误差 |
| 输出不确定性 | 预测分布 | 分类概率、置信区间 |
| 融合先验 | 贝叶斯更新 | MAP、贝叶斯模型 |
| 决策 | 最小化期望风险 | 分类阈值、代价敏感决策 |

## 概率模型

机器学习通常建模：

$$P(Y\mid X,\theta)$$

训练是根据数据学习参数 $\theta$，预测则是计算新输入下输出的条件分布。

```text
数据 (X,Y)
   -> 概率假设 P(Y|X,θ)
   -> 最大化似然/后验
   -> 得到参数 θ
   -> 输出预测与不确定性
```

## 损失函数的概率解释

| 损失 | 概率假设 |
|---|---|
| 二分类交叉熵 | 标签服从伯努利分布 |
| 多分类交叉熵 | 标签服从类别分布 |
| 均方误差 | 误差服从固定方差高斯分布 |
| L2 正则 | 参数具有高斯先验 |
| L1 正则 | 参数具有拉普拉斯先验 |

最大似然与负对数似然：

$$\arg\max_\theta P(D\mid\theta)=\arg\min_\theta[-\log P(D\mid\theta)]$$

## MLE 与 MAP

最大似然：

$$\hat\theta_{MLE}=\arg\max_\theta P(D\mid\theta)$$

最大后验：

$$\hat\theta_{MAP}=\arg\max_\theta P(D\mid\theta)P(\theta)$$

MAP 比 MLE 多使用了参数先验，可视为一种正则化。

## 不确定性

- **数据不确定性**：数据自身存在噪声，增加相同类型数据也无法完全消除。
- **模型不确定性**：训练数据不足导致对参数缺乏把握，可通过更多数据降低。

> [!warning]
> 分类器输出的 softmax 值不一定天然校准为真实置信度，必要时需进行概率校准。

# 安全威胁、恶意软件与系统加固（★★★）

#operating-systems #system-security #malware #hardening

## Overview Table

| 威胁 | 特征 |
|---|---|
| 病毒 | 附着宿主并在运行时传播 |
| 蠕虫 | 利用网络和漏洞自主传播 |
| 木马 | 伪装成正常程序执行恶意功能 |
| 勒索软件 | 加密/破坏数据并索取利益 |
| Rootkit | 隐藏持久化和提权活动 |
| 逻辑炸弹/后门 | 条件触发或绕过正常认证入口 |

## 常见漏洞链

    输入验证缺陷 → 内存破坏/注入
       → 控制流或权限提升
       → 持久化、横向移动、数据访问

缓解手段包括最小权限、补丁、强认证、ASLR、DEP/NX、栈保护、控制流完整性、沙箱、代码签名、网络隔离、备份和监控。

## 可信计算基

TCB 是实现安全策略所必须信任的软硬件集合。攻击面越小、接口越简单，越利于审计和验证；安全启动可验证从固件到内核/组件的完整性链。

> [!warning]
> 单项机制不能独立保证安全：ASLR 可被信息泄漏削弱，杀毒不能替代补丁和隔离，备份还需离线/不可变副本并定期验证恢复。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| 病毒 vs 蠕虫 | 依附宿主传播 vs 自主网络传播 |
| 最小 TCB | 减少必须信任和审计的代码 |
| 纵深防御 | 预防、隔离、检测、响应与恢复多层组合 |

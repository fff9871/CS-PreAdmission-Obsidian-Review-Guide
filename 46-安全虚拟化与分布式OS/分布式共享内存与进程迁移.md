# 分布式共享内存与进程迁移（★★★）

#operating-systems #distributed-systems #distributed-shared-memory #process-migration

## Overview Table

| 机制 | 目标 | 难点 |
|---|---|---|
| DSM | 让多节点内存表现为共享地址空间 | 一致性、粒度、假共享、故障 |
| 远程分页 | 缺页时从其他节点取页 | 网络延迟和所有权定位 |
| 进程迁移 | 把执行状态移到另一节点 | 地址空间、文件、通信端点和外部状态 |
| 负载迁移 | 利用空闲节点、靠近数据 | 迁移成本与收益预测 |

## DSM 访问

    node A access page
       → local fault
       → locate owner/copy
       → fetch/invalidate/update
       → resume

一致性可采用写无效或写更新；页粒度简单但容易产生假共享，对象粒度语义更好但运行时复杂。

## 迁移阶段

停止并复制易实现但停顿长；预复制先迭代传输脏页，最后短暂停顿；后复制先迁移执行状态，缺页时按需拉取，但源节点故障风险更高。

> [!warning]
> 迁移 CPU/内存状态不等于完整迁移：打开文件、网络连接、设备、身份凭据和时间语义都需重定向或重建。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| DSM 假共享 | 不同节点写同一页中的不同变量仍触发页一致性通信 |
| 预复制 | 迁移前迭代发送内存，缩短最终停顿 |
| 迁移是否值得 | 预计后续收益需大于传输与重建成本 |

# 指令流水线原理与性能（★★★）

#computer-organization #pipeline #pipeline-performance

## Overview Table

| 指标 | 理想 k 段流水线 |
|---|---|
| 时钟周期 | 由最慢阶段延迟加流水寄存器开销决定 |
| 单条指令延迟 | 约 `kT` |
| n 条指令总时间 | `(k+n-1)T` |
| 稳态吞吐率 | 约每周期完成 1 条指令 |
| 相对串行加速比 | 理想约 `nk/(k+n-1)`，n 很大时趋近 k |

## 五级流水线

    Cycle → 1   2   3   4   5   6   7
    I1      IF  ID  EX  MEM WB
    I2          IF  ID  EX  MEM WB
    I3              IF  ID  EX  MEM WB

经典五级包括 IF 取指、ID 译码/读寄存器、EX 执行、MEM 访存、WB 写回。流水化通过重叠不同指令的阶段提高吞吐率，通常不会缩短单条指令的逻辑延迟。

## 非理想因素

- 阶段不均衡使时钟由最慢阶段决定。
- 流水寄存器带来时钟、建立保持和控制开销。
- 冒险导致暂停、冲刷或重执行。
- 分支和异常破坏连续供给。

> [!warning]
> 流水段越多不一定越快。更深流水线可提高频率，却增加寄存器开销、分支误预测损失和旁路/控制复杂度。

## Exam/Test Patterns

| 场景 | 回答 |
|---|---|
| 流水线提升什么 | 主要提升吞吐率，而非必然降低单条延迟 |
| n 条任务时间 | 装入 `k-1` 周期，加 n 个结果节拍 |
| 深流水线代价 | 寄存器开销、阶段不均、冒险和误预测损失 |

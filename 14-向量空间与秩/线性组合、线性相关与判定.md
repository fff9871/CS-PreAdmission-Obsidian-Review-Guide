# 线性组合、线性相关与判定（★★★）

#linear-algebra #vector-spaces #linear-independence

## Overview Table

| 问题 | 判定方法 |
|---|---|
| 向量组是否无关 | $Ac=0$ 是否只有零解 |
| 列向量是否无关 | $\operatorname{rank}(A)=$ 列数 |
| 方阵列向量是否无关 | 可再用 $\det A\ne0$ |
| $b$ 能否由列向量表出 | $\operatorname{rank}(A)=\operatorname{rank}([A\mid b])$ |

## 定义

$v$ 是 $v_1,\ldots,v_k$ 的线性组合，若 $v=\sum_i c_iv_i$。

向量组线性相关，当存在**不全为零**的 $c_i$ 使

$$c_1v_1+\cdots+c_kv_k=0.$$

否则线性无关。

## 等价判定

把向量作为列拼成 $A=[v_1\ \cdots\ v_k]$：

```text
求 r = rank(A)
   ├─ r = k：列向量线性无关
   └─ r < k：列向量线性相关
```

这是非方阵也适用的判定。行列式只能用于列数等于行数的方阵情形。

## 常用结论

- 含零向量的向量组必相关。
- 含成比例的两个向量必相关。
- 向量个数大于空间维数必相关。
- 不同特征值对应的特征向量线性无关。
- 一个向量可由其余向量表出，当且仅当整个向量组相关。

> [!warning]
> “存在系数使线性组合为零”没有区分度；全零系数总能做到，必须要求系数不全为零。

## Exam/Test Patterns

| 关键词 | 回答 |
|---|---|
| “怎么判断向量组无关” | 拼成矩阵求秩；列秩等于向量数则无关 |
| “方阵还有什么方法” | 行列式非零、齐次方程只有零解 |
| “几何意义” | 无冗余方向，张成空间维数等于向量数 |
| “某向量能否表出” | 比较增广前后的秩 |

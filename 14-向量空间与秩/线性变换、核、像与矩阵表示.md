# 线性变换、核、像与矩阵表示（★★★）

#linear-algebra #vector-spaces #linear-transformations

## Overview Table

| 概念 | 定义 |
|---|---|
| 线性变换 | $T(au+bv)=aT(u)+bT(v)$ |
| 核 | $\ker T=\{v:T(v)=0\}$ |
| 像 | $\operatorname{im}T=\{T(v):v\in V\}$ |
| 同构 | 双射线性变换 |

## 核与像

核衡量输入中被压缩为零的方向；像描述所有可能输出。二者都是子空间。

$$\dim\ker T+\dim\operatorname{im}T=\dim V.$$

对矩阵 $A\in\mathbb F^{m\times n}$，$T(x)=Ax$：

- $\ker T$ 是 $Ax=0$ 的解空间；
- $\operatorname{im}T$ 是 $A$ 的列空间；
- $\dim\operatorname{im}T=\operatorname{rank}(A)$。

## 单射、满射与核像

| 性质 | 等价条件 |
|---|---|
| $T$ 单射 | $\ker T=\{0\}$ |
| $T$ 满射到 $W$ | $\operatorname{im}T=W$ |
| $T$ 同构 | 单射且满射 |

## 矩阵表示与换基

选定定义域基 $B$ 和陪域基 $C$ 后，线性变换对应唯一矩阵 $[T]_{C\leftarrow B}$。若同一空间更换基，矩阵通过相似变换联系：

$$[T]_C=P^{-1}[T]_BP.$$

```text
抽象变换 T
   + 选择输入/输出基
   ↓
矩阵表示 A
   + 更换基
   ↓
相似矩阵 P⁻¹AP
```

> [!warning]
> 矩阵依赖基，线性变换本身不依赖基；相似矩阵描述同一个算子在不同基下的坐标。

## Exam/Test Patterns

| 关键词 | 回答 |
|---|---|
| “线性变换定义” | 保持加法和数乘 |
| “核的意义” | 被映到零的输入方向；核为零等价单射 |
| “像的意义” | 所有可达到的输出，维数等于秩 |
| “秩—零化度” | 核维数 + 像维数 = 定义域维数 |

# 极大线性无关组、生成空间与向量组的秩（★★★）

#linear-algebra #vector-spaces #linear-independence #rank

## Overview Table

| 概念 | 定义 |
|---|---|
| 生成空间 | 所有线性组合构成的集合 |
| 极大线性无关组 | 线性无关且能表出原向量组全部向量的子组 |
| 向量组的秩 | 任一极大线性无关组的向量个数 |
| 等价向量组 | 两组向量能相互线性表出 |

## 极大与最大

在线性代数教材中，“极大线性无关组”是不能再从原向量组加入向量而保持无关的子组；它等价于张成空间的一组基。所有极大无关组大小相同。

```text
原向量组（可能冗余）
       ↓ 删除可由其他向量表出的项
极大线性无关组
       ↓
保留相同张成空间，元素数 = 秩
```

## 求法

把向量作列组成矩阵并行化简。原矩阵中与阶梯形主元列对应的列向量构成一个极大线性无关组。

> [!important]
> 选取的是**原矩阵**的对应列，不是行变换后阶梯形矩阵的列，因为行变换会改变具体列向量。

## 等价向量组

两向量组等价，当且仅当它们张成同一子空间。等价向量组秩相同，但“秩相同”本身不足以保证两组等价；还需张成空间相同。

## 与基础解系

极大无关组是原向量组张成空间的一组基；基础解系是齐次方程组解空间 $\ker A$ 的一组基。二者本质上都是“某个空间的基”，但所在空间不同。

## Exam/Test Patterns

| 关键词 | 回答 |
|---|---|
| “极大无关组” | 无关且张成原向量组，元素数等于秩 |
| “如何求” | 化阶梯形，取原矩阵的主元列 |
| “与基础解系关系” | 都是基；前者基于列的生成空间，后者基于零空间 |
| “等价向量组” | 相互线性表出，即张成空间相同 |

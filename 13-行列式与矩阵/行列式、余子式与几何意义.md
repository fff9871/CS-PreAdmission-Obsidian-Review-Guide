# 行列式、余子式与几何意义（★★★）

#linear-algebra #determinants

## Overview Table

| 概念 | 公式/含义 |
|---|---|
| 余子式 | 删除 $a_{ij}$ 所在行列得到的行列式 $M_{ij}$ |
| 代数余子式 | $A_{ij}=(-1)^{i+j}M_{ij}$ |
| Laplace 展开 | $\det A=\sum_j a_{ij}A_{ij}$ |
| 几何意义 | 有向面积/体积的缩放因子 |

## 定义与几何意义

行列式把 $n\times n$ 方阵映射为标量。若 $A$ 表示线性变换，则 $|\det A|$ 是体积缩放倍数，符号反映定向是否翻转。

```text
单位立方体
   ↓ 线性变换 A
平行多面体
体积倍率 = |det A|
```

$\det A=0$ 表示空间被压入低维子空间，因此列向量线性相关且 $A$ 不可逆。

## 高频性质

| 操作 | 行列式变化 |
|---|---|
| 交换两行 | 乘 $-1$ |
| 某行乘 $k$ | 行列式乘 $k$ |
| 一行加另一行的倍数 | 不变 |
| 两行相同/成比例 | 为 0 |
| 三角矩阵 | 对角元之积 |
| 乘积 | $\det(AB)=\det A\det B$ |

## 特殊公式

- Vandermonde 行列式：$\det V=\prod_{i<j}(x_j-x_i)$。
- Cramer 法则：若 $A$ 可逆，$Ax=b$ 的第 $i$ 个分量 $x_i=\det A_i/\det A$。
- 直接按排列定义计算复杂；实际常用高斯消元或 LU 分解，约为 $O(n^3)$。

> [!warning]
> 面积和体积是 $|\det A|$；行列式本身带方向符号。行列式只对方阵定义。

## Exam/Test Patterns

| 关键词 | 回答 |
|---|---|
| “行列式意义” | 线性变换的有向体积缩放因子 |
| “某行倍加” | 行列式不变 |
| “为何 det=0 不可逆” | 体积压缩为零，列向量相关 |
| “大规模计算” | 消元或 LU，而非递归展开 |

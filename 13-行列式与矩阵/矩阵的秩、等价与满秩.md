# 矩阵的秩、等价与满秩（★★★）

#linear-algebra #matrices #rank

## Overview Table

| 视角 | 秩的含义 |
|---|---|
| 子式 | 非零子式的最高阶数 |
| 行阶梯形 | 非零行数/主元个数 |
| 列空间 | 线性无关列的最大个数 |
| 线性变换 | 像空间维数 |

## 秩的基本性质

对 $m\times n$ 矩阵：

$$0\le\operatorname{rank}(A)\le\min(m,n),$$
$$\operatorname{rank}(A)=\operatorname{rank}(A^T),$$
$$\operatorname{rank}(AB)\le\min(\operatorname{rank}A,\operatorname{rank}B).$$

初等行、列变换不改变秩。

## 满秩

| 情况 | 含义 |
|---|---|
| 列满秩 | $r=n$，列向量线性无关，要求 $m\ge n$ |
| 行满秩 | $r=m$，行向量线性无关，要求 $n\ge m$ |
| 方阵满秩 | $r=n$，等价于可逆 |

> [!warning]
> 长方形矩阵可以满秩，但“满秩”是达到 $\min(m,n)$；它不一定存在双侧逆。

## 矩阵等价

$A,B$ 等价，若存在可逆矩阵 $P,Q$ 使 $B=PAQ$。同型矩阵等价当且仅当秩相同；等价标准形为

$$\begin{pmatrix}I_r&0\\0&0\end{pmatrix}.$$

```text
A ──初等行/列变换──> 标准形
                     主元数 = rank(A)
```

## 秩的意义

秩同时衡量矩阵所携带的独立方向数量、线性变换输出空间维数，以及方程组中的主元数量。

## Exam/Test Patterns

| 关键词 | 回答 |
|---|---|
| “秩是什么” | 非零子式最高阶数，也等于主元数和像空间维数 |
| “满秩性质” | 分行满秩、列满秩；方阵满秩才等价可逆 |
| “矩阵等价” | 通过可逆行列变换联系，同型时等价于秩相同 |
| “秩怎么求” | 高斯消元化阶梯形，数主元 |

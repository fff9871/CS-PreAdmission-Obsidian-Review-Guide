# 矩阵运算、转置、迹与特殊矩阵（★★★）

#linear-algebra #matrices

## Overview Table

| 对象 | 条件/性质 |
|---|---|
| 矩阵乘法 $AB$ | $A$ 的列数等于 $B$ 的行数 |
| 转置 | $(AB)^T=B^TA^T$ |
| 共轭转置 | $(AB)^*=B^*A^*$ |
| 迹 | $\operatorname{tr}(A)=\sum_i a_{ii}$ |

## 矩阵乘法

矩阵乘法对应线性映射复合：$ABx=A(Bx)$，所以右侧矩阵先作用。它满足结合律、分配律，通常不满足交换律。

| 性质 | 是否一般成立 |
|---|---|
| $(AB)C=A(BC)$ | 是 |
| $A(B+C)=AB+AC$ | 是 |
| $AB=BA$ | 否 |
| $AB=0\Rightarrow A=0$ 或 $B=0$ | 否 |

## 转置、共轭与迹

- 实矩阵转置：行列互换。
- 复矩阵共轭转置：先共轭再转置。
- $\operatorname{tr}(AB)=\operatorname{tr}(BA)$，更一般地迹在循环置换下不变。
- 迹等于全部特征值之和（按代数重数）。

## 特殊矩阵

| 类型 | 定义 |
|---|---|
| 对角矩阵 | 非主对角元全为 0 |
| 上三角矩阵 | 主对角线下方全为 0 |
| 对称矩阵 | $A^T=A$ |
| 反对称矩阵 | $A^T=-A$，实数域上对角元为 0 |
| Hermitian | $A^*=A$ |
| 正交矩阵 | $Q^TQ=I$ |

```text
向量 x ──B──> Bx ──A──> A(Bx)=ABx
```

> [!warning]
> $\operatorname{tr}(AB)=\operatorname{tr}(BA)$ 不意味着 $AB=BA$。

## Exam/Test Patterns

| 关键词 | 回答 |
|---|---|
| “矩阵乘法为何不交换” | 表示映射复合，作用顺序不同 |
| “迹是什么” | 方阵主对角元之和，也是特征值之和 |
| “对称与反对称” | $A^T=A$ 与 $A^T=-A$ |
| “复矩阵对应转置” | 使用共轭转置 $A^*$ |

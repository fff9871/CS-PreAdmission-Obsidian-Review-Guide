# 矩阵与张量（★）

#linear-algebra #matrices #tensors

## Overview Table

| 对象 | 数据轴数 | 典型记号 |
|---|---:|---|
| 标量 | 0 | $a$ |
| 向量 | 1 | $x_i$ |
| 矩阵 | 2 | $A_{ij}$ |
| 高阶数组 | 3 及以上 | $T_{ijk\ldots}$ |

## 两种语境

在机器学习中，tensor 常指多维数组；在数学与物理中，张量还强调坐标变换下的多重线性结构。矩阵可以表示二阶张量，但“多维数组”只有配合适当变换规则才是严格数学意义的张量。

## 矩阵化与收缩

- 展平/矩阵化：把高阶数组重排为矩阵，便于使用矩阵分解。
- 张量收缩：对成对指标求和，是矩阵乘法的高阶推广。
- 外积：由多个向量生成秩一张量。

```text
向量外积 ─> 秩一矩阵/张量
多个秩一项相加 ─> 低秩近似
```

## 与线性代数的联系

张量计算依赖向量空间、基变换、内积、范数和分解。常见 CP/Tucker 分解可视为高阶数据的低秩表示。

> [!warning]
> “阶”在矩阵理论中有时指方阵大小，在张量语境中常指轴数；回答时要先说明含义。

## Exam/Test Patterns

| 关键词 | 回答 |
|---|---|
| “张量与矩阵区别” | 矩阵是二维表示；张量可有更多指标并具有多重线性变换规律 |
| “机器学习 tensor” | 通常指可计算的多维数组 |
| “矩阵是几阶张量” | 常见工程语境下是二阶张量 |

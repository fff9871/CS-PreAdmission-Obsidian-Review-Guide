# 期望、方差、协方差与相关系数（★★★）

#probability #moments

## Overview Table

| 指标   | 描述对象 | 含义        | 是否受量纲影响 |
| ---- | ---- | --------- | ------- |
| 期望   | 单变量  | 中心位置      | 是       |
| 方差   | 单变量  | 围绕均值的离散程度 | 是，单位平方  |
| 协方差  | 两变量  | 共同线性变化方向  | 是       |
| 相关系数 | 两变量  | 标准化线性相关强度 | 否       |

## 期望

离散型：

$$E[X]=\sum_xxP(X=x)$$

连续型：

$$E[X]=\int_{-\infty}^{\infty}xf_X(x)dx$$

线性性质不要求独立：

$$E[aX+bY+c]=aE[X]+bE[Y]+c$$

## 方差

$$Var(X)=E[(X-E[X])^2]$$

常用计算式：

$$Var(X)=E[X^2]-E[X]^2$$

线性变换：

$$Var(aX+b)=a^2Var(X)$$

## 协方差

$$Cov(X,Y)=E[(X-E[X])(Y-E[Y])]$$

$$Cov(X,Y)=E[XY]-E[X]E[Y]$$

和的方差：

$$Var(X+Y)=Var(X)+Var(Y)+2Cov(X,Y)$$

一般线性组合：

$$Var(aX+bY)=a^2Var(X)+b^2Var(Y)+2abCov(X,Y)$$

## 相关系数

$$\rho_{X,Y}=\frac{Cov(X,Y)}{\sigma_X\sigma_Y}$$

$$-1\le\rho_{X,Y}\le1$$

| 数值 | 含义 |
|---:|---|
| 接近 1 | 强正线性相关 |
| 接近 -1 | 强负线性相关 |
| 接近 0 | 线性相关弱，不代表独立 |

## 协方差矩阵

随机向量 $X=(X_1,\ldots,X_n)^T$ 的协方差矩阵：

$$\Sigma_{ij}=Cov(X_i,X_j)$$

性质：

- 对称：$\Sigma^T=\Sigma$；
- 对角线为各变量方差；
- 半正定：$a^T\Sigma a\ge0$；
- $a^T\Sigma a=Var(a^TX)$。

> [!warning]
> 协方差绝对值受变量尺度影响，不能直接跨不同量纲比较；相关系数用于无量纲比较。

## Exam/Test Patterns

| 问法 | 标准回答 |
|---|---|
| 如何快速算方差 | $E[X^2]-E[X]^2$ |
| 期望是否要求独立 | 不要求 |
| 方差何时可以直接相加 | 变量不相关，独立是充分条件 |
| 相关系数范围 | $[-1,1]$ |
| 协方差矩阵性质 | 对称半正定 |

# 独立、不相关与互斥（★★★）

#probability #dependence

## Overview Table

| 概念     | 数学条件                  | 含义              |
| ------ | --------------------- | --------------- |
| 事件独立   | $P(A\cap B)=P(A)P(B)$ | 一个事件不改变另一个事件的概率 |
| 随机变量独立 | $f_{X,Y}=f_Xf_Y$      | 联合分布可分解         |
| 不相关    | $Cov(X,Y)=0$          | 没有线性相关          |
| 互斥     | $A\cap B=\varnothing$ | 两个事件不能同时发生      |

## 独立

事件独立等价于：

$$P(A\mid B)=P(A)$$

随机变量独立意味着对任意合适集合 $S,T$：

$$P(X\in S,Y\in T)=P(X\in S)P(Y\in T)$$

独立是对整个联合分布的约束，因此比“不相关”更强。

## 不相关

$$Cov(X,Y)=0$$

它只说明变量之间没有线性关系，仍可能存在明显的非线性关系。

反例：$X\sim U(-1,1)$，$Y=X^2$。由于对称性 $E[X^3]=0$，所以 $Cov(X,Y)=0$，但 $Y$ 完全由 $X$ 决定。

## 独立与不相关的关系

```text
独立 + 二阶矩存在
        ↓
      不相关

不相关 ──通常不能推出──> 独立
联合高斯时可推出
```

## 独立与互斥的关系

若 $A,B$ 互斥：

$$P(A\cap B)=0$$

若还要求独立：

$$P(A)P(B)=0$$

因此，当两个事件概率均大于 0 时，互斥与独立不能同时成立。

> [!important]
> 互斥表示“一个发生会排除另一个”，不是“互不影响”。

> [!warning]
> 若其中一个事件概率为 0，则它可以与另一个事件既互斥又独立，这是零概率边界情况。

## Exam/Test Patterns

| 问法 | 标准回答 |
|---|---|
| 独立能否推出不相关 | 二阶矩存在时可以 |
| 不相关能否推出独立 | 一般不能；联合高斯可以 |
| 互斥能否推出独立 | 两事件概率均非零时不能 |
| 零协方差意味着什么 | 没有线性相关关系 |
| 如何证明独立 | 检查联合分布是否可分解为边缘分布乘积 |

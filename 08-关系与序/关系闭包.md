# 关系闭包（★★★）

#discrete-mathematics #relations

## Overview Table

| 闭包 | 需要补什么 | 公式/算法 |
|---|---|---|
| 自反闭包 | 全部自环 | $r(R)=R\cup I_A$ |
| 对称闭包 | 每条边的反向边 | $s(R)=R\cup R^{-1}$ |
| 传递闭包 | 所有可达捷径 | $t(R)=\bigcup_{k\ge1}R^k$ |

## 闭包的定义

性质 $P$ 的闭包是包含 $R$、满足 $P$ 的**最小关系**。这里“最小”按集合包含关系理解。

```text
原关系 R
  + 为满足目标性质所必需的最少关系对
  = 目标闭包
```

## 三种基本闭包

设恒等关系 $I_A=\{(x,x)\mid x\in A\}$，逆关系 $R^{-1}=\{(y,x)\mid(x,y)\in R\}$。

- 自反闭包：补齐所有对角元素。
- 对称闭包：给每个关系对补反向关系对。
- 传递闭包：若存在从 $x$ 到 $y$ 的正长度路径，就加入 $(x,y)$。

## Warshall 算法

对有限关系矩阵 $M$，依次允许每个顶点作为中间点：

$$M_{ij}\leftarrow M_{ij}\lor(M_{ik}\land M_{kj}).$$

三层循环结束后得到可达矩阵，即传递闭包。时间复杂度 $O(n^3)$。

> [!warning]
> 同时求多种闭包时，操作顺序可能影响中间结果。目标应直接定义为“包含 $R$ 且同时满足全部性质的最小关系”，而不是机械地只做一遍各类闭包。

## Exam/Test Patterns

| 题型关键词 | 回答 |
|---|---|
| “闭包是什么” | 包含原关系、满足指定性质的最小扩充 |
| “自反闭包” | 加恒等关系 $I_A$ |
| “传递闭包图像意义” | 两点之间存在正长度路径就建立关系 |
| “矩阵求传递闭包” | Warshall：逐个允许中间顶点 |

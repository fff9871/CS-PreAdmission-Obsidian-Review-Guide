# 偏序、全序与良序（★★★）

#discrete-mathematics #relations #order-theory

## Overview Table

| 序结构 | 条件 | 例子 |
|---|---|---|
| 偏序 | 自反、反对称、传递 | $(\mathcal P(S),\subseteq)$ |
| 全序 | 偏序且任意两元素可比 | $(\mathbb Z,\le)$ |
| 良序 | 全序且每个非空子集有最小元 | $(\mathbb N,\le)$ |
| 严格偏序 | 反自反、传递 | $<$、真包含 $\subset$ |

## 偏序与可比性

偏序允许不可比元素。若 $x\preceq y$ 或 $y\preceq x$，称 $x,y$ 可比；全序要求任意一对都可比。

> [!important]
> 中文资料中的“半序”常被用作“偏序”的同义词；若课程另有定义，应以课程术语表为准。

## 哈斯图

有限偏序可用哈斯图表示：

1. 省略自环；
2. 省略由传递性可推出的边；
3. 较大元素画在较高位置，边默认向上。

```text
    6
   / \
  2   3      （整除关系在 {1,2,3,6} 上）
   \ /
    1
```

## 极值概念

| 概念 | 条件 | 唯一性 |
|---|---|---|
| 极大元 | 没有严格更大的元素 | 可有多个 |
| 最大元 | 大于等于所有元素 | 若存在则唯一 |
| 极小元 | 没有严格更小的元素 | 可有多个 |
| 最小元 | 小于等于所有元素 | 若存在则唯一 |

## 良序与归纳

良序要求每个非空子集都有最小元。$\mathbb N$ 的良序性与最小反例法、数学归纳法密切相关；$\mathbb Z$ 在通常次序下不是良序，因为负整数集合没有最小元。

## Exam/Test Patterns

| 题型关键词 | 回答 |
|---|---|
| “偏序定义” | 自反、反对称、传递 |
| “偏序与全序区别” | 全序额外要求任意两元素可比 |
| “极大元与最大元” | 最大元支配所有元素；极大元只要求上方没有更大者 |
| “整除关系” | 正整数上的偏序，通常不是全序 |

# 等价关系、等价类与划分（★★★）

#discrete-mathematics #relations

## Overview Table

| 概念 | 条件/含义 |
|---|---|
| 等价关系 | 自反 + 对称 + 传递 |
| 等价类 | $[a]=\{x\in A\mid xRa\}$ |
| 商集 | $A/R=\{[a]\mid a\in A\}$ |
| 划分 | 非空子集族两两不交，且并集为 $A$ |

## 等价关系

等价关系形式化“按某个标准视为相同”。典型例子是模 $n$ 同余：

$$a\equiv b\pmod n\Longleftrightarrow n\mid(a-b).$$

它自反、对称、传递，因此把整数分成 $n$ 个剩余类。

## 等价类的性质

若 $R$ 是等价关系，则：

1. $a\in[a]$；
2. $aRb\Longleftrightarrow[a]=[b]$；
3. 两个等价类要么相等，要么不交；
4. 所有等价类覆盖整个集合。

```text
集合 A
 ├─ 等价类 C1
 ├─ 等价类 C2
 └─ 等价类 C3
类内元素互相等价，类间没有交集
```

## 划分与等价关系一一对应

- 等价关系产生等价类划分。
- 给定划分 $\Pi$，定义“$x,y$ 位于同一块”即可得到等价关系。

这是从“成对关系”切换到“分组结构”的核心桥梁。

## 整除是不是等价关系

在正整数上，$a\mid b$ 自反、反对称、传递，但不对称。例如 $2\mid4$ 而 $4\nmid2$。所以它是偏序，不是等价关系。

## Exam/Test Patterns

| 题型关键词 | 回答 |
|---|---|
| “等价关系定义” | 自反、对称、传递 |
| “等价类是否重叠” | 若有公共元素则两类相等，否则不交 |
| “划分怎么产生关系” | 同属一个划分块时定义为相关 |
| “整除是等价关系吗” | 不是；它不对称，在正整数上是偏序 |

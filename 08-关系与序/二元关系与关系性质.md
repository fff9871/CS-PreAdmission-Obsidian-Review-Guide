# 二元关系与关系性质（★★★）

#discrete-mathematics #relations

## Overview Table

| 性质 | 形式化定义 | 典型例子 |
|---|---|---|
| 自反 | $\forall x,(x,x)\in R$ | $\le$、相等 |
| 反自反 | $\forall x,(x,x)\notin R$ | $<$ |
| 对称 | $xRy\Rightarrow yRx$ | “同岁” |
| 反对称 | $xRy\land yRx\Rightarrow x=y$ | $\le$、整除 |
| 不对称 | $xRy\Rightarrow\neg(yRx)$ | $<$ |
| 传递 | $xRy\land yRz\Rightarrow xRz$ | $\le$、整除 |

## 二元关系

从 $A$ 到 $B$ 的二元关系是 $A\times B$ 的任意子集；$A$ 上的关系满足 $R\subseteq A\times A$。

关系可用有序对集合、关系矩阵或有向图表示。

## 性质的量词结构

判断关系性质时必须检查整个定义域：

```text
自反：检查每个对角点
对称：检查每条边的反向边
反对称：只禁止不同顶点之间的双向边
传递：检查每条长度 2 的路径是否有捷径边
```

## 空关系与边界情况

非空集合 $A$ 上的空关系：

| 性质 | 是否成立 | 原因 |
|---|---|---|
| 自反 | 否 | 缺少所有 $(x,x)$ |
| 反自反 | 是 | 没有任何自环 |
| 对称 | 是 | 不存在反例，真空成立 |
| 反对称 | 是 | 不存在不同元素双向关系 |
| 传递 | 是 | 不存在可触发前件的关系对 |

这给出“对称且传递不能一般推出自反”的最小反例。

> [!warning]
> “反对称”不是“对称的反面”。一个关系可以既对称又反对称，例如相等关系。

## Exam/Test Patterns

| 题型关键词 | 回答 |
|---|---|
| “自反性有什么意义” | 每个元素与自身相关，是等价关系和非严格偏序的基础条件 |
| “对称+传递推出自反吗” | 一般不能；非空集合上的空关系是反例 |
| “反对称怎么理解” | 不同元素不能同时互相关联，自环不受禁止 |
| “用图判断传递” | 每条 $x\to y\to z$ 都要有 $x\to z$ |

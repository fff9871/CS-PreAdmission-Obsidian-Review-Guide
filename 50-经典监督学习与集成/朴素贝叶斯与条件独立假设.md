# 朴素贝叶斯与条件独立假设（★★★）

#machine-learning #supervised-learning #naive-bayes #conditional-independence

## Overview Table

| 变体 | 特征分布 |
|---|---|
| Gaussian NB | 连续特征按类条件高斯 |
| Multinomial NB | 计数/词频 |
| Bernoulli NB | 二元出现与否 |

## 分类公式

`ŷ=argmax_y p(y)∏_j p(x_j|y)`

“朴素”指给定类别后各特征条件独立：

`p(x|y)=∏_j p(x_j|y)`

实际计算使用对数把乘积变求和；对离散计数采用 Laplace/加 α 平滑，避免未见特征让整类概率为零。

## 特点

训练和推断快速，小数据、高维稀疏文本常有效。条件独立假设通常不真实，但分类边界仍可能表现良好。

> [!warning]
> 朴素性核心不是“所有特征边缘独立”或“每个特征同等重要”，而是给定类别后的条件独立假设；不同特征仍可有不同似然参数和贡献。

## Exam/Test Patterns

| 问法 | 回答 |
|---|---|
| 零频问题 | Laplace/加 α 平滑 |
| 防下溢 | 累加 log probability |
| 生成式分类器 | 学 `p(x|y)` 与 `p(y)` |

# 决策树、信息熵与信息增益（★★★）

#machine-learning #supervised-learning #decision-tree #information-gain

## Overview Table

| 指标 | 公式/特点 |
|---|---|
| 熵 | `H(D)=-Σ p_k log₂p_k` |
| 信息增益 | `H(D)-Σ_v |D_v|/|D| H(D_v)` |
| 增益率 | 信息增益 / 属性固有值 |
| Gini | `1-Σp_k²` |

## 树生成

    node data
      → enumerate features/splits
      → evaluate impurity decrease
      → choose best split
      → recurse until stopping criterion

分类树叶子输出类别分布或多数类，回归树叶子常输出均值。树天然表达非线性与特征交互，对单调尺度变换不敏感。

## 信息增益偏好

取值很多的离散特征容易把数据切得很纯，信息增益可能偏好这类特征；增益率通过分裂信息做归一化，但也有自身偏好。

> [!warning]
> 决策树分裂后信息增益小于等于 0 并不是唯一停止条件；还会用深度、样本数、纯度、最小增益和剪枝策略。
